# WireVersion 1

TCP 帧 = 4 字节大端正整数长度 + UTF-8 JSON 对象。请求最多 16 KiB，响应最多 8 MiB；数字字段只接受整数，不接受 true、浮点或字符串数字。JSON 最大输入深度32；重复字段、未知字段、缺少必需字段、未知枚举及 Debug 都在 Execute 前拒绝。字符串一般≤256字符，CommandId/MatchId≤100，凭证≤64。

`Hello` / `Resume`：Type、RoomId、Credential、WireVersion（1）、ProtocolVersion、EngineVersion、ContentHash、ContentVersion、RulesVersion；LastRevision 可选非负整数。所有能力须精确匹配当前服务基线。先验证能力、房间及凭证，后派发 Welcome/投影。Resume 不重放命令日志，LastRevision 只是恢复提示，不影响权威 revision。

`Welcome`：RoomId、Seat、Generation、Capabilities、Snapshot（本人 GameView）。同席新认证在房间锁内递增代次并关闭旧连接；旧连接再次执行时还会检查对象绑定和代次。凭证是32随机字节的64字符十六进制 bearer token，座位不由昵称/传入席位推导。

`Intent`：Type、CommandId、MatchId、ExpectedRevision、Kind及下表参数。服务从连接绑定生成 Command.ActorSeat，调用 Execute(authenticatedSeat, command)。允许的 TargetSeat 表示规则目标，不是操作者。

| Kind | 参数（?为可选） |
|---|---|
| ChooseHero、SelectCard、ChooseAttackTarget、Defend、ForcedDiscard、ChooseOptionalDiscard、ChooseRecoveredCard、ChooseEffectTarget、ChooseCardSwap、ChooseRoundMinionRemoval、ChooseUpgrade、ChoosePrimaryOption、ChooseMinionProtection、ChooseDiscardAttack | Value |
| ConfirmCard、Pass、BeginPrimary、DeclineDefense、DeclineRetaliationDiscard、ResolveRoundEnd | 无 |
| DeployHero | TargetSeat、Destination |
| ChooseInitiative | TargetSeat |
| Move | MoveMode；Destination 或 Value="begin"（两者不能同时存在） |
| ChooseEffectMove | Destination 或 Value="skip"（两者不能同时存在） |
| ChooseMinionSpawn | Destination、Value?（单位ID；省略交核心处理） |
| RespawnHero、ChoosePlacement | Destination |
| ChooseMinionReturn | Value（单位ID）、Destination |
| ChooseGoldTransfer | TargetSeat、Value（数量字符串）；核心既有跳过格式为 TargetSeat=-1、Value="0" |

Destination 严格为 `{ "X": 整数, "Y": 整数 }`，坐标输入限定±1000，棋盘/距离/合法性仍由核心决定。普通 TargetSeat 0..3，仅金币转移额外接受 -1；MoveMode 只接受字符串 Secondary/Fast。完整白名单在 `Wire.Fields`。

`Result` 只给发起连接：CommandId、Accepted、Duplicate、Code、Message、Generation、Snapshot。接受新命令后，房间锁内逐席生成并排队发送 `Snapshot`（Type、Generation、Snapshot）。结果不直接序列化核心 CommandResult，以便统一应用投影隐私收窄。

`Error` 表示协议/认证拒绝，不含投影；认证后可解析出的合法长度 CommandId 用于关联输入拒绝。身份无效、版本不匹配、超限帧等会关闭连接。普通非法规则命令返回 Result+本人视图；保持同连接可继续操作。

去重、冲突、过期、跨局检查全部复用 GameSession：相同完整命令返回 duplicate；改ID内容返回 command_id_conflict；已接受历史优先于 stale_revision。服务不会偷偷换 revision。拒绝命令不产生新revision，不广播成功。

每个客户端固定持有本人 GameView。只采用同 MatchId 的更高 revision，旧Result仍可完成其 CommandId；旧Generation不能完成新请求。断线的未确认意图保留在当前客户端进程内，返回 Uncertain；续连后由调用方显式 RetryAsync 原ID。客户端进程重启后的待发意图恢复未实现。

房间使用同一个锁串行处理认证/Execute/投影排队；每连接单独顺序写队列容量32，10秒握手/写超时；服务最多32条并发传输连接，认证席位仍只有4个。没有每提交落盘承诺。仅本地操作员标准输入 stop 能触发退出导出。

隐私：只调用 View(已认证席位)，不广播存档、Receipts或AcceptedCommands。现有核心的 Pending 候选元数据在非本人投影里仍可能存在，适配器进一步清空 CandidateCells/CandidateSeats/CandidateUnits，保留等待者与原因；不生成规则候选。核心统一投影需求见交接文档。
