# NET-02 外网后续评估（未部署）

NET-01尚待Unity接线与四窗口实操。本页仅预列后续方案、成本与门槛，不表示已进入公网交付；没有创建账号、购买服务、部署、改变防火墙或公开任何凭证。

## 方案和成本

查询日期2026-09-26；不含税费、电费、已有网络成本及超额流量。以下是服务公开标价，不是容量承诺。

| 方案 | 账号/成本 | 适合用途与限制 |
|---|---|---|
| 一位好友电脑开权威服务 + Tailscale私网 | Personal目前最多6用户免费，$0/月；四人需要各自登录身份并加入受控网络 | 首次四好友试局优先；主机要全程在线，连接质量须从好友实际网络测量。需要另做私网绑定配置和访问控制，目前程序仍硬限127.0.0.1 |
| Linux云主机，保持单一权威 | AWS Lightsail含公网IPv4的1GB套餐$7/月，2GB套餐$12/月；需AWS账号及付款方式 | 可先把$12/月列为待批准预算，是否1GB足够由长局测量决定。域名、备份、流量超额另计；跨地区延迟需验证 |

官方来源：[Tailscale价格](https://tailscale.com/pricing)、[Tailscale上手与账户说明](https://tailscale.com/docs/how-to/quickstart)、[Lightsail套餐规格和价格](https://docs.aws.amazon.com/lightsail/latest/userguide/amazon-lightsail-bundles.html)。Lightsail 1GB $5档是IPv6-only，本表采用含IPv4的$7档，避免混淆。实际选择时重新核价和地区可用性。

推荐先完成 NET-01 UI 验收，再以私网方案进行外网延迟/中断测试；是否创建账号、配置好友网络、使用付费主机由用户确认后执行。主机玩家仅是另一个已认证席位，服务本身不占第五席。

## 可交付完整对局前的步骤

1. 统一主任务 UI 会话接口、四人确认、固定本人手牌、断线禁用、恢复清预选；四窗口完成 NET-01。
2. 固定服务/客户端/内容/规则同一版本，提供成套发行物与逐文件哈希；卡牌仍以该版本实际已支持列表为准，不能把未来卡开发自动视作已兼容。
3. 选择私网或云主机方案，实测四人网络的延迟、丢连接、重连时间和到胜利的完整对局；测每阶段Snapshot、内存、历史增长、8MiB边界及10,000重放命令限制。当前只证明整轮与指定等待夹具。
4. 公网方案须加入TLS、凭证安全分发/过期与撤销、房间访问控制、限流、连接资源监控。不能仅将当前明文回环监听改为0.0.0.0就发布。
5. 定义逐命令日志提交/落盘失败停止发布、崩溃截断检查、凭证恢复、服务重启恢复的测试门槛。当前退出存档不是可靠恢复协议。
6. 明确Host离线的体验：首阶段可停止对局等待原服务恢复；Host迁移是独立工作，不能复制一套客户端规则或自行选另一个客户端权威。该体验含义需用户选择。

暂无外网可用性、完整比赛耗时/带宽、全天在线、服务重启恢复或所有卡联动的验收承诺。
