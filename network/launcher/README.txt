Goa2V1 完整试玩包 · 使用说明 · 2026年10月6日
====================================================

一、第一次打开：只找“开始游戏.exe”

1. 下载完整ZIP。右键压缩包 → 全部解压 → 选择一个新文件夹。
   不要在压缩软件内运行，不要只复制exe或快捷方式。
2. 打开解压出来的Goa2V1文件夹，双击“开始游戏.exe”。
3. 在统一入口选择：新手教程、本地对局、好友联机、使用说明。
4. 保留整个文件夹。player、host、launcher、content、easytier都是运行组件。

适用Windows 10/11 64位电脑；需要支持当前Unity客户端的显卡。
无需安装Unity、Blender、.NET SDK或EasyTier GUI。
若系统拦截、显示安全警告或启动报错，先保留提示并反馈；不要关闭安全软件。
Start-Multiplayer.cmd是保留的联机直达入口，通常不需要使用。

二、新手教程与本地对局

第一次玩建议先点“新手教程”。教程和普通对局共用同一个游戏客户端。
单人操控萨彼娜，另三席由固定陪练配合，不需要网络和好友。
十章包含镜头与移动、暗选与先攻、英雄攻击与水晶、防御与手牌条、
普通小兵、重型与推进、轮末兵战、卡牌升级、八级紫卡、自主练习。
五种卡牌数值在相应操作时讲解；目标8—10分钟，实际耗时待新手实测。
章节可以重试、收起、退出和继续。继续从所在章节起点开始，不恢复半步选择。
教程记录独立，不覆盖普通对局存档。当前没有教程配音。

“本地对局”为同一台电脑操控四席的热座模式，不是三名电脑AI陪你打。
可在游戏设置中进入独立教程，退出后恢复进入前的本地对局。
调试入口适合规则试验，不要把调试局当作正式联机房间。

三、四人联机：一人开房，三人各用自己的邀请

四人必须使用同一个新完整包。首次建议先让一位好友连通，再增加至四人。
不需要单独打开EasyTier，也不需要手填IP、网络密码、TOML或虚拟IP。

房主：
1. “开始游戏” → “好友联机” → “创建房间并进入”。
2. 等待“已连接”，游戏自动打开。保持联机窗口与电脑运行。
3. 回到联机窗口，依次选择好友一／二／三，导出三个不同的邀请文件。
4. 将每个.private.json文件私发给对应好友。一人一个，不能共用。

好友：
1. “开始游戏” → “好友联机” → “导入邀请并加入”。
2. 选择房主发给自己的邀请，等待自动连接、验证席位，游戏会自动打开。
3. 不要自己再创建房间；那会成为另一个房间。

Windows首次可能询问本包easytier-core.exe是否允许联网。
确认来自本包后可以允许；这不会安装虚拟网卡，也不需要关闭整个防火墙。
程序不改DNS和默认路由，不接管你已有的EasyTier或VPN。
免费公共节点可能不可用或连接较慢；目前仍需四台异地电脑真人整局验收。

四、进入对局后

先由房主客户端物理投币，其他人同步观看，决定选英雄的先手队伍。
选英雄顺序为先手队1人、另一队2人、先手队剩余1人。
同队两人可浏览英雄，先确认的合法选择先被接受；右侧可查看英雄简介。
双方队长部署英雄后，再投一次决定对局的初始决策币。
若硬币卡住出现重投入口，四人必须都同意；缺人时等待，不由房主代投票。
联机暗选每个人都须确认，四人全部确认后揭示。

左键英雄：普通浏览展开／收起技能环；正在选合法目标时优先选目标。
右键英雄：查看公开卡牌、等级、经验和永久加成。
右键技能并保持悬停：查看完整牌文，鼠标移开后关闭。
Enter：确认当前可确认的操作；绿色确认、深灰撤回按钮在屏幕右侧。
空格／右下状态窗：回到当前行动，重置本地预选并重新聚焦。
中键拖动：平移视野；滚轮缩放。拖动和缩放保留当前行动预选。
滚轮在左侧行动石板附近：上下浏览行动记录。
Q／E：旋转战场视角。
1—4：本地热座切换操控席位；联机只切换查看对象，不能替别人操作。
右上设置：音量、热键、记录、图鉴等；联机还有连接与重连状态。

注意：还没提交的目标可以撤回；已经确认的攻击、弃牌、前置效果等不能回滚。
右下状态窗告知谁在行动，轮到自己时会提示需要做什么。
头顶五色条表示卡牌状态，不是生命值；已出变暗、弃置变灰。
真实等级和金币扣费在轮末，圆中的1→3只是可升级预告。

五、退出、断线与保存

同一个仍在运行的房间：
- 只关闭游戏，可在联机窗口点“重新打开游戏”。
- 游戏内断线，先使用设置中的重连。
- 好友断开连接后，可“重新加入上次房间”，前提是房主未停止原房。
- 同一席位不要同时开两个连接。

结束整局：先关游戏，再点联机窗口“取消／停止本次连接”。
房主看到“房间已停止并验证存档”后再关联机窗口。
停止房间会断开全部好友。当前没有房主迁移、自动崩溃恢复，
也没有从已停止房间的存档继续开房的用户入口。
保存资料用于排错与后续恢复工作，不等于现在能断电后继续网络对局。
关闭统一入口本身不会替你停止另一个已经打开的联机窗口。

六、收到新版本后，四个人都要这样做

1. 结束旧对局并正常停止房间，关闭旧游戏和联机窗口。
2. 四个人下载同一个新完整ZIP，全部解压到新目录，不覆盖正在运行的旧包。
3. 从新目录的“开始游戏.exe”启动；不要误点仍指向旧目录的快捷方式。
4. 房主重新创建房间，导出三个新邀请并分别发给好友。
5. 先检查四人进入、投币选英雄、暗选确认、攻防弃牌、轮末升级和重连。
6. 验证可用后再整理旧目录，至少保留上一可用完整包作为回退。

源码上传不会自动更新朋友电脑。本包没有自动更新或游戏账号。
旧engine97包不能与本包engine98混用，旧房邀请也不能当作新房邀请。

给开发助手的更新提示词：
“请把目前通过验证的版本制作成同源完整包，包含游戏、教程、房主服务、
自动组网、统一入口及最新说明；检查解压后的启动、版本清单与SHA256，
不要包含个人邀请、密钥、日志或存档。更新桌面入口并给我好友下载地址。
保留上一可用包、main和engine34回退引用，说明哪些验收仍需真人完成。”

七、遇到问题

启动失败：确认已全部解压，保留原始报错或截图，不只发“打不开”。
连不上：看联机窗口停在哪一步，检查房主未关房、四人包相同、邀请各不相同。
等待连接给出结果后再取消重试；高级初始节点一般不用改。
没有Windows虚拟IP不代表失败，本包是用户态自动组网，以认证结果为准。
卡住：记录发生时间、版本、当时操作、是否切出切回，先保留日志。
如果出现规则疑问或显示不一致，记录卡牌名、英雄、回合和完整操作步骤。

反馈格式：
包版本：___；时间：___；房主或席位：___；刚做了：___；
预期：___；实际：___；能否重复：___；截图或短视频：___。

本地／教程日志：%LOCALAPPDATA%\Goa2V1\Logs
联机日志和个人邀请：%LOCALAPPDATA%\Goa2V1\Multiplayer
教程进度：%USERPROFILE%\AppData\LocalLow\Goa2V1\Goa2V1\tutorial
普通本地存档：上述LocalLow目录中的saves。
网络诊断目录含密钥、个人邀请和存档，不要整目录发到公开群或公开issue。
更新ZIP不会主动删除这些本机资料。

八、版本范围与第三方组件

本包集成六英雄108卡的现有规则实现、最新UI与模型、音效、十章教程、邀请联机。
属于完整可运行的试玩包，不代表美术、新手理解或四人异地整局均已验收。
部分美术仍待打磨、地图标志物扩展和已记录规则分歧仍保留。
单机与教程不依赖公共组网节点；联机免费节点的速度、可用性没有保证。

EasyTier 2.6.4 Goa2 userspace build是独立LGPL-3.0组件。
不附带或安装Npcap/Packet.dll及虚拟网卡驱动。
许可、修改源码、替换说明在easytier文件夹，完整依赖源码链接见其说明。
普通玩家只下载完整游戏ZIP，无需另下源码包或仓库的“Download ZIP”。
