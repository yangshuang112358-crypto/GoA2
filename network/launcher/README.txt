Goa2V1 四人联机试玩包（Windows x64）

1. 四人都完整解压同一个原始压缩包。双击 Start-Multiplayer.cmd 打开中文启动器。
   不需要 Unity、Python 或 .NET SDK。系统若阻止脚本，请保留提示并联系开发者，勿关闭系统安全策略。
2. 异地联机前，每人先独立安装/运行 EasyTier，使用相同的私人网络名称与密钥。
   官方下载：https://github.com/EasyTier/EasyTier/releases
   软件免费，但公共节点带宽和可用性不保证；实际中国境内延迟需你们测试。
3. 房主：刷新地址，选择 EasyTier 网卡的私有 IPv4，点击“创建房间”。
   普通 Wi-Fi/以太网地址用于同一局域网；127.0.0.1 只能本机测试。
   Windows 若询问网络访问，只允许房主服务在此次可信私人网络通信。
4. 分别选择席位 2、3、4，导出三个不同邀请文件，分别私发给对应好友。
   邀请含个人席位凭据；不要公开，不要把三个文件都发给同一位朋友。
5. 好友：点击“选择邀请文件并加入游戏”，打开自己的文件。
   一个邀请对应一个身份；重复打开同一邀请会替换该身份原先的连接。
6. 游戏内各自选英雄；队长部署。技能环选卡后必须分别确认，四人确认后揭示。
   1—4 只查看角色，不会切换你的身份；断线后在右上设置里重连。
7. 房主保留启动器及房主服务运行。关闭游戏窗口可再次点击“进入房主游戏”。
   “停止房间并保存”会断开所有人；此版还不能重新打开旧房继续对局。

连接失败：确认房主仍开着、四人 EasyTier 网络互通、邀请来自本次房间且游戏包相同。
TCP 可达检查只代表能联系到端口，不代表已经认证、直连或延迟足够低。
没有自动配置防火墙、没有公网大厅、没有短房间码、没有自动房主迁移。

运行数据存放在 %LOCALAPPDATA%\Goa2V1\Multiplayer，包括个人邀请、房间凭据、日志和存档。
只分发原始发行 zip；不要发送运行数据目录。游戏包不包含 EasyTier 或任何公共节点密钥。
目前工程验证与真人/异地验收区分记录，不能因本机四客户端通过就视为异地验收通过。
