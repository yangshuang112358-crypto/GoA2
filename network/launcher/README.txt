Goa2V1 四人邀请联机版 · 2026-10-03

所有人都使用本次完整压缩包。先“全部解压”，不要在压缩软件里直接启动。
双击最外层 Start-Multiplayer.cmd。不要直接打开 host 或 easytier 文件夹中的程序。
不需要另装 Unity、.NET SDK、EasyTier GUI；不需要输入 IP 或导入 TOML。

房主
1. 点击“创建房间并进入”，等待“房间已准备好”，游戏会自动打开。
2. 回到启动器，依次选择好友一/二/三，点击“导出这个好友的邀请”。
3. 将三个不同的 .private.json 文件分别私发给三位好友。一人一个，不要共用。
4. 保持启动器和电脑运行。可以关闭游戏后用“重新打开游戏”回到原席位。

好友
1. 解压与房主相同的游戏包，打开 Start-Multiplayer.cmd。
2. 点击“导入邀请并加入”，选择房主发给自己的 .private.json 文件。
3. 自动组网、验证席位后打开游戏。同一个仍在运行的房间，可以“重新加入上次房间”。

第一次运行时
Windows 可能弹出 easytier-core.exe 联网提示。确认它来自本游戏包后，点击“允许”。
这是允许游戏网络通信，不会安装虚拟网卡、修改系统 DNS、默认路由或关闭防火墙。
若不允许入站，仍可能通过公共节点中继连接，但直连和延迟不能保证。
启动器只管理自己启动的进程，不会退出已有 EasyTier GUI 或其他 VPN。

进入游戏后
四人各自选择英雄并部署；暗选阶段每个人需要确认。1–4 键只查看其他席位，不转移控制权。
Enter 确认，空格开关视野跟随。更多热键与重连入口在游戏右上角设置中。
断线先使用游戏设置中的重连；若网络进程已退出，关闭游戏，在启动器重新加入。

结束一局
先关闭自己的游戏。好友点“取消／停止本次连接”；房主用同一按钮停止并保存。
看到“房间已停止并验证存档”后再关启动器。当前不能从旧存档重开网络房间，不能自动更换房主。
房主新开房间后，必须重新导出三个邀请，旧邀请不会进入新房间。

版本更新
先结束旧房间、关闭旧客户端及启动器，再把新包解压到一个新文件夹。
给所有好友同一个新包，然后创建新房间并发送新邀请。不要混用新旧文件。
旧手动邀请、旧 EasyTier TOML 不能用于“导入邀请”；需要时使用“手动／局域网入口”。

连接失败
等待最多约 75 秒。检查房主未关房、四人版本相同、每人邀请对应不同席位。
可取消后重试。高级初始节点通常不用修改；要更换时由房主重新开房并发新邀请。
公共节点免费但速度和可用性没有保证。本机验证不能代替四台异地电脑的实测。
点击“打开本机诊断目录”保留资料；目录含私人邀请和存档，不要整目录公开上传。
本机资料在 %LOCALAPPDATA%\Goa2V1\Multiplayer，更新游戏包不会主动删除这些资料。

网络组件与许可
EasyTier 2.6.4 Goa2 userspace build 为独立 LGPL-3.0 组件，只保留本项目使用的 TCP/UDP 与用户态转发。
不分发或安装 Npcap/Packet.dll，不分发虚拟网卡驱动。许可、精确修改源代码、替换说明在 easytier 文件夹。
完整依赖源码包随同一 GitHub Release 单独提供；试玩者只需下载游戏包。
