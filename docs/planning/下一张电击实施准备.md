# 电击的下一步实施准备

接续引擎34，当前未改规则、未开放电击。先以content/canonical/cards.json核对wasp-01-电击，并单独建立正式合同和失败测试。

原子顺序：先选合法的相邻攻击目标；攻击前来源可选择至多一个相邻敌方英雄，排除攻击目标；该英雄若有手牌则本人弃一张；完成后对最初目标执行攻击、正常防御与后续流程。没有额外英雄或选择不执行此项，不应取消原本的攻击。空手只跳过弃牌，不击败。

关键实现风险：当前ChooseEffectTarget会写CardExecution.TargetUnitId。电击不能直接复用这个写入，否则额外弃牌英雄会覆盖原攻击目标。应为临时效果目标增加独立可序列化字段，或明确使用独立恢复结构；旧存档默认字段须按现有兼容策略处理，不能改写冻结文件。

可以复用引擎33的目标本人弃牌窗口、公开来源/私密具体牌、空手跳过，以及引擎34的范围筛选结构。新弃牌恢复点必须回到同一攻击程序的下一步；不得调用旧防御反制的EndCardExecution。等待弃牌时不能再次计算攻击，也不能允许再次选原攻击目标。

手工布局：从黄蜂整个攻击行动开始。一个相邻英雄作原攻击目标，另一相邻敌方英雄作弃牌分支；另放一名可移除敌方小兵作为原攻击目标分支。加载后记录说明“先选攻击目标→选另一英雄或跳过→目标本人弃牌→返回原攻击”。同时说明把额外英雄手牌清空时攻击仍继续。

最低联动回归：原目标与额外目标不混淆、原目标为小兵、额外目标空手、来源选择跳过、弃牌窗口保存恢复、私密牌不泄漏、错席位/重复命令、弃牌不会执行牌上的防御文字、后续近身还击与强制弃牌各自只执行一次。夏尔加萨反击及六大招仍未开放，必须将未来触发排队放在完整原行动结束之后，不能为了本牌先假造大招行为。

结束本轮工作时保留原生引擎34可执行包。额度不足以做完电击时，仅保留这份准备说明，不抬高实现状态或开启未验证的程序。
