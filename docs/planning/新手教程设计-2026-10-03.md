# 新手教程设计 · 2026-10-03

状态：内容与实现方案已准备，游戏内教程尚未制作。已有168个调试预设可提供场景素材，但调试按钮不能直接冒充新手教程。

## 玩家先学什么

建议分成可独立重试的小章，首课目标约8—12分钟，时长待新手实测。首课不教全部108张牌、六紫卡或全部升级。

| 章节 | 实际操作 | 判断学会的依据 |
|---|---|---|
| 0 进入游戏 | 选择本地练习；联机另有进房向导 | 能区分本地与联机，知道轮到谁，不把等待好友当卡死 |
| 1 看懂战场 | 缩放、中键、空格跟随；左/右键英雄、技能读牌 | 找到自己和指定小兵，打开读牌再返回；无需死记热键 |
| 2 一张牌的选择 | 五色手牌、先攻/主要/移动/防御/范围；出牌与弃牌状态 | 选牌、换选、取消、确认；知道联机需各自确认，紫卡不是第六张暗选牌 |
| 3 移动与返回 | 开行动环、预选移动、高亮格、返回改选、勾或Enter确认 | 一次取消不花行动，一次合法移动确实提交；不把路径内敌人当可穿过 |
| 4 攻击与防御 | 选一个合法小兵，再演示对英雄攻击、对方防御/不防御 | 知道先攻不等于攻击力；防御牌消耗手牌；技能环会切至响应者 |
| 5 小兵与团队 | 近/远/重差异、重型保护、当前交战区、队长决策 | 先移除保护者再按规则推进，区别击败小兵与任意时点自动推进 |
| 6 一轮与成长 | 四回合、回收、轮末兵战、经验/升级、同色替换 | 完成一次候选选择；到8级才学习紫卡拥有流程 |
| 7 胜负与联机 | 水晶生命、推进胜利、等待他人、断线状态 | 能读懂结果、知道房主须保持服务；完成一次引导结算 |

进阶另设：同先攻决策币与队长顺序、免疫、放置/推拉/移动差异、动态范围、中毒、反击与多层响应、紫卡改规则。未裁定Q-09/U-017不作为首课确定答案；用户解释加*的约定也保留。

## 第一章具体脚本

使用独立固定种子本地教程局，推荐先用布罗根的基础教学场景；具体牌以正式数据检查为准，不另造教学伤害公式。

1. 镜头全景，提示“目标是击败敌方水晶或推进战线，先练一次行动”；只显示一行当前任务。
2. 高亮自己的英雄，要求左键展开环；右键一个技能看完整描述，移开关闭。
3. 引导选一张普通牌；教学控制器让其他三席按脚本合法选牌并确认，不要求新手代操四个人。
4. 到本人完整行动起点，引导移动预选 → 返回 → 再次预选 → 确认。附近留一个无效格说明原因，但不强制点击它。
5. 下一局面从攻击者的完整行动起点开始。目标小兵有合法攻击路径；系统控制对手只执行固定合法分支。
6. 第二个场景攻击英雄，玩家实际选择目标并提交，才展开防御方环。引导防御，再看行动石板的二级节点和弃牌状态。
7. 结尾提示两个核心事实：“确认前可改选；已发生的前置效果不能撤回”“防御会减少本轮剩余选择”。开放自由练习、重试本章、下一章。

每步给清晰预期，失败提示说原因和下一步，不用只弹“非法命令”。教程文案不暴露源码、命令名、状态机术语。

## 实现方式

新增独立教程控制器与可版本化场景定义，持有章节ID、步骤ID、起始种子/存档、期望事件或谓词、提示锚点、允许操作和重试点。始终通过现有GameSession/Command接口提交，不能直接改血量、位置或行动计数来假装通过。

现有debug-positions/scenarios可复用生成起点，但新增预设必须加载到完整行动开始前。等待匹配的已接受事件才推进教学；不要根据“玩家点过按钮”判定规则完成，也不要用文本日志字符串作唯一判断。

高亮应绑定稳定的UI元素ID/单位ID/格坐标，适配窗口尺寸及视野缩放。遮罩只限制当前教学操作；退出、重试、读牌和镜头帮助始终可达。引导不应抢正在确认的目标或泄露联机暗选。

教程存档/完成进度独立于真实热座存档、联机邀请和权威房间数据。可从章节起点重来，后续版本场景不兼容时解释并重置本章，不修改真实对局。

## 验收与第一批范围

- 第一批只完成1—4章的基本读牌、选牌、移动与攻防链，不新增AI决策引擎；对手为固定合法脚本。
- 自动检查每章能够通过真实命令走完；非法分支不部分修改；重试/退出不污染真实存档；UI重排、不同分辨率仍能找到锚点。
- 邀请至少一名没看过项目的人，开发者不口头提示；记录停顿、误点和看不懂的词。完成率和耗时实测后再定目标。
- 交付一段连续首课录屏、章节文件和已知问题；教程测试通过不表示全部卡牌教学完成。
