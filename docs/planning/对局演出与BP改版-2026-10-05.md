## 已确认的规则边界

- 真实投币覆盖旧的“规则先定结果”约定：房主 Unity 客户端物理模拟，权威房间服务记录最终面，其余客户端只观看。不能各自模拟并裁定。服务端无 Unity 依赖；记录 tossId、结果、主持身份、投票及阶段，重连从快照恢复，不再次掷币。
- 异常重抛四个席位一致同意，缺人等待；不得房主代投票或超时强行重抛。投票绑定本次 tossId，旧投票不带入下一投。
- 经验充足提前显示“1 → 3”等预期等级，本轮真实等级仍为1；扣费与真实升级仍在轮末。预期等级按连续支付当前等级计算，最多8级，金币被转移后必须重新计算，不预扣。
- BP 先手由首次投币决定，按队伍1–2–1选人，同队尚未选人者先提交成功者占用英雄/名额；另一次投币用于正式对局决策币。非当前队只能查看介绍。命令必须服务端串行校验，不能只禁用 UI。
- 金币、助攻、等级等动画只表现核心已经确认的事件；动画物理不参与游戏数值计算。
- 升级候选只使用本人的投影；他人不得通过升级环/比较浮窗看到私有候选。8级紫卡保留流程。

- [ ] **F07 岩石精修。** 非中心岩块改为更自然的不规则连接岩石，维持中心对称、相邻连接、完整六边形底座与出生点可读性。中央两石补盘旋上升并形成/融合为圆盘的演出，顶部最终平整、竖边清楚、决策币无穿插。区分临时演出网格与稳定棋盘，动画不改阻挡/坐标；重连直接恢复稳定形态，不反复盘旋。

- [ ] **F09 武器握持与初始朝向。** 全部剑类核对“剑刃朝前后”的用户要求，用正面/侧面近景确认刃面与刃口朝向；避免只从俯视角猜测。远程兵手握弓的木制中段，弓弦朝身体后方；剑柄、盾柄、弓把与手掌必须接触，动作过程中不能漂浮。
- [ ] **F10 远程兵真实取箭/拉弓。** 一手从头顶向后探到背后箭筒→握箭取出→移到弓上搭弦；持弓手把弓送到身体前方并伸直，拉弦手后拉蓄势。箭与手/弦分别绑定到对应阶段，弦发生形变，不以整体举弓替代拉弓。结算后松弦、箭飞向目标并消失，再回到正常站姿。先确认骨架和握持坐标，再做分段动作/过渡，不能单靠上臂转动冒充整套动作。
- [ ] **F11 近战准备/攻击。** 举剑约45°，不抬成90°；保留前跨准备，出招为此前要求的下劈，命中后回位。检查肘部/肩部和剑尖轨迹，不穿身体或邻格单位。
- [ ] **F12 重型准备/攻击。** 胳膊向外顶，剑横在身前、剑尖略偏向自己；出招为横劈。免疫时先由贴地底盘展开八足站起，再举剑/盾；非免疫时直接准备。保留免疫/非免疫与举剑/盾组合，动作完成回到当前真实状态，不能固定回免疫姿态。
- [ ] **F13 举盾防御。** 盾移到身前，不在身体侧面悬着；前弓步降低身高，重心前移。覆盖近战/重型的不同骨架。此条覆盖此前不合适的姿态角度；重型用底盘/足支撑表现，不强做人的膝盖。
- [ ] **F14 朝向参与目标。** 提供攻击伤害加成的小兵朝向被攻击者；提供伤害减免的小兵朝向攻击者。预选目标改变时平滑转向，取消预选/结束攻击后恢复合适站姿；只旋转可视模型，不旋转英雄环/改变六边格坐标。预选时从当前行动英雄取得攻击方，正式防御时从攻击上下文取得；重复攻击、反击、攻击后位移/击败均保留当次演出快照。无有效目标时不指向世界原点。调试样例也必须提供明确目标。
