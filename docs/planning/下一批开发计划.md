# 下一批开发计划

BATCH-02仍在用户授权的约12小时内持续推进。基础战斗、代表牌反制、击败/复活、兵线、轮末升级循环、四边界面和本地程序包已有实际证据；本文件不再把它们列为尚未开始。当前21张牌开放，剩余87张及联网仍须继续开发。

1. 完成本批更长模拟、独立程序重放及小窗口交互复核。失败要区分规则断言、测试工具和环境；保留原失败证据。补充可直接打开的手工调试局面及测试入口。
2. 补齐主要移动代表牌：选择语义已明确的一张，合同覆盖移动预算、是否分段、零步结束、基础移动与后续牌文、快速移动替换、存档恢复。未实现后续文字时不能只开放数值移动。
3. 接入移动/放置/推动/换位各自的合法查询与来源。要求先完成整段启动条件的冲锋攻击应预检合法路线和终点敌人；普通移动不能默认拥有同样预检约束。艾瑞恩出生点放置先等待U-015/016。
4. 分批增加回合/本轮效果、替换击败、卡牌取回和触发队列，每批以具体代表牌说明触发时点、操作者、空资源、重复与到期。多目标顺序不能用同时修改数组替代逐个选择和事件。
5. 开始NET-01的本机四身份协议切片：固定总四席，实际认证身份进入GameSession，分别接收私有投影；覆盖重复、过期、断开和重连后的待选择恢复。部署拓扑与账号接入另写ADR，不能把热座切换当成联网身份认证。
6. 在代表牌和网络切片之间持续增加逐卡覆盖；全卡合同、特殊联动、紫卡、完整四人长局及发布门槛通过后，再进入正式发布。当前压缩包用于本地测试，后续发布仍须独立验收。

进入具体合同才处理阻塞该行为的待确认问题。正式数据的0、null、感叹号和次要行动存在标记必须保留区别，不凭界面推断改数据。不重复搭建环境或复制第二套规则核心。

本批已询问而未收到答复的U-013/014/015/016只暂停对应牌的相关分支；不能把等待时间当作用户认可。后续状态以content/status/cards.json和实际报告为准，未写完的目标设计不升为已实现。
