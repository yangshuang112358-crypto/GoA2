# 战场操作迁移

本批基线 de9a57f，日常分支 experiment/ai-level-20260920。覆盖旧“右侧迁移尚未实施”状态；最终验证结果另见验收记录。不修改 main、永久 engine34 回退引用或卡牌裁定。

## 操作

- 当前英雄的行动圆环提供主要行动、次要移动、快速移动、放弃。选择后进入本地预选，右侧 ↶ 返回行动选择。无合法目标的直接攻击保持不可用。
- 普通攻击、无前置的主要移动/放置由核心给出只读预览；地图高亮合法对象，点目标或格后出现 ✓。Enter 与勾使用同一确认入口。
- 需要先弃牌、紫卡移动、紫卡迫弃或立即执行效果的主要行动，先确认启动。启动后，↶ 只改选当前未确认步骤，不允许改回行动类型、返还已支付牌或撤回已移动位置。
- 次要/快速移动普通落点为本地预选；有紫卡前置时先确认启动，按核心继续前置与落点选择。
- 防御、弃牌、取回、交换、弃牌堆反击使用英雄卡牌圆环。取回/反击模式把弃牌翻至可识别正面，实际牌区仍由规则决定。
- 多步目标、可选继续/停止、卡牌分支、金币数量使用情境圆环；地图选择时收起，右侧“步骤选项”可展开。候选超过六项分页，不能把“跳过”当作撤销已提交效果。
- 地图确认覆盖部署、复活、小兵移除、回归、出生冲突；队长/本人权限继续取自当前投影。轮末入口在战场，升级保留两列三行和紫卡领取流程，确认及永久被动来源位于升级浮层。
- 操作说明和攻防来源在底部紧凑提示/详情中；图鉴、战报、规则效果列表、存读档、新对局、调试、热键和联机恢复仍在设置。

## 接口与不可回退边界

`GameView.PrimaryPreview` 仅对当前行动者投影。`GameSession` 在独立快照中运行既有 BeginPrimary；只有开启后的差异局限于执行帧、待选择、阶段和明确允许的提示事件，且没有 BeforeAction 时，才发布攻击/移动/放置预览。不在 UI 重写卡牌合法性。每 revision 缓存一次，返回集合仍为独立副本。

新增命令追加在枚举尾部：CommitPrimaryAttack、CommitPrimaryMove、CommitPrimaryPlacement。会话重新计算预览，再把 BeginPrimary 与首次目标确认放在同一 draft 中执行。任一步不合法则整体拒绝；成功只增加一次 revision、receipt 和 AcceptedCommand。重放使用相同入口，重复命令沿用已有幂等处理。旧命令和 engine97 卡牌语义保持不变，旧存档不迁移。

网络 UiIntent 与 Wire 白名单同步扩展。预选/返回没有 RPC；断线或待回执时战场入口统一禁用。源码与服务端应同批构建；不得只更新 Player 后把旧服务端称为本批验收版本。

## 展示组织

GameScreen.WorldDecisions 负责入口与世界坐标定位；既有具体 Pending 的说明/合法候选/提交接线仍复用 Combat、Battlefield、Upgrades 的构建函数。设置中移除对应决策按钮。卡牌圆环继续负责私有预选与公开弃牌演出，行动石板继续使用接受后的公开事件，不受本地浏览影响。

当前圆环使用程序金属描边和按钮缩放，并非 Blender 最终美术资产。高质量模型/符文替换仍保留原验收清单。
