# R2B02 通用标记精修

用户指出 R2B01 单件的沙漏太宽、鞋子辨识不清，且二者没有像其他类别一样的内部标记。本批将两者重做，并完成可复用的通用石标与流程徽记模型库。全部图片及视频由保存的 Blender 网格实渲，未以概念图替代模型。

## 本次具体修订

- 靴子采用侧面轮廓：高靴筒、收窄脚踝、向前鞋尖、鞋底、独立鞋跟；内部增加鞋带、扣件及鞋底层次的金属靴徽记。
- 沙漏轮廓宽高比约0.72，腰部收窄；内部独立制作上下支架、双腔玻璃、沙堆和细砂流。原单件遗漏统一内部徽记的问题已修正。
- 七种通用标记均为石座＋中间立体徽记＋真实凹刻数字的统一结构。无数值的技能采用中央徽记，不为布局刻一个0。
- 数字槽低于石面，原值为暗色槽底，加减分别填绿／红魔力；石材仍保留牌色。双位数12/13及负数−2另适配窄沙漏下半部，保留完整石边。
- 视觉复核另将盾牌字形2略上移并缩小，给宽底笔与盾牌斜边留出石材；七标记总览扩大取景以完整显示底部“先攻”标签。
- 范围是同心圆；攻击距离是带外露矛头的准星长矛。响应徽记的弧和箭头做成连续实体，避免看似断开。
- 完整回旋镖复制场景替换了全部五块石标，维持原4／3／3／3／9及中文凹刻名字。旧源保留以便比较。

## 通用覆盖与接线约束

| 模型语义 | 使用位置或用途 | 默认材质与注意点 |
| --- | --- | --- |
| boot | 移动主要行动或次要移动 | 主要行动牌色；次要移动灰石 |
| shield | 防御主要行动或次要防御 | 主要行动牌色；次要防御灰石 |
| sword | 攻击／基础攻击主要行动 | 牌色 |
| skill | 技能／基础技能主要行动 | 牌色；零值隐藏 |
| hourglass | 先攻 | 灰石；紫卡的占位0不代表正常先攻排序 |
| range | 技能范围 | 跟随牌色，同心圆 |
| distance | 攻击距离 | 跟随牌色，准星长矛；代码字段可能名为远程 |
| discard / recover | 弃置／取回流程与记录 | 无额外数值槽 |
| reaction | 响应／额外行动记录 | 无额外数值槽，不是普通撤回按钮 |
| quickmove | 快速移动行动入口 | 无额外数值槽，不给卡面新增快速移动数值 |
| ultimate | 紫卡触发或状态 | 紫石与紫晶，无额外数值槽 |

依据正式108张数据及现有 `SkillWheel`、`SkillDiscArtwork`、`ActionCardGlyph`、`CardDisplay` 核对。范围／距离必须读取真实类别，不能仅凭主要行动是攻击还是技能推断；牌内推动、移动等文本数值不新增为固定角标。当前10张带!的条件防御继续按用户约定显示∞，并保留具体条件文案；∞不代表无条件免疫。!仅保留兼容字形，不改正式规则或卡牌数据。

“通用覆盖”指上述数值与流程类别，不表示108张技能专属图标已量产，也不包括中毒、免疫等全部状态的专属美术。

## 验证与交付边界

四项结构检查及36块凹刻数值、1068个字形取样射线通过。既检查石面没有挡住字槽，也检查字槽下面实际存在石材，避免数字浮在轮廓外；这项检查发现并修正了12/13与沙漏细腰的冲突。七种语义均有独立内部徽记。报告见 [几何验证](samples/r2b02-badges-20261009/geometry-validation.json)。

## 重建

在仓库根目录运行。手工修改的模型请先另存；只重建生成器产物时才加 `--replace-generated`。

```powershell
$badgeBlender = "$env:USERPROFILE/Applications/Blender/blender-4.5.14-windows-x64/blender.exe"
& $badgeBlender --background --factory-startup --disable-autoexec --python-exit-code 1 --python tools/art/build_r2b02_badge_library.py -- --root . --out artifacts/r2b02-badges/final --no-render
& $badgeBlender --background --factory-startup --disable-autoexec art/production/samples/R2B02-Badges/R2B02_SemanticBadges.blend --python-exit-code 1 --python tools/art/render_r2b02_badge_library.py -- --out artifacts/r2b02-badges/final --stills --video
python tools/art/package_r2b02_badge_library.py --root .
```
