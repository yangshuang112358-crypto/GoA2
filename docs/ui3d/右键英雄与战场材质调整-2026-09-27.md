# 右键英雄与战场材质调整

基线5f9f6c4；用户本轮要求覆盖上一版hover、弃牌黑色及悬浮决策币设计。

- 英雄信息只由右键打开，关闭按钮、Esc或再次右键同英雄关闭。移出不关闭。中键拖动保留；空白处右键仍可拖动。
- 统一金银红绿蓝紫顺序，两列、满级三行；本人显示真实手牌，对手只显示公开牌，未公开槽位不透露牌名和描述。牌底显示本轮出牌回合或当前弃牌状态，不分回合标题。取消队伍、席位、队长、隐藏提示与术语按钮。永久加成从右侧迁入英雄信息。
- 选牌/出牌按原颜色变暗，弃牌改为灰色。Selected变暗仅用于本人，不能通过他人头顶泄露暗选颜色。英雄全名无底色；等级数字清除默认控件边距。
- 决策币参考中央(0,0)/(0,1)两块六角地形共同边长（.965世界单位），落定后贴地形顶端；只有投掷/翻面过程中离地。加厚倒角、刻边、镶座、宝石与独立高光材质；不引入物理权威随机。
- PrimaryImmediatelySkips是只读展示查询：无目标且第一步就是选择攻击目标的行动置灰。前置移动、弃牌增程、有效紫卡行动前流程仍保持可开始。CanBeginPrimary与规则命令本身不变，因此旧回放不改写。原通用预览/撤回待办仍未实施。

本批不依赖新软件或更高推理档位；程序化材质可迭代，但不宣称已达到商业游戏成品美术。验证结果在完成后另记，不以此说明代替运行证据。

水晶问题根因：上一版额外固定装饰模型叠在弧线中点生命水晶处。已去掉重复装饰模型，保留相同大小、差频漂浮的生命水晶，皇冠目的地锚点保留。
