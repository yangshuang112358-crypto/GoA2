# 设置按钮：立体石板与齿轮动效

基线0e49e1e；本轮只调整右上设置按钮，原抽屉内容、热键和规则保持原语义。

外观采用切角石板、暗色厚侧壁、旧铜斜面包边、固定石面颗粒/裂纹、铆钉和齿轮浮雕。保留“设置”文字便于辨识。104×72固定点击区域，绘制部分透视倾斜；悬停约2.6像素抬起、轻微放大和暖色亮边，随鼠标最多约9/11度倾斜；齿轮悬停偏转，打开时偏转18度。按下压入约4像素，松开弹簧回弹；打开状态保留轻微压入与暖色高光。

使用UI Toolkit程序绘制与三维投影，不新增材质贴图文件，不安装软件，不迁移渲染管线，也不使用规则随机数。动效状态在GameScreen刷新之间保留，标签位置同步，避免打开抽屉时回弹被界面重建截断。静止时不持续请求重绘。
