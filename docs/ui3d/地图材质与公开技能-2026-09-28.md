# 地图材质、设置音效与公开技能 · 2026-09-28

## 本次用户要求与覆盖关系

用户改为所有英雄已装备技能的名称、数值、描述均公开；只保密选牌阶段正在选择哪张牌。这覆盖先前“他人未公开手牌显示问号”的展示要求。仍不可操控他人；左键合法目标优先。暗选的选中、取消、私有弃牌预选不向别人展示。

核心投影新增 `PlayerView.PublicCards`：装备牌实例复制后对外提供，Selected 投影为 InHand；揭示之后保留真实公开区及已出回合。OwnCards 仍仅本人可见。技能轮和右键英雄查看均使用本人投影，不读取他人会话或完整存档。该字段是新增展示契约，未变更命令、存档或 engine97 的规则。未来联机分支接入时须保留此字段及遮蔽逻辑，不能直接发送原始 Cards。

## 地图

- 地形障碍：确定性生成的分层切面岩石、碎石和表面裂纹；几何保留在自身格内，不增加碰撞或改变合法路径。
- topGrass / bottomGrass：短草叶片、地表苔绿色纹理与轻微风动。其余地面为土地，巷道稍浅；仍保留棋盘格界线。
- 英雄出生点为王冠，近战小兵为交叉双剑、远程为弓箭、重型为盾牌。双圆与十二刻度组成符文，红蓝按出生点所属队伍着色；不是当前占据单位的阵营。
- 生命水晶仍一颗对应一点生命，不加入冒充生命的额外大水晶。切面、水晶高光与缓慢旋转叠加原有各自浮动频率；碎裂和皇冠沿用规则事件驱动。
- 美术属于程序生成的风格化第一版，没有使用外部模型；尚不等于 LOL 的手工模型、绘制贴图、烘焙光照和完整粒子资产质量。

## 设置声音

`SettingsAudio` 由 GameScreen 的 GameObject 持有，避免 Render 重建按钮时切断声音。进入、离开、开启分别为三段原创的短石质摩擦、铜质轻响、低频扣合音。资源在 `Resources/UI3D/Audio`，通过 `tools/ui3d/generate-settings-audio.py` 可重复生成，不包含炉石提取音频。声音为 2D UI 音效，不随镜头远近改变；设置关闭使用离开声。启用 Unity 内置 Audio 模块。

## 角标的差距与本次增强

旧版只有单层 Painter2D 线条与底牌，缺少雕刻图标、包边厚度、阴影、贴图及灯光，这才是简陋的主要原因，并非运行失败。本次加入金属切角、多层明暗、肩部羽片、实心浮雕符号、数字描边，并随按钮轻微位移倾斜。仍是 UI Toolkit 程序绘制的 2.5D 外观；如果继续追求参考图的精度，下一步应制作统一的高分辨率图集或独立小模型，以及技能插画，而不是只继续堆叠轮廓线。当前使用技能名称占位的约定不变。

## 录屏

`tools/ui3d/record-terrain-demo.ps1` 使用同一对局连续移动镜头和操作界面，临时安装编辑器录制代码，退出后移除；不改正式 Player。需要本地 FFmpeg 参数或先前安装到 artifacts 的副本。图像来自真实 Unity GameView，脚本输入，并非真实 OS 键鼠测试。

录屏音轨按真实 SettingsAudio.Played 事件时间混入游戏的三份原始 WAV，乘游戏 .7 音量；不录桌面麦克风，不代表验证了设备扬声器。视频为 H264/AAC MP4，手机可浏览。最终证据见相应 verification 文档。
