# 技能圆环与表现规范

用户所称“技能”在UI中泛指五张普通卡牌，不等于规则的技能行动。基线be09bd6。合法目标选择优先于左键打开英雄圆环（本轮用户明确答复）。2026-09-28最新要求覆盖旧隐藏牌约定：他人装备技能名称、数值和牌文公开，只隐藏其当前暗选结果；只对本人开放操作。

本轮迁移选牌/取消/确认与强制弃牌、可选弃牌、弃牌保护小兵。迁移后对应底部手牌入口及右侧选项撤去，保留说明。底部手牌栏只在防御、换牌与升级需要时出现；普通看牌使用右键英雄/技能。防御、攻击、移动、取回、换牌、升级等原操作入口保留，不能冒称已全部迁移。普通查看左键开关、切换英雄并聚焦；右键技能看详情。右键英雄仍看两列完整公开信息。

CancelCardSelection作为独立追加命令，不能修改旧SelectCard同ID点击的语义；确认后和离开选牌阶段拒绝取消；私有事件。引擎97已存在命令语义不变，新命令需要将来网络端采用相同核心版本。QuickSelection仍然四人选完立即揭示。

表现层状态独立于GameState：预选弃牌/确认提示/圆环开关不发规则命令。收到公开DiscardColorShown才排队演出展开→翻面→收起；新建展示状态读取快照不重播旧事件；读回较早版本清理待播事件，回读更早版本清理未来动画。当前Player无已集成联网适配器，因此本轮只交付该公开事件消费边界和本机验证，不宣称远端同步完成。

五色圈保留卡牌身份；本轮已使用压下且变暗，弃牌翻至金属凹叉背面，轮末回手后复原。可复用透视投影按钮组件负责倾斜、高光、翻面和压下；目前用名称占位，后续图标替换不改规则。附属数值（最新）：左上次要移动、右上次要防御、左下主要行动、右下距离/范围；先攻沙漏居中放在按钮正下方。数值居中悬浮于各自图标上方，取消右上双图标缩小堆叠。数值显示总值，净增绿、净减红、原值白，缺失次要行动不显示。

决策币开局保留多周投掷，后续换面只翻半圈，约0.32秒；相机抵达等待与硬币翻转时长独立。

## 后续美术沟通方式

最有效的输入是一张标注尺寸/位置的截图，加上默认、悬停、按下、弃置四种状态，以及3—5秒动效参考。先验收一个技能按钮样板，再扩到全部界面。明确哪些是必须相似的结构、哪些允许重新设计；用“抬高/倾斜方向/翻转时长/回弹幅度”等描述，胜过只说“更像炉石”。

增强效果优先补图标、金属/磨损贴图、短音效、动画曲线与局部发光。当前可在已有管线用自定义材质及Particle System；VFX Graph依赖URP/HDRP，不能当作无需评估的一键升级。依据Unity6.3官方对比：https://docs.unity3d.com/6000.3/Documentation/Manual/ChoosingYourParticleSystem.html 。本轮没有安装新软件或迁移渲染管线，商业级雕饰与粒子仍需单独美术精修。

圆环在实际战场视口内缩放与限位；极小战场会缩小按钮。弃牌打开和公开演出各触发一次聚焦，普通手动开环也聚焦，不切换操控身份。角色在结算中离场时使用最后公开位置播放弃牌。合法目标点击优先，取消/预选不能向对方投影泄露。

可复用的美术描述示例：
“这次只改一个技能按钮。布局用截图A，金属边框用截图B，悬停参考视频第3—6秒。按钮直径约110像素，悬停抬升6像素、倾斜不超过8度，按下0.12秒、翻面0.3秒。先给一个按钮的默认/悬停/按下/弃置四态，再应用到全体。参考图只参考边框材质，不照搬其他文字和布局。”这些参数是沟通示例，不是当前全部实装参数。
