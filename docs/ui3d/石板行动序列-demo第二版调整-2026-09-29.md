# 石板行动序列 Demo 第二版

依据用户本轮五项要求，覆盖旧草图中“每张石板都有凹槽”“组币预定红蓝面”等表现方案。当前只修改独立浏览器demo，不接Unity、规则或网络。

1. 原回合四张主卡才有上下凹槽。防御/弃牌等子卡、结算后新增的一级反击卡均为直边。
2. 只在先攻相同且均未开始行动的相邻主卡之间放置组币。使用中性金属/魔法刻纹，触碰或点击后随机轴向旋转并减速。它不是规则决策币的红蓝状态投影，不修改队长选择或规则队列。
3. 同先攻未行动组间距14，普通主卡间距54；子卡间距13，保留父子缩进。均为1600×1000设计坐标。
4. 主卡开始行动即脱离分组，所有与它连接的组币消失，两侧不再保持紧邻。未行动成员重新形成符合条件的相邻关系；已完成牌不会重新加入。换位期间组币暂隐，避免跨卡错位。
5. 原创程序音效采用轮盘加减速卡齿、低频机械摩擦及落定声，参考匹配轮盘听感；不是炉石原声。鼠标旋币、换位、落板与响应插入使用相应反馈。可开关音效。

## 边界

- 三/四人并列：每对符合条件的相邻主卡之间一枚币。队长确认后，开始执行者脱组，其余仍紧邻。
- 被响应打断的主卡已开始行动，不恢复未行动组；响应卡和额外反击均不生成组币。
- 中毒重排仍只动未行动区；完成/当前节点固定。凹槽是否显示与卡牌来源身份相关，不与层级等同。
- 此次改变的是行动栏组币外观，战场中央决定红蓝先后的规则决策币保持原样。规则预排顺序仍由原机制提供；随机转动不参与随机裁定。
- 原有布局压力场景/注入中毒场景继续只证明UI行为，不称为合法规则对局。
