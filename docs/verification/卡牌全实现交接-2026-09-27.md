# 六英雄卡牌实现交接

当前源码为实验引擎97，108/108张具有实现登记；全量2196/2196项自动回归通过；最终发行证据见本文件“最终验收”及card-batch-engine97.json。实现登记不等于所有规则分歧已解决，也不等于联网成品验收。

## 本次补齐

- engine95 石化：两格、最近且含所有并列敌英雄。
- engine96 石化之眼：三格、最近且含所有并列敌英雄。
- engine97 石化凝视：三格、全部敌英雄。

三牌统一保留英雄身份，提供免疫、禁移及地形阻挡；允许非移动行动和紫卡能力。D-061规定最近模式先计算全部最近英雄，再过滤已有免疫，不改选较远者。D-062规定移动起步合法就完成本次移动，再按最终位置重算；下一段移动重新检查。自己的放置技能仍可使用，其他人的位移须通过免疫检查。普通持续效果在来源牌取回、来源被击败及回合结束时取消。

规则入口为core/com.goa2.core/Runtime/Rules/PetrificationRules.cs；UI读取PlayerView.IsPetrified，不计算规则。ActiveEffect.BaseRadius保存基础技能范围，动态加当前RangeBonus。默认零字段在旧档省略；既有引擎存档保持版本行为及原始重放。虎爪紫卡的免疫条件已包括石化提供的免疫，但前置移动仍受石化禁移。

## 实施与验证范围

每张牌单独测试、构建、保存真实待选择窗口、提交并推送。三牌专项共36项，覆盖完整命令流程、最近/全范围差异、并列、距离/被动、免疫、移动、非移动技能、地形穿越、来源取消、旧档和非法命令原子性。合成局面用于隔离路径与紫卡条件；Editor场景用于实际命令、逐步存档重放。两类证据分别保留，不把合成局面说成玩家手工操作。

本批没有重新执行实际Player窗口的图形、OS输入和四客户端联机验收。场景及Windows构建通过不能替代这些验收。

## 本地操作

在Goa2V1根目录PowerShell执行：

```powershell
./tools/run-player.ps1
./tools/open-debug-position.ps1 -List
./tools/open-debug-position.ps1 -Name petrify-cast
./tools/open-debug-position.ps1 -Name petrify-eye-cast
./tools/open-debug-position.ps1 -Name petrify-gaze-cast
```

后面三个命令任选其一；先关闭已打开的受跟踪Player窗口。也可从游戏调试区选同名场景。场景加载到施法前或当前英雄完整行动前，最近记录显示操作方法及分支。placement场景从阿连行动前开始，手动执行潮水；合法示例落点为(1,-8)，(4,-9)因空出生点限制不可选。dynamic场景用于观察来源移动后的解除；石化凝视需把来源移出范围，不能仅改变最近排序。

```powershell
./tools/test-unity.ps1 -Filter 'Goa2.Tests.PetrificationTests;Goa2.Tests.PetrificationEyeTests;Goa2.Tests.PetrificationGazeTests' -ReportName stone-local
./tools/test-unity.ps1 -Assemblies 'Goa2.Core.Tests;Goa2.Presentation.Tests;Goa2.UI3D.Tests' -ReportName all-local
```

Unity测试/构建按同一项目串行执行。可执行命令及效果另见artifacts/运行命令与效果说明.txt，位于artifacts/player文件夹外。若本机应用控制阻止Player运行，保留原错误；Editor回放可使用tools/run-editor-scenarios.ps1，不把Editor结果冒充Player结果。
