# 行动石板集成验收

已集成到日常分支的Unity项目，Windows Player和服务端已构建。不是独立浏览器demo。本轮不改变engine97、卡牌程序、内容哈希或存档格式。详细设计见[接入说明](../ui3d/行动石板项目接入-2026-09-29.md)。

## 已实现

- 完整正式牌面，包括项目中的裁定括注/关键词着色、主次行动及距离数值、被动加减值、升级被动。108张牌均使用实际卡库，不用demo摘要。
- 无统一窗口/滚动条的石板，原四主卡才有凹槽，同先攻未行动相邻组币，随机旋币不影响规则。不同先攻/开始行动恢复宽间距。
- 权威事件形成防御/弃牌/紫卡/取回卡的父子关系；反击真正选牌后新增一级；主卡结算记录与场景动态插入、换位相连。
- 队长直接点击合法候选石板，提交原ChooseInitiative；设置栏旧选择按钮移除。暗选及本地预选不生成公开节点。
- 左侧滚轮浏览，战场仍缩放；普通Render保留浏览，开始下一主行动重置浏览并置顶，读档/重连不重播历史。
- 音效缩短为0.07/0.13/0.18/0.22秒的原创机械声。

完整牌面比旧摘要更高，需要滚动阅读整条序列；每张牌自身不裁掉文字。仍为程序石材美术，用户视觉/声音验收见清单G组。

## 本地体验

在Goa2V1目录运行：

```powershell
./tools/run-player.ps1
```

或双击 `artifacts/player/Goa2V1.exe`。设置→调试→自动选英雄与出生→四人快速选牌。卡牌揭示后出现石板，在左侧滚轮浏览。队长的同先攻候选可以直接点击。其余行动仍通过原技能环/设置中的行动栏进行。

多人本机试用仍为 `./network/start-room.ps1`。请用本次新Player与重新启动的同版服务端；旧服务端进程不会因磁盘文件更新自动升级。普通联机仍需四位分别确认暗选，不用本地快速选牌模式。
