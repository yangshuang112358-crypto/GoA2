# 地形贴格与连续石墙

用户新要求：岩石底部与格子重合；相邻岩石组成整体石块/石墙；顶部可有随机起伏但高差不能影响观感。此要求覆盖旧岩石底部明显内收、上部较大随机偏移的造型。

## 实施

- 源码与资源提交 `167675c`。普通岩石底边采用地图六边形的原始外轮廓，底座半径为1；顶部仅轻微内收倒角，屋面起伏约墙高的10%以内。
- 相邻格共用顶部边缘，删除内部墙面并焊接重合点，形成连续石墙。仍保持以棋盘中心为轴的180度对称。
- 修正Blender导出到Unity的平面朝向。旧资产即使整体中心对称，实际格子仍可能错位；现在以Unity导入后的世界坐标逐角核对，不只比较包围盒。
- 中央两格新增贴合双六边形的连续低底座，上方原盘旋合拢与平整决策币圆台保留。规则中的障碍格、路径与地形高度规则没有改变。
- Blender源 `art/terrain/Atlantis_Connected_Rocks.blend`，生成器 `tools/art/build_battlefield_rocks.py`；程序备用石墙同步收小起伏、取消底部内收。用户的 `Workbench.blend` 未修改。

## 验证

1600×1000 Unity Editor真实渲染：`artifacts/ui3d/audit-1600x1000-20261005-215238/report.json`，10项通过。新增重点：

- 所有外侧底边角点与地图标准格点误差小于1毫米。
- 普通石墙屋面最大高差小于0.12个世界单位。
- 地面接触处以上没有开裂的网格接缝。
- 中心对称、圆台中心及16个周边采样点平整、出生符文底板及规则存档不变。
