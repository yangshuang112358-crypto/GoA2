# 免费四人启动器验收 · 2026-09-29

## 已实现

基线0526c55已确认推送。Windows x64外部启动器：枚举本机私有地址、创建房间并进入席位1、分别导出席位2/3/4邀请、选择邀请加入、连接/版本检查、重开房主客户端、停止并验证导出存档。四人仍分别确认选牌。

`tools/package-multiplayer.ps1`先检查Player与源码一致，再使用独立win-x64锁文件发布自带.NET 10运行时的服务，最后打包。好友不需要Unity/Python/SDK；Python仅为开发验收工具。包包含364个受校验文件（不含包清单自身），UnityPlayer为158个payload文件，引擎97。未改既有Player源码；不虚报重新构建Unity。

正式内容沿用manifest加四份canonical数据。发行目录只取构建白名单；邀请、运行日志及存档保存在用户数据目录，原始发行zip不包含这些信息。使用者应分发原始zip。

## 失败与修复

1. 首次发布带RID时沿用普通锁文件产生NU1004；新增独立`packages.win-x64.lock.json`，原普通锁文件不改，之后locked publish通过，未升级Newtonsoft依赖。
2. 首次脚本验收发现PowerShell数组`.Address`与内建成员冲突，改为显式逐项取属性；重新验收通过。
3. 服务已正常保存但PowerShell 5.1丢失Process退出码；启动时保留进程句柄，重新验收通过。没有忽略存档检查来掩盖错误。
4. OS自动化最初缺psutil，改用系统进程查询；两次录入失败分别因Alt激活菜单及Unity新窗口抢前台。修正自动化聚焦与等待后4项通过，产品未因此放宽确认步骤。失败截图仅本地保存，不当作通过证据。
