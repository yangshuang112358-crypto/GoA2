# 紧凑行动石板验收

用户确认：右侧操作迁移方案采纳；左侧仅采用石板主题，尺寸由实现决定，平时仅头像、技能图标、技能名、数值图标及数值，悬停读完整卡牌。本批实施左侧；行动圆环、地图勾和返回箭头尚未实施，不能说右侧已完成迁移。

## 实现

- 轨道宽随屏幕在304—344像素之间；1600宽屏从约496减至344，约减少31%。石板高136像素，正常间距36、同先攻16、响应12，嵌套每层16像素，最多缩进三层但完整父子关系继续保留。
- 卡面只保留六种英雄头像、对应主要行动的技能图形、名字和图标数字；没有规则描述、身份段落、升级被动段落或结果段落。队伍细线、卡色边缘、响应用途小图标保留用于辨识。
- 先攻、主要数值、次要移动/防御、范围/远程距离沿用本人投影的有效加成；正增绿、负增红，正常白；抵挡为∞，无项目不预留占位，零值技能不显示0徽记。
- 悬停180毫秒后旁边出现完整官方数据牌文、用户星号裁定说明和执行记录。移开、滚轮浏览、重绘或卸载时隐藏；详情不拦截点击。普通态大小不因hover改变，不推挤后续石板。
- 原四主卡凹槽、同先攻未行动组币、实际选择后脱组、响应真实提交后插入、反击额外一级及下一主卡置顶继续保留。
- ActionCardGlyph 是程序绘制的六种头像和行动类别图标，不是官方人物插画，也不是108张各自独立技能美术。后续可替换该显示组件，规则和卡牌数据不依赖其图形。
