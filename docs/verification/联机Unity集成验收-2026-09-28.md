# 联机Unity集成验收 · 2026-09-28

结论：engine97与当前UI已集成，可以开始本机四窗口用户验收。私网IPv4入口已增加，尚无两台电脑的实测；公网接入、旧房间重开/服务器崩溃恢复尚未完成，不宣称正式线上发行。

## 实现

- 合并网络已提交交接6f29b90，日常集成分支保留原卡牌及GameScreen接线；没有覆盖main或永久engine34回退引用。
- `GameScreen.Network.cs`捕获Unity线程同步上下文，按本人GameView绘制；网络模式不创建GameSession。数字键只看英雄，无法变更认证席位。
- `UiIntent`只发送该命令适用的字段，服务端新增CancelCardSelection白名单；其余候选与规则全部由核心裁定。网络模式四人显式确认。
- 初次连接比较本地核心/内容版本与房间能力；断线禁用地图、技能环、升级、防御及确认。未收到结果保留原ID，重连后明确重试；迟到结果不使状态倒退。
- 本地预选不联网，重连清空；公开弃牌事件驱动其他玩家演出。对方技能名称公开，暗选结果与私人候选仍隐藏。
- 本机/私网IPv4开房、加入、正常关房并验证存档脚本。包校验新增网络客户端源码输入，避免漏验包源。
