## 本机验收

1. 桌面Goa2V1 → **08-UI与模型验收**。
2. 右上设置→调试→“新建 BP / 两次真实投币演示”。四席本地用1—4或BP右侧席位按钮切换。按1–2–1选人；双方队长部署后第二次投币进入暗选。
3. 调试→“新建卡边局面 / 四人投票重抛”。切四个席位分别同意；第四票才重抛。
4. 调试→“新建战斗动作 / 击杀金币演示局面”。当前为萨彼娜；设置中把基础攻击设为9，攻击地图上的黄蜂。切2号席位黄蜂选择低防御或不防御；看弃牌收环、小兵动作、金币飞向萨彼娜/布罗根与经验到达。
5. 调试→升级环样例，加载9/6/3/紫卡局面；点候选看永久收益，右键看上下牌文，确认看收环重排。真实等级/扣费仍在轮末。
6. 调试→重播中央石台盘旋合拢；兵姿按钮可单看举盾、举剑、搭弓，结束后选“正常兵姿”。
7. 阶段横幅均为5秒；空格或右下窗回到当前行动，中键拖动可自由观看。
