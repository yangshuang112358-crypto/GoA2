# Goa2 石板行动序列 · 独立交互 demo

直接双击 `index.html`，使用 Edge/Chrome 打开，无需安装Unity、无需服务器或联网。源码是单文件Canvas原型，与Goa2V1运行时无依赖。

## 操作

- 初次打开自动连续演示六组场景，约107秒。
- 右下角选择场景、上一场景/下一场景、暂停/继续或从头播放；空格暂停。
- 鼠标在左侧石板附近（含明确边缘热区）滚轮：上下浏览；没有滚动条、没有整个信息栏的窗口底板。
- 鼠标在其他战场区域滚轮：缩放战场。浏览到顶/底不会把滚轮传给战场。
- 悬停石板：收稳与高光；点击普通卡：魔法反馈。场景3的合法红方候选卡可以点击，演示队长选择与换序。
- 新一级卡开始时退出自由浏览并平滑置顶。

## 连续演示的章节

| 演示时间 | 内容 |
|---|---|
| 0—15秒 | 两组同先攻预排、垂直落板、微摆与悬停；先攻数值只在卡内 |
| 15—34秒 | 投掷飞斧攻击前弃牌→反射屏障防御→防御效果导致三级弃牌；预选期间不造未知牌 |
| 34—49秒 | 原攻击完整结算后，反击实际使用的牌新增一级置顶；其防御为二级 |
| 49—68秒 | 三张/四张同先攻，队长选择、前浮换位，蓝红剩余顺序调整 |
| 68—81秒 | 注入中毒后的公开数值，10变6；只重排未行动牌，已完成卡保留 |
| 81—107秒 | 深层长列表、附近滚轮浏览、离开后缩放；记录更新不抢浏览，新一级开始自动置顶 |

字幕为演示说明，不是正式游戏新增HUD。录像中的圆形指针是脚本操作位置提示。

## 范围

这是真正运行并可交互的浏览器原型，演示数据由脚本驱动；不是Unity实机，不接规则/联机。中毒与长层级部分是注入状态/结构压力示例，不声称整个脚本是一场合法对局。反击的原有等待时序保持。

卡牌名称、基础先攻、卡色参考项目数据；人物头像以文字标识占位，技能图标、石材、战场均为程序绘制。未使用Blender成品模型，未制作音效。本版连续录像无音轨。

## 工程验证与录制

`verify-record.cjs` 使用 Playwright 和本机 Edge：`node verify-record.cjs` 执行16项UI验证；`node verify-record.cjs --record` 连续录制真实浏览器渲染，输出 `output/stone-sequence-continuous.webm`。录制需要Playwright的FFmpeg组件。请通过环境变量或Node模块路径提供Playwright；用户直接运行网页不需要这些依赖。

检查包含实际浏览器鼠标/滚轮事件，但不是OS输入测试，不是卡牌核心回归。转码为MP4只为手机播放，不拼接、不变速、不替换画面。截图通过程序跳到指定场景作静态检查，不混入连续录像。
