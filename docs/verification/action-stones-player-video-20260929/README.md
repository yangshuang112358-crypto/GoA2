# 正式 Player 行动石板连续实操录像

2026-09-29，源码基线 e3a485a，沿用已构建的 engine97 Player，构建清单见 build-info.json。本次没有修改游戏源码或重新构建。

play.mp4：1600×1000、约90秒、H.264/AAC、约12 MB。只裁去开头34秒准备等待，中间无剪接、无加速。Windows gdigrab 采集实际可见 Player 客户区与鼠标；WASAPI 扬声器回环采集实际声音，不是事后配音或事件混音。系统采集时有丢帧，约26 fps有效采样。完整视频解码无错误，录音非静音。

setup.json 只负责在录像前准备四人同先攻、英雄位置和装备；8步在实际Player无图形模式通过，然后载入其导出存档。录像里的选牌、选择先行者、放弃、攻击目标、防御确认及滚轮均由 Windows 键鼠注入完成，未使用 UI Toolkit 合成回调或直接提交游戏命令。不是四名人类玩家或跨电脑联机验收。

录像内容：黄蜂选静电封锁后揭示四张完整卡；蓝队选艾瑞恩先行；随后红队选黄蜂，展示同先攻换位和已行动卡脱组；布罗根猛攻黄蜂，黄蜂使用闪耀之刃防御（2对3防御失败）；防御牌以二级节点保留，切到下一主卡后向上浏览历史。视频中夏尔加萨的反击只是本回合主卡，未发动额外反击攻击。

此段没有演示反射屏障强制弃牌或三级嵌套。反射屏障仅能抵挡非相邻英雄的远程攻击，在这个相邻攻击局面不能使用。准备存档中的调试传送不是合法移动演示。用户美术验收仍待反馈。
