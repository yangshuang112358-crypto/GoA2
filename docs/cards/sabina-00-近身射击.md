# 近身射击实施合同

2026-09-13，目标引擎22。sabina-00-近身射击，萨彼娜金色基础攻击，先攻12，攻击2、远程1，次移1、次防1，无被动。

原文：选择攻击距离内的一个单位为目标。攻击后：如果目标与你相邻，将目标推动1格。（单位被推动到障碍物上会停下，这算作一次有效的推动。）

普通远程攻击使用1+远程加成，可攻击合法英雄/小兵。英雄防御结算后，如果原目标仍在地图上且与萨彼娜相邻，强制沿远离萨彼娜的直线推动1格；不是可选操作。目标已被击败离场、扩距攻击的不相邻目标不推动。初次攻击小兵直接击败，因目标离场不执行推动。对局已结束也不再推动。

推动独立于普通移动和快速移动：不消耗移动预算、不受移动图标加成、不使用普通移动事件，不受只限制移动/快速移动的静电封锁边界影响。正常占位、地形、地图外仍阻挡；受阻停在目标原格，实际推0格仍为有效推动，不将其当成攻击失败。

依据：R-MOVE及正式牌文；另核对发行商第二印规则印刷第18页Push，推动沿远离施力者的直线，不能推满时走到可达的最远处，可为0格。没有使用多目标同时推动规则覆盖用户既有逐个处理裁定。

程序：ChooseAttackTarget → Attack → PushAttackTargetIfAdjacent → End。推动为攻击后即时步骤，不增选择窗口；现有防御断点恢复后继续。可复用的PushRules只计算相邻施力者方向的直线推移路径及阻挡原因，应用仍由规则命令边界完成。UnitPushed保存目标席位、来源牌、施力者、起终格及路径；PushStopped补充障碍/占位/地图外原因。0格也发UnitPushed。无新增GameState保存字段，版本22才注册。

联动边界：这张牌能推动的存活目标是英雄；小兵被初次攻击击败后已移除，因此不会用本卡绕开尚未完成的小兵出战区回归流程。尚未实现的大招/全面免疫对推动的响应仍单独验收，不因此声称所有强制位移已完成。

检查：数值防御/躲闪后推1、六个方向、地形/占位/地图外推0、击败英雄或小兵不推、扩距攻击不相邻不推、移动加成不扩推、静电边界不限制推动、事件顺序、重复防御不重复推动、防御断点保存恢复、胜利停止、E21原档。

手工完整起点提供英雄防御后推动、前方被友军占位、攻击旁边小兵三个分支。加载时右侧最近记录输出操作；不预先进入防御窗口。
