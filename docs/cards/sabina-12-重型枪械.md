# 萨彼娜·重型枪械

2026-09-26规格；引擎56已实现并通过规则验收，Player实际画面/输入尚未验收。正式ID `sabina-12-重型枪械`，紫色卡牌等级4，英雄8级独立持有，无暗选及次要行动。

原文：“你的基础攻击+2攻击距离和+2攻击。如果你推动一名敌方英雄，该英雄丢弃一张卡牌，否则被击败。”

裁定：D-035规定合法受阻0格也触发；D-036允许目标有手牌时主动选择被击败。不能把因免疫/位移保护根本没有执行的推动当成合法0格。

## 原子合同

1. 持有能力为本人正在执行的基础攻击提供两项独立加成：攻击+2、攻击距离+2。普通红色攻击、技能上的远程图标、次要防御/移动不受益；被动图标原值保持，未来中毒不能反转这项紫卡加成。
2. 本人真正执行对敌方英雄的推动后，记录目标与紫卡来源。推动小兵、友方或其他英雄作为来源不触发；攻击已击败、目标已经离场则没有后续推动。
3. 目标有牌时由目标本人选择一张手牌弃置，或明确选择不弃牌并被击败；空手直接进入击败。原攻击者不能代选具体牌。弃牌私有牌名与公开颜色沿用现有规则。
4. 击败奖励、水晶、来源持续取消与胜利走正式英雄击败流程；不得重复奖励。后续击败不反写原本成功防御的攻击结果为“攻击击败”。
5. 子选择暂停原卡执行，保留尚未结束的防御后续；支付/击败后继续原卡一次，原卡只结算一次。即时胜利则结束，不再恢复父流程。
6. 紫卡能力独立持有，来源死亡不删除所有权；没有在场来源不能制造推动。当前完整代表为近身射击，新增通用推动入口时必须接入相同的推动完成通知。

## 建议接入

- 紫卡注册层描述基础攻击数值与推动后支付后果；主战斗/移动中不按卡ID特判。
- 分项攻击计算与当前攻击距离/界面均从同一能力查询读取，不能仅增加展示值或仅增加实际伤害。
- 新增可保存的支付后果状态，记录来源、目标、继续点；复用强制弃牌UI，但支持这次明确允许的主动被击败。通用原语供后续五张“否则击败”牌使用。

## 必要验证

正常8级取得、引擎门控、数值与非基础类别负例；距离3/4边界；推1格/墙阻0格/单位阻0格/禁止推动；目标主动付牌/主动被击败/空手；错误身份及重复命令；防御后续仍能恢复；胜利截断；支付窗口保存恢复。手工预设从萨彼娜开始近身射击之前进入，并提供受阻与不同目标分支。

## 实施记录

引擎56。紫卡注册提供基础攻击+2攻击/+2距离；加值单列UltimateBonus，攻击详情与绿色加值展示从核心投影读取，升级图标不改。推动后保存ForcedPaymentProgress，待选择时保留父卡游标与防御响应；有牌本人弃牌或主动被击败，空手直接击败。此原语只恢复当前父卡，尚不声称支持任意多层反击栈。

已覆盖的测试设计：距离4/5（当前升级有+1远程）；非基础类别不获加值；墙/地图边缘/单位占位的合法0格；铜墙铁壁完全禁止推动；空手与即时胜利；支付双方身份、非法牌、重复命令和保存恢复；侧步在支付后继续或因防御者离场跳过移动；原攻击击败英雄/小兵不再推动或重复奖赏；引擎55冻结电闪雷鸣响应字节不变。
