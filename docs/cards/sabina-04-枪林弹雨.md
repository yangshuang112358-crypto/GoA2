# 枪林弹雨实施合同

2026-09-13，目标引擎21。sabina-04-枪林弹雨，萨彼娜红3，先攻9，攻击3、远程2，次移4、次防5；未选候选提供范围被动。

原文：选择攻击距离内的一个单位为目标。攻击后：如果此攻击击败了一个小兵，且攻击距离内没有敌方英雄，你可以移除攻击距离内的一个非重型敌方小兵。

沿用交叉火力已验证的攻击后可选移除流程，但额外移除距离从相邻改为2+远程加成。范围加成不扩大任何一步的攻击距离。EnemyHero条件也采用同一个当前攻击距离：远程增加后，原先在圈外的敌方英雄可能进入圈内而阻止额外移除。免疫英雄仍是存在的敌方英雄。

目标为一个敌方近战或远程小兵，排除重型、友军和英雄。初次攻击英雄、防御成功、无目标等分支不额外移除。R-DEFEAT已区分移除与击败，此牌未覆盖一般规则；因此后续MinionRemoved仍不发金币、助攻，不计另一场攻击或击败。重型初次攻击仍按已有推进、出生、恢复顺序完成，再检查新战区目标。

通用程序保持ChooseAttackTarget → Attack → OptionalMinionRemovalAfterDefeat → End；只读参数ExtraRemovalUsesAttackRange=true。交叉火力默认false并保留相邻。已有枚举指令改为通用名称，序号不变且不进入保存内容；无新增保存字段。Pending沿用effect_minion、ChooseEffectTarget与本人skip，断点及父行动不变。引擎21注册枪林弹雨，E20冻结档保留交叉火力相邻限制。

检查：两格额外移除、不重复奖励/重放；射程边界及范围/远程物品区别；扩距使敌方英雄进入条件范围；英雄被击败或抵挡不触发；初始无后续目标；错误选择者/友方/重型；推进后的两格新兵目标；旧E20原始恢复及相邻限制。

手工完整起点布置(6,-8)近战兵为初次攻击、(6,-7)远程兵距萨彼娜两格为额外移除，另有三格外敌方英雄；右侧记录说明顺序、跳过及把英雄移入射程的反例。

证据：14项专用（实现前13失败1通过），与交叉火力合计29项针对性检查通过；完整675 C#与32 Python，7份相关原生122步，包含占位出生后选择两格新兵。实际Player中额外移除说明和跳过按钮可见，未计物理点击或视觉截图。
