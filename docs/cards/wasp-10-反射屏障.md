# 反射屏障：行为合同

黄蜂绿3牌，先攻3，主要防御!，次移2，无次防，未选图标先攻+1。原文：“如果攻击者不与你相邻，抵挡一次远程攻击。若如此做，攻击者丢弃一张卡牌（如果可行），此回合：你免疫不与你相邻的英雄的远程攻击。”

抵挡条件、强制弃牌与R-DEFENSE后处理顺序同偏转屏障；无牌分支按D-011自动继续，不能让有牌攻击者跳过。完成该反制后，为黄蜂建立本回合远程攻击免疫，来源是本次使用的防御牌，保护单位是黄蜂自身。它在回合结束到期，不在揭示本牌时提前生效。

免疫按后续攻击实际来源、远程类别及当时距离判断：不相邻英雄的远程攻击不能指定也不能影响黄蜂；相邻英雄的远程攻击、非远程攻击，以及独立技能/移动/推动不被本免疫一并禁止。技能范围或远程加成不能把“不相邻”改成更远的边界；是否为远程也不能只按数值距离推断。普通保护与攻击目标查询/提交重检继续适用。

来源、受保护单位、创建顺序、持续期与私有来源可保存。该效果来自防御牌，不属于闪耀之刃取消的技能卡效果。未揭示的防御牌名沿用U-006保守投影，其他角色可看到远程免疫事实及受保护角色，不额外获得其弃牌卡名。本人仍可查看完整来源。

版本4开放本牌；旧版保持原未实装响应语义。验收包括偏转屏障全部适用项，另加生效前/后、非相邻/相邻/非远程攻击、两个敌方来源、到期恢复、来源可见性、被保护目标不高亮和命令拒绝、无牌反制后仍获得免疫，以及与闪耀之刃来源类别的分离。两张艾瑞恩牌防御失败后的U-013不适用于这张“若如此做”且成功抵挡才触发的牌。
