# 冲拳实施合同

正式源 brogan-13-冲拳：蓝1，先攻9，主要技能0，无范围图标，次移2/次防6，无被动。

原文：“选择一项：移除与你相邻的一个标志物；或将与你相邻的一个敌方小兵推动最多2格。”

D-050已明确当前六英雄没有地图标志物，本批仅开放存在的单位分支，地图标志物移除记为待扩展，不把出生点或中毒标记充当地图标志物。界面应注明当前分支范围，不声称标志物已经实现。

选择相邻敌方实体小兵，英雄（包括一人成军的布罗根）、友方兵、受免疫保护的重型不合法。选择者为布罗根；选中后沿来源到小兵的方向推动0、1或2格。零格主动不推动时跳过；合法推动因墙、单位或地图边缘受阻则停在最后合法格，完全受阻可结算实际0格的推动。推动不是移动，不使用移动被动、不走普通移动路径，不跨过阻挡。按通用位移免疫检查，可推动的最后重型和受保护重型分别验证。

用独立ChooseUnitPush指令和目标策略建立effect_target，再以effect_move命令承载推动落点选择；ResumeAt区分普通移动与推动，界面文字必须明确。不修改原攻击目标；被选小兵ID保存在Pending.UnitId。复用PushRules、RecordDisplacedMinion和行动末小兵回归；为后续野蛮飞踢的英雄目标保留AfterHeroPushed调用，不能把推动误报为普通移动。

测试：敌友/英雄/小兵/重型分类，0/1/2格及非法远格；受阻0格、墙/占位/地图边界；移动加成和静电边界不改变推动；待选择保存和私有性、错误身份与幂等；推动离区的小兵先回归再收尾；原有强制推动行为与旧存档。手工预设从布罗根完整主要行动前加载，提供推动长度和归区分支。
