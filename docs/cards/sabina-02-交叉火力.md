# 交叉火力实施合同

2026-09-13，目标引擎20。sabina-02-交叉火力，萨彼娜红2，先攻9，攻击3，远程2，次移4、次防4；未选候选提供先攻被动。

原文：选择攻击距离内的一个单位为目标。攻击后：如果此攻击击败了一个小兵，且攻击距离内没有敌方英雄，你可以移除与你相邻的一个非重型敌方小兵。（你不会因移除小兵而获得金币。）

程序：ChooseAttackTarget → Attack → OptionalAdjacentMinionRemovalAfterDefeat → End。初次攻击可选敌方英雄或正常可击败的小兵，距离1至2+远程加成，不排除相邻。攻击英雄走既有防御/击败，攻击小兵走击败奖励/重型推进；不因本牌后半段而禁止攻击英雄或重型。

本次攻击结果必须是minion_defeated。待攻击及其兵线推进/占位出生全部完成后，以当前场上位置检查攻击距离内不存在敌方英雄，包括免疫英雄，不把“不可被攻击”误当作“不存在”。然后由萨彼娜本人选择移除一个相邻敌方近战或远程小兵，也可不移除；友军、英雄、重型、距离2小兵均不合法。远程物品扩大初次攻击及敌方英雄条件距离，不扩大“相邻”后续移除。没有合法后续目标直接结束已完成的攻击。

额外移除使用RemoveMinion的无奖励入口，发MinionRemoved并用EffectMinionRemoved保存来源卡/控制者/目标；不发MinionDefeated、击败金币、助攻或额外AttackDeclared。重型初次击败按现有可恢复兵线推进完成后续，不读取旧战区已清除的小兵。后续移除排除重型，不能再次推进。

PendingChoice.Kind=effect_minion，Source为本牌，Chooser为萨彼娜，Optional=true；复用ChooseEffectTarget命令及GameView.EffectTargets作为单位目标选择，不将小兵塞入英雄选择规则。Cursor、AttackOutcome和Pending均已能保存，无新保存字段。版本20才注册；旧E19重复攻击保持原语义。

检查：击败再移除/跳过、金币只一次；条件英雄距1/2/3及远程加成、免疫英雄也阻止；相邻移除不扩距、友军/重型/英雄/距离2非法、错误席位及重复、攻击英雄/防御成功不触发、无后续小兵、重型推进同步/占位出生后恢复且只开一次窗口、E19原始存档。

手工起点均在萨彼娜完整Action开始；第一近战兵为攻击目标，第二相邻远程兵为额外移除分支，远处英雄可用调试瞬移移入射程比较条件。加载后右侧最近记录显示操作方法，不预先进入攻击中途。
