# 吟游诗人实施合同

2026-09-13；目标引擎16。brogan-10-吟游诗人，布罗根绿3，先攻4，技能0，远程3，次移2、次防5；未选候选提供先攻被动。

正式原文：如果你或攻击距离内的一个友方英雄与敌方单位相邻，则该友方英雄可以拿回一张已结算或已丢弃的卡牌。

1. 布罗根选择自己或距离3+远程加成内的一个队友英雄；该英雄须相邻敌方英雄或任一种小兵。共用战鼓目标原语，不把范围加成混入远程，不套用攻击目标免疫。
2. 受益英雄本人从自己的Discarded或PlayedResolved选择一张，或明确跳过。InHand、Selected、PlayedUnresolved、紫卡和其他人的牌均不能选。没有可取牌时自动完成。
3. 取回仅将这张卡变为InHand；保留公开出牌历史、PlayedRound/Turn记录用于本项目“本回合揭示过攻击牌”判定。下一回合可以再次出牌；不能在当前回合凭取回再获得额外行动。完成原布罗根行动，不能把受益者当成父行动控制者。

原语：ChooseHeroTarget(AlliedNearEnemy) → OptionalRecoverDiscard(recoverResolved=true) → End。牌区能力为只读程序参数，不新增存档字段；原战鼓/忠实信徒仍只有Discarded候选。待选择的来源、目标及操作者全部沿用引擎15结构。

持续效果按D-026：从指定牌区取回时，按创建顺序取消该受益者以该张牌为来源的当前或待生效效果；来源私有性沿用效果记录。不会取消另一张牌的效果或再次触发该牌。引擎16的所有正式取回共享此规则，旧引擎15战鼓日志不受影响。

关键检查：本人/队友已弃牌、队友本回合已结算牌、本人先前回合已结算牌、跳过、牌区/权限/重复提交、两个选择断点保存、取回再出牌及四回合历史、神枪手“本回合使用攻击卡”条件、旧引擎15跨玩家取回档。范围/邻接/静电/打断施法沿用战鼓共享检查并跑回归。没有位移/复数目标/强制成本，不设计无关穷举。

手工起点停在布罗根的完整Action：虎爪本回合偷袭已结算且躲闪在弃牌区，可选择取回其中一张或放弃；若选择本人，则可取回飞斧。右侧最近记录列出操作与下一回合重新使用分支。
