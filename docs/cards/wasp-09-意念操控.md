# 意念操控实施合同

正式源 wasp-09-意念操控：绿2，先攻3，主要技能0，远程3，次移2/次防3，攻击被动。

原文：“将攻击距离内与你不在同一直线上的一个单位或标志物放置到与你相邻的格子。”

先选择攻击距离内不在任一六边形直线轴上的合法单位，再由黄蜂选择自身相邻空格放置。不限阵营：可选合法敌方/友方英雄或小兵；自己和所有相邻单位均因同一直线条件不合法。距离使用远程被动，非技能范围被动；技能不会受仅攻击免疫阻止，但全行动免疫、敌方位移保护及固有重兵保护须过滤。没有相邻空落点时没有可完成的目标。选择后放置为必选，不是可选移动。

放置不经过路径、不受墙或静电移动边界限制；终点须在地图上且无地形/单位，空出生点允许（本牌没有潮水的额外限制）。发出UnitPlaced，保留来源/操作者/被放置单位；不能发成UnitMoved或触发被放置英雄的行动前。离区小兵仍按行动结束先回归。D-050当前六英雄无地图标志物，单位分支先验收，地图部件分支待扩展。

架构：新ChooseUnitPlacement指令仅调度两个可保存窗口：effect_target/unit_placement_target与placement/unit_placement。外部复用ChooseEffectTarget及ChoosePlacement；当前指令不更改主攻击流程，候选从规则层返回。后续心灵控制通过单独的可选重复步骤展开第二次完整行动，不能无限循环或混用海妖的ApproachRepeated标志。

测试：双方英雄与小兵、三轴直线排除、射程边界及两种被动区别、满占相邻格、全免疫/攻击免疫区别、位移保护、放置跨墙/静电且不触发移动、小兵归区与旧档；非法命令零修改/重发幂等/旁观私有候选。手工从黄蜂行动前加载，放置目标与其他同轴单位作分支。
