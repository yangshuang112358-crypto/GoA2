# 挑战者：行为合同

正式输入：arien-13-挑战者，艾瑞恩蓝1，先攻9，主要防御5，次移3，无次防/被动。原文：“无视所有的小兵防御修正。”

在本英雄受到攻击后的防御窗口，由本人选择手牌中的此卡并弃置。判定时忽略全部小兵修正，即R-COMBAT公式中的b与c都归零，仅比较防御5＋有效防御加成与攻击牌值＋有效攻击加成。保留原小兵修正明细供日志解释，但不参与本次结果；不删除或移动任何小兵。

本牌是数值防御，不是“抵挡”，攻击的不可抵挡关键词不禁止本牌。数值大于等于攻击则成功，否则击败；没有后续免疫效果，不继承决斗家/传奇决斗家文本。不是持续删除小兵修正。

验收：有正/负小兵修正的两种场景、攻击5相等成功/攻击6失败、有效防御加成、不可抵挡可防、下一次攻击恢复常规修正、非手牌/权限/恢复和公开颜色。若后续发现更高权威逐卡更正，先记录再变更。
