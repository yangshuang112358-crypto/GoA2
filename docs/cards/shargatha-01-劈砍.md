# 劈砍：行为合同

夏尔加萨红1，先攻7，非远程攻击4，次移5、次防6，无升级图标。原文：“选择与你相邻的一个单位为目标。每有一个与你相邻的敌方单位，+1攻击。（计算所有敌方单位，包括攻击目标。）”

按D-007选择相邻敌方单位，排除攻击免疫/重型保护。攻击英雄时，声明攻击的实时局面中，每名距攻击者1格的敌方英雄或小兵提供牌文+1；包括目标、远程及重型小兵，不把计数误当成对这些单位的攻击，因此受保护的重型仍计数。友方、自身、距离2、已经离场单位及标志物不计数。该修正以攻击者为中心，与以防御者为中心的小兵b/c项分别计算，两种来源都保留。

每次只攻击选定目标，不攻击或移除所有相邻敌人。声明攻击后保存本次来源单位ID与修正值，待防御不能重复叠加。小兵被合法选中则按普通小兵规则直接击败；不为小兵创建英雄数值防御窗口。次防6与移动不触发主要攻击，放弃不产生计数效果。

引擎6开放；旧版本保持未实装语义。验收覆盖1/多个相邻敌方单位、目标及其他种类、友方排除、两中心区分、主值+永久+牌文+兵修正、免疫/保护与反制、防御停顿恢复、无目标、原子拒绝、次要使用。没有群攻、持续或重复步骤。
