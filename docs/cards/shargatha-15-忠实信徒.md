# 忠实信徒：实施合同

2026-09-13，目标引擎12。正式来源content/canonical/cards.json；遵循R-ACTIONS、R-CARDS与角色唯一规则。没有本卡直接待裁定分支。

夏尔加萨，蓝2，先攻10；主要技能0，无范围图标；次要防御6、移动3；升级被动为攻击图标。原文：如果你与一个小兵相邻，你可以拿回一张已丢弃的卡牌。

1. 主要技能开始时，按真实英雄位置检查距离恰好1的小兵；近战、远程、重型与双方阵营均满足。相邻英雄、障碍和出生标记不算小兵。没有目标选择，也不移除小兵；重型保护与攻击免疫不改变这个纯相邻条件。
2. 条件成立且本人弃牌区有牌时，本人选择一张取回或明确跳过。只能取回自己的Discarded，不能取回已出、未结算、手牌、别人牌或紫色大招；金牌若在弃牌区同样合法。没有相邻小兵或弃牌为空时自动继续。
3. 取回令对应牌回到InHand，不重复给予升级图标、不重置回合、其余四张牌区不变。记录私有卡ID及公开取回颜色；公开Pending不装入私有候选ID。来源为忠实信徒，保持原CardExecution直至本人完成选择。
4. 此牌是技能，受敌方打断施法/闪耀之刃技能封锁。改用次要移动、防御或放弃不会取牌。取回后的合法防御/下一回合选牌直接走既有规则。

新增通用OptionalRecoverDiscard指令与ChooseRecoveredCard命令。保留引擎11真实移动窗口作旧档基线，引擎12以下不能取得新牌效。此牌没有持续、推动、移除、重复、多目标、攻击后响应；六张大招尚未实装，不声称通过大招集成。

测试矩阵：双方三类小兵；精确1/2格与相邻英雄；空弃牌；取回/跳过；金牌与普通牌；非法他人牌/已出牌/手牌/重复命令/过期revision/伪造身份；公开与私有投影；保存恢复；技能封锁；取回数值防御牌后使用；快速突刺受到黄蜂屏障反制后的本人弃牌取回；轮末归还不重复；旧引擎和安全升级。
