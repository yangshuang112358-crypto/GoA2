# 电能爆炸实施合同

正式源 wasp-05-电能爆炸：红3，先攻9，攻击6、范围2，次移4/次防7，防御被动。

原文：“选择与你相邻的一个单位为目标。攻击前：技能范围内最多一名敌方英雄（除攻击目标外）丢弃一张卡牌，否则被击败。”

主目标按攻击默认规则为相邻敌方单位，包括合法小兵；范围图标仅限定攻击前额外英雄，不能把攻击变为远程。攻击前可以不选择额外目标；选了则由该英雄本人弃牌或按D-036主动选择被击败，空手直接被击败。额外目标必须非免疫、敌方、在范围2加范围被动内，排除原攻击目标。攻击免疫也阻止本攻击的附带弃牌，全免疫同样阻止。

沿用OptionalOtherHeroDiscard的选目标机制，新增表示“否则被击败”的指令，复用ForcedPaymentProgress并保留原攻击目标。额外支付完成后才计算原攻击；不能把额外英雄写成攻击目标或提前执行弃牌反击。若额外击败导致胜利，立刻终止原攻击。空目标、免疫等沿用现有停止规则，通用撤回仍暂缓。

实际弃牌使用DiscardCard，反击等待整次电能爆炸攻击行动完成；可序列化保存额外目标选择、支付、防御与反击窗口。现有电击/电能波“如果可能”的空手跳过和无拒绝权保持不变。金钱/水晶/复活、受保护小兵和紫卡推动等没有本牌专属重写。

测试：攻击相邻限制、范围额外目标及排除原目标、可跳过；有牌支付/拒绝/空手、胜利终止；错误席位/目标/重复零额外执行，原目标不丢失；英雄及小兵主目标；范围与远程被动区别、攻击免疫；真实反击等待原攻击结束；旧电能波能力和旧存档。手工加载到黄蜂完整攻击行动前；反击组合从夏尔加萨先行动开启反击的位置加载。
