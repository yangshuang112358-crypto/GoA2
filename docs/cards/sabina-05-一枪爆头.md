# 一枪爆头：行为合同

萨彼娜红3，先攻9，攻击4，远程2，次移4、次防7，未选图标移动+1。原文：“选择攻击距离内的一个单位为目标。如果目标英雄在此回合使用了攻击卡牌，则+2攻击。”

依D-007选择攻击距离内敌方单位；与神枪手不同，本牌可以选择相邻目标。最大距离为2加永久远程加成，技能范围加成不扩大攻击。目标英雄本回合已揭示攻击或基础攻击牌即满足+2，按统一R-ROUND/R-ACTIONS及神枪手明确说明理解“使用”，不额外要求已结算；条件查询、来源明细、牌区/回合边界与防御交互同神枪手合同。

次要防御只提供7点基础防御；移动或快速移动不执行主要攻击。正式升级选中获得枪林弹雨的范围+1，未选本牌获得移动+1，永久数值来自真实升级账本。

程序从引擎5开放。验收除条件修正共用矩阵外，必须有相邻英雄/小兵可选与神枪手相邻拒绝的差异测试、非相邻反射免疫排除/相邻远程不被排除，以及放弃、恢复、幂等和升级来源。牌名不代表自动击败；仍按实际攻击与防御数值结算。
