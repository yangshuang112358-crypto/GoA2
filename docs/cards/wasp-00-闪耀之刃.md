# 闪耀之刃：行为合同

正式输入：黄蜂金牌，先攻12，基础攻击3，无范围/远程图标，次移1、次防2，无被动。

原文：“选择与你相邻的一个英雄为目标。攻击后：取消与你相邻的敌方英雄技能卡上的激活效果。此回合：与你相邻的敌方英雄无法执行技能行动。”

按D-007，攻击目标仅相邻敌方英雄；小兵、己方、自己和非相邻英雄不能指定。没有远程/范围图标，本牌的相邻距离不会被远程或技能范围加成扩大。基础攻击3使用同一a+b-c、数值/主要防御、击败/奖励流程。

步骤1由黄蜂选择合法英雄；无目标结束剩余牌文，不建立后续禁止。步骤2结算攻击及目标防御；防御成功并不跳过“攻击后”，本牌没有要求击败目标。步骤3按攻击后实时位置，取消相邻敌方英雄以技能卡为来源、已激活的持续效果。仅取消对应的来源记录，不删除其卡牌、紫卡拥有、移动牌/防御牌/攻击牌效果，也不取消友方或非相邻来源。第四回合仍按本回合到期，不跨轮。

步骤4建立黄蜂为来源的相邻敌方英雄技能禁止，持续至当前回合结束。这个范围固定相邻1，不是技能范围1，不吃范围加成。中心随黄蜂当前位置变化；来源不在地图上时无覆盖区域。攻击、防御、移动和快移不被当作技能启动。该效果来自基础攻击牌，因此另一份“取消技能卡上的激活效果”不能把它当技能卡效果取消。

被击败的攻击目标已离场，攻击后不再处于相邻格；其已有持续记录按明示持续期保存，离场时无区域，不因原攻击目标身份强行匹配取消。已激活记录与尚未生效的下回合记录分开：本牌用语仅取消激活效果；未来涉及其他取消用语时另建合同。

版本3开放本牌；版本0—2保持主要行动未支持的能力集合。主要程序、持续范围类别、取消来源/发起牌与创建顺序可保存重放。作为次要移动、次防或放弃时不执行上述主文字。

验收：相邻/非相邻/己方/小兵与两个范围加成；防御成功后取消与封技；技能封锁不阻止这张基础攻击；取消时实时来源位置、阵营、来源类别与生效时间；被击败目标离场；无目标不建效果；移动/次防不触发；重复命令和待防御恢复；新旧引擎能力隔离。免疫及复杂防御反制按对应来源牌的合同补充集成，不借用历史手测升级状态。
