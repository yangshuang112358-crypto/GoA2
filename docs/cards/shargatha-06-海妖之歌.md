# 海妖之歌实施合同

正式源 shargatha-06-海妖之歌：银色基础技能，先攻1，技能0、远程3，次防3，无次移。

原文：“选择攻击距离内与你不相邻的、最近的、非免疫的敌方单位为目标；沿最短有效路径将该单位向你移动最多2格。可重复一次。”

候选依次按敌方、攻击距离、非相邻、非免疫筛选，再以六边格距离取最近的一组，并列由夏尔加萨选择。重型保护、铜墙铁壁的敌方位移保护、行动免疫均要在此检查；不能仅用能否被攻击代替技能位移权限。没有有效路径不意味着可以擅自改选更远目标。

向来源英雄的移动以可到达其相邻空格的最短有效路径为依据；绕障碍时某一步可以暂时增加直线距离，不能只找“距离每步减1”的格子。路线受单位实际移动限制、占位、地形和静电封锁约束。最多2格可走0、1、2格；方向与路线由技能操作者选择，单位移动被动不增加固定牌文距离。实现用反向BFS取得有效剩余路径长度，再枚举至多2步的最短前缀，避免全路径指数穷举。无完整有效路径时跳过该次移动，不自行放置或推开阻挡。

重复最多一次（D-028），再次执行整个基础技能并重新求最近目标，可选原目标，前提是仍满足条件。重复属于新行动，需再次触发幻化行动前；牌内移动不触发。被移出当前战区的实体小兵在该次行动结束后按D-030回归，再进入重复选择，不能等两次都结束才回归。沿用可序列化父行动与小兵回归，不生成新兵战。

程序边界：独立最近目标策略与接近移动路线；复用effect_target/effect_move命令和界面，仅新增明确ResumeAt。重复接受后生成新行动实例、重置该次执行字段；小兵回归保存原执行游标。主回合流程不写卡ID特判。

测试重点：最近并列、近处免疫者不干扰下一合法候选、近处无路不改选更远；英雄/三类小兵与重型保护；0/1/2步、绕障碍最短路线、静电边界；两次各自重新选目标、无第三次；幻化首次和重复各触发一次；小兵归区先于重复；每个选择窗口保存重放、私有候选/错误席位/非法格零修改/幂等。手工从基础技能开始前加载，放等距敌方英雄与兵，提供路线与重复分支。

距离与路径语义已对照项目的一般距离/移动规则及官方规则摘录核对；不是新增用户裁定。实现与验收记录见下方。
