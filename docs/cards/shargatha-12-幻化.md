# 夏尔加萨·幻化

状态：引擎57规则实现；22项专项及1476项完整C#回归通过，构建/批处理证据见紫卡开发记录。Player实际画面与输入未验收。正式ID shargatha-12-幻化，紫色、牌级4、英雄8级持有，先攻0、终极技能0，无次要行动和升级图标。

原文：“你可以穿过障碍物。在你执行行动之前，与你相邻的一个敌方英雄丢弃一张卡牌（如果可行）。”

## 原子合同

1. 持有能力独立于手牌和临时效果。D-037允许本人移动路径穿过地形与单位；终点必须存在、非地形、未占用。预算、直线、快速移动区域、静电封锁等其他限制保持；按R-MOVE，不把普通通行策略默认推广到推动/放置/换位。
2. 获准提交主要行动、次要移动、快速移动、防御响应及重复行动时，先进入行动前窗口；只是查看候选、过牌、拒绝防御、放弃重复不触发。牌文内部移动不另外触发。
3. 来源英雄选择一名相邻且非免疫的在场敌方英雄；无合法目标就继续原行动。D-040允许选择空手者，即使另有有牌邻敌；空手跳过弃牌，有牌由其本人强制选择一张手牌弃置。没有击败后果。
4. 待选择使用明确可保存的行动前帧，记能力来源/程序版本、父行动与待选择、执行类型和已确认意图。尤其防御前须挂起原攻击，支付完成后恢复原防御；不重新发起攻击，不提前消耗防御牌或结束已揭示牌。
5. 完成一次前置帧后仅恢复一次意图，不重触发自身。普通重复每个实例分别触发。非法命令与重复请求不制造额外弃牌。胜利清空帧；等待期间禁止结构性调试破坏父状态。
6. 公开能力和选中英雄，具体弃牌只向本人展示。未来反击依指南在对应行动完成后处理，本卡不提前递归执行尚未实装的反击。

## 验证矩阵

- 数据/绑定/引擎门控：精确文本、正常8级获得、紫卡不进手牌、旧56不触发。
- 四行动入口与重复：主要攻击/技能、次要移动、快移、防御；卡内移动与拒绝/跳过为负例。
- 目标/支付：距离1/2、敌我/小兵/来源排除、免疫、空手与无目标、有牌不可跳过、私有弃牌与错误身份。
- 几何：穿墙/穿人路径及不可落点，直线预算、主移/卡内移共享路径，快速区域保持；推动/放置为不同语义的负例。
- 帧：选目标和支付两个窗口保存恢复、重复请求、防御父攻击保留、整张只结算一次、旧冻结存档逐字节一致。
- 本卡不适用：攻击加值、击败奖励、多目标排序、标志物或轮末持续到期；依赖尚未实现卡的联动仅记录，不宣称已测。

手工场景从完整行动之前开始；防御分支从敌方攻击者回合起点开始，让玩家亲自攻击夏尔加萨，再选择防御和相邻弃牌目标。

实现边界：BeforeActionFrame目前承担幻化的单个前置窗口，尚未声称具备任意递归反击队列。主要行动中的已实现攻击与忠实信徒有正式可重放测试；未实装的主要移动卡及反击需在后续卡落地时追加集成。直线路径、静电边界、免疫过滤使用明确的隔离查询测试，不作为完整组合实战证据。
