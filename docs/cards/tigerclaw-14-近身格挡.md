# 近身格挡：行为合同

虎爪蓝2，先攻11，主要防御!，没有次防数值，次移3，未选图标防御+1。原文：“抵挡一次非远程攻击。攻击者丢弃一张卡牌（如果可行）。”

1. 只在本人响应攻击且本牌仍在手中时可用。检查非远程且可抵挡；名字中的“近身”不额外要求相邻。不能抵挡远程或不可抵挡攻击。数值高低、负攻击、永久防御加成不改变合法抵挡结果。
2. 本人确认使用后弃置本牌，抵挡成功，按R-DEFENSE先完成原攻击的后续文字，再处理本防御反制。
3. 攻击者固定为原攻击者，非另选目标。根据D-011及R-EFFECTS，攻击者有手牌时必须本人选择一张，不能跳过或改为放弃攻击；空手按“如果可行”直接继续。选牌窗口保存原攻击、来源、防御者和弃牌者，恢复后从该窗口继续。
4. 结束防御后处理并结束原牌，不能重复消费或重复攻击。普通弃置/次移/快移/放弃不触发这段文字。没有新持续效果。

防御卡来源及防御弃牌对原防御者私有，其他人看到弃牌颜色、待操作席位与攻击完成事实，遵循现有U-006最小披露方案；不把本机完整存档作为公开视图。引擎7开放，旧版本保持未实装。升级选中获得侧步的攻击+1，未选本牌获得防御+1。

矩阵：非远程/远程/不可抵挡、相邻/远端、手牌/空手、实际弃牌顺序、错误席位/非手牌/跳过的原子拒绝、重复/存读档、基础攻击后文、次移/快移、两种升级分支、旧引擎与来源隐私。路径、占位移动、多目标、重复和到期不适用于本牌独立文字；其他新型替换竞争仍按U-003处理。
