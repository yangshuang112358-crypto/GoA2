# 至死不渝实施合同

正式源 shargatha-17-至死不渝：蓝3，先攻10，主要技能0，无范围，次移3/次防6，攻击被动。

原文：“如果你与一个小兵相邻，你可以拿回一张已丢弃的卡牌，然后此回合：你免疫攻击行动。”

1. 沿用忠实信徒：相邻双方任一实体近战/远程/重型小兵均满足条件；这是存在检查，受保护重型也计入。英雄或地形不代替小兵。
2. 夏尔加萨本人从自己的弃牌区选一张取回，可主动跳过。私有候选不向其他席位泄漏。没邻兵或无弃牌自动跳过。
3. D-045：只有实际取回成功才建立本回合攻击行动免疫；跳过、无牌均不建立。取回本来持续效果的来源时，先执行既有来源取消，再创建本牌新效果。
4. D-033：免疫覆盖攻击行动本身和它附带的弃牌、强制位移、取消效果；不扩大为技能/防御/紫卡能力免疫，不影响其他单位用于存在或支援计数。来源自身的行动不受自身免疫禁止。
5. 本回合结束、来源被取回/替换或本人被击败时取消；不跨回合或复活保留。次移、次防、快速移动不取牌或建免疫。

实现计划：保存“实际取回成功”的执行结果，条件性ApplyEffect；独立AttackActionImmunity效果。CanAffect增加明确的攻击行动上下文，由攻击及其附属步骤传入，不根据正在行动的席位推断所有旧光环都是攻击效果。保留技能、护兵、紫卡及防御响应的自身来源类别。

测试：取回/跳过/空弃牌/无邻兵，双方三类小兵条件；攻击目标及电击/电能波额外弃牌免疫；华丽刀锋附属位移免疫；技能仍可影响；来源取回/被击败/回合到期；非法取牌/错误席位/重试/私有候选；选择窗口保存重放；旧63存档原始字节。与已落地反击共用弃牌区，但取回不是弃牌，不增加反击触发。手工从整次技能行动前起，取回后由敌人攻击比较候选。
