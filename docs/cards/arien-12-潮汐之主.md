# 阿连·潮汐之主

引擎60已实现，18项专项及七Editor场景通过；完整1551项C#、32 Python、构建和包校验通过，Player/UI未验收。正式ID：arien-12-潮汐之主；紫卡、卡牌等级4、英雄8级持有；无行动数值或底部加成。原文：“在你执行基础技能后，可以在你所在的战斗区域触发一场小兵战斗。”

## 已确定语义

D-043：基础技能完成时，阿连必须仍在场且站在当前交战区；在其他区域不产生触发选项。这里只启动当前兵线的小兵战斗，不在其他区域另开战区。D-039/D-042：持有一人成军的在场布罗根在任意区域贡献2兵，少兵方队长选中他即保留英雄并终止本次剩余移除；此前移除保留。

1. 持有者完整执行基础技能后检查一次；目前对应银牌打断施法。先建立银牌技能封锁效果，再产生紫卡选项。普通技能、攻击、以银牌防御或选择替代移动均不触发。
2. 由阿连本人选择“发动兵战”或“不发动”；平局仍可发动并立即完成。不能由队长替阿连选择是否发动。
3. 发动后按当前兵线普通小兵战斗规则计数，少兵方队长逐个选择，重型最后；一人成军只在兵战内加入计数和重型保护。小兵回归在父行动的完成前置流程中结束，不在这里创建新的移动行动。
4. 这是移除，不是英雄击败小兵：没有击败金币，不触发保卫/持盾等击败替换。移除重型推进、清兵、产生新兵和处理出生占位；出生选择完成后才恢复父行动。
5. 本次兵战不回收手牌、不收费升级、不发轮末补偿、不递增轮数。父行动恰好完成一次，继续当前行动序列；若它本来就是第四回合最后行动，才自然进入正常轮末入口。
6. 胜利优先：推到获胜时终止对局，不再恢复父行动或弹出升级。
