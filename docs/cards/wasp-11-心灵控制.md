# 心灵控制实施合同

正式源 wasp-11-心灵控制：绿3，先攻3，主要技能0，远程3，次移2/次防4，范围被动。

原文：“将攻击距离内与你不在同一直线上的一个单位或标志物放置到与你相邻的格子。可以重复一次。”

第一次完整执行意念操控式目标筛选及相邻空格放置。第一动作完成后，先解决小兵归区及待处理响应，再重新计算可选目标，允许不重复；重复仍须完整执行合法放置，只能再执行一次。不得将“可以重复”解释成第一次也可跳过，或第二次沿用失效目标/落点。第一次放到相邻的单位通常不满足第二次非同轴条件；若小兵归区后又满足，则牌文没有不同目标限制，可以再选。

采用两条展开的指令ChooseUnitPlacement、OptionalRepeatUnitPlacement、End，以Cursor保存次数，无需新循环计数。可选重复入口更新ActionInstanceId并走既有行动前入口；若出现插入响应则恢复命令，不重复消费目标。单位放置原语及D-050限制与意念操控一致。牌面范围被动不代替远程距离加成。牌本身是普通技能，不触发电闪雷鸣的基础技能后弃牌。

测试：第二次可跳过、两次不同合法目标、归区后同一兵再次合法、没有第二目标自动结束、非法第三次、保存/幂等、各席位私有候选及旧78档。手工从黄蜂第一次完整行动前加载，提供友方英雄、敌方英雄及小兵作分支。
