# 两面夹攻实施合同

2026-09-13；目标引擎17。tigerclaw-05-两面夹攻，虎爪红3，先攻10，攻击4，远程1，次移5、次防6；未选候选提供范围被动。

正式原文：选择攻击距离内的一个单位为目标。如果有友方单位与目标相邻，则+3攻击且此攻击无法被抵挡。（抵挡是一个关键词-目标英雄仍可以进行防御）

1. 虎爪选择距离1至1+远程加成内的一个敌方英雄或可移除小兵。范围加成不扩大攻击距离；不是固定相邻攻击。重型保护、远程攻击免疫仍正常适用。无目标则结束该牌。
2. 在攻击宣告时，检查目标是否相邻至少一个本队其他英雄或任一种小兵。D-026官方Friendly定义不含虎爪自己；与背刺已有明确文字相符。标记不算单位，敌方单位不提供此牌文支援。一个或多个支援都只+3，且同一条件令本次攻击不可抵挡。
3. 目标英雄仍可用合法数值防御并叠加其防御加成；“抵挡”类牌不能使用，不触发屏障反制。兵修与牌文+3分别计算；小兵按既有移除/击败流程结算，不伪造小兵防御窗口。
4. 本次攻击的不可抵挡事实及支援单位列表保存至AttackBreakdown，不在对方选防御期间重新采样。结束这次攻击，不影响下一次攻击。不能以不可抵挡绕过目标免疫。

原语：ChooseAttackTarget → Attack → End；复用OtherFriendlySupport，增加其“有支援则不可抵挡”程序参数及暂态CardAttackModifier标志，交给已有AttackBreakdown.Unblockable。不新增存档字段，不把背刺的+2变为不可抵挡；旧版本不开放此牌。

关键检查：本人不计入、其他英雄及三类小兵、多个支援只加一次、距离1/2与远程/范围区别、无目标和重型保护、敌方及错误操作者拒绝、不可抵挡时带头冲锋被拒绝但一枪爆头次防成功、无支援可用抵挡、保存/重复、防御失败即时胜利、次要移动不触发、E16吟游诗人取回持续效果档。支援类型过滤与背刺共享，仍保留本牌针对检查。无移动、强制成本、后置步骤和持续时长，不穷举这些分支。

手工起点：虎爪完整Action，萨彼娜相邻且可用带头冲锋或一枪爆头次防；本队布罗根位于萨彼娜另一侧提供支援，另有敌方近战兵满足带头冲锋条件。加载后先亲自攻击，再切目标选防御。另一份无支援起点用于比较抵挡恢复合法性；右侧最近记录给出方法及分支。
