# 决斗家实施合同

正式源 arien-15-决斗家：蓝2，先攻10，主要防御6，次移3，无次防，攻击被动。

原文：“无视所有的小兵防御修正。此回合：你免疫其他敌人的所有攻击行动。”

沿用挑战者的数值防御和忽略小兵修正；不是抵挡，防御值不足仍被击败。用作防御后，本回合不能被除本次攻击者以外其他敌人的攻击行动指定/影响，覆盖这些攻击的附带弃牌、移动、持续封锁。原攻击者、友方、自己不受此免疫限制；其他敌人的技能、防御与紫卡不被本牌禁止。

D-051明确防御失败也创建免疫，击败不移除此免疫；同回合复活后继续生效。独立序列化保留标志，不能靠英雄暂时离场隐藏后重新创建；正常回合到期、取回来源牌仍取消，其他来源效果照常因击败取消。保持武装密谋成功抵挡才免疫的既有语义。展示加（*此免疫保留至本回合结束，被击败后复活仍生效。）。

程序：DefenseProgram显式声明其他敌方攻击免疫和跨击败标志；复用防御效果建立，保留原攻击者席位。ActiveEffect增加默认省略的跨击败字段；取消函数按字段与新引擎过滤，旧存档字节与旧引擎行为不变。防御卡名及来源仍仅本人可见，公开保护提示不得泄漏牌名。

测试：成功/失败数值防御、忽略双向小兵修正；原攻击者可攻击、其他敌人不可攻击但可技能；友方可行动；同回合真实复活、回合末移除、吟游诗人取回取消；己方其他持续效果仍因击败消失；非法防御和幂等/私密显示/失败存档重放/旧64窗口。手工从攻击者完整行动开始前加载，强弱攻击分支测试失败与成功。
