# 潮水实施合同

正式源 arien-07-潮水：绿1，先攻4，主要技能0，远程2，次移2/次防3，无被动。

原文：“将你放置到攻击距离内没有出生点，且不与空的出生点相邻的格子内。”

复用潮汐之力的自放置程序与私有落点查询；使用远程图标及远程被动，不用范围或移动被动。D-029必须是不同的普通空格，不能落任何出生点。D-048按放置后占位判断相邻出生点是否空：英雄出生点和小兵出生点均包括，来源英雄腾出的出生格必须算空。因此从出生点A不能放到邻格B；相邻出生点由其他单位占据时不触发“空”的禁止。地图上所有出生点都检查，不只当前交战区正在使用的出生点。

放置无路径，不受普通移动边界约束；技能封锁仍禁止发动。无法放置沿用既有程序停止规则，不在本批实现用户另行暂缓的通用撤回功能。幻化等行动前能力按真正主要行动统一触发，不因放置再触发；没有新的小兵位移或兵战流程。

计划用独立PlacementTargetKind表示额外邻接过滤，共享查询和执行；不能修改潮汐之力的旧宽松过滤，也不能改伺机待发的未决障碍物语义。新引擎逐卡绑定，魔法水流下一版本复用，仅远程距离不同。

测试：空英雄/小兵出生点都禁止；来源腾空出生点禁止；被他人占据的相邻出生点允许；远程被动与错误被动；非法位置/席位/重试；静电边界与技能封锁；序列保存重放；旧档字节和潮汐之力仍允许邻空出生点。手工从阿连主要行动前加载，同时提供合法、空出生邻格及被占出生邻格供比较。
