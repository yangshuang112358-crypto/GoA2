# 虎爪·斗篷与匕首

准备合同，尚未实现。Q-11前置移动是否预检后续穿敌路线已询问，待答；以下步骤不代替该裁定。正式ID：tigerclaw-13-斗篷与匕首；紫卡、英雄8级持有。原文：“如果你处于免疫：在你执行（或重复）任何行动前，移动最多2格；在你执行基础攻击后，你可以对不同目标重复一次基础攻击。”

## 已裁定边界

- D-037：主要行动、次要移动、快速移动、防御响应全部属于行动前入口。牌文内部移动不另触发。该范围记TODO-003供用户日后平衡复查，不能重复询问已确定的范围。
- D-038：基础攻击首次加重复总计最多两次，第二个目标必须不同；描述已追加括号。重复的是完整基础攻击，瞬闪打击仍须再次沿直线移动2格并穿过一个敌方单位。
- 虎爪当前可以通过自己的伺机待发获得完整免疫。测试激活时使用明确相邻墙格，避免依赖U-017尚未确认的“单位也算障碍物”解释；不借机修正伺机待发。
- 紫卡自身不授予免疫、不延长到期；主要/次要牌的移动图标不增加这里写明的2格。

## 实施拆分

1. 精确紫卡注册、单独的免疫条件查询。只使用经证实的完整免疫来源；不得把防御加值、位移保护、仅部分攻击免疫都当作完整免疫。现有部分免疫牌属于其他英雄，虎爪不能装配它们来伪造正式联动。
2. 复用幻化的可保存行动前帧和原攻击保存方式，但新增“前置移动→恢复原行动选择”的继续点。幻化保存既定目的地是因为弃牌不改变位置；斗篷会改变位置，不能照抄既定目的地后直接恢复旧Move。
3. 主要行动应先完成紫卡0—2格移动，再进入主牌程序；若是瞬闪打击，随后重新计算它的直线穿敌路线，两个预算独立。紫卡移动不调用FinishAction，不重复触发自己。
4. 次要/快速移动先记行动模式，在前置移动结束后重新给出原移动的落点。快移继续检查前置移动后所在区域及敌人，不把前置两格当作快移区域扩展。
5. 基础攻击及全部已要求的防御后续完成后，询问是否重复；确认后再次进入前置移动，再重跑完整金牌程序。记录首次攻击目标、重复预算及是否已询问；从新位置重新生成合法路线并排除旧目标。不能复用横枪跃马“先选目标、再从Attack指令继续”的特定流程。
6. 普通红牌攻击不能得到紫卡重复。无免疫、免疫未生效或已经到期时不得额外移动/重复；通过前置移动合法性查询与窗口恢复维持规则核心权威。
7. 新字段默认值省略，旧engine57及之前窗口可按原版本恢复；胜利立即终止后续。拒绝、非法和重复提交均不能重复位移或消费两次牌。

## 验收与未来交互

- 正式可重放：用伺机待发在相邻墙处获得下回合免疫；次回合瞬闪打击先紫移、再金牌穿敌、正常防御/击败后选择重复、第二次紫移/穿不同敌人，最终只结算金牌一次。
