# 打断施法：行为合同

正式输入：arien-06-打断施法，艾瑞恩银牌，先攻12，基础技能0，范围2，无次要移动，次防3，无被动。

原文：“此回合：在技能范围内的敌方英雄不能执行技能。（打断施法不会阻止攻击行动。）”

本人实际执行主要基础技能时，建立此回合技能禁止范围，再结束本牌；暗选、揭示、次防或放弃不会提前生效。没有敌人也可建立范围。来源与创建轮/回合/顺序、起止时点可保存和重放。

范围是来源英雄当前格的2＋有效技能范围加成，动态检测敌方英雄；友方、来源自身、小兵不作为本牌的被禁止行动者。来源离场时没有可覆盖区域，状态仍按此回合持续期保存。

在范围内启动技能/基础技能主要行动受阻；以主要family=skill作为当前数据的类别入口。攻击（包括带范围图标的攻击）、主要移动、次要移动、快速移动、数值防御和主要防御响应不会被错误归入技能启动。受到适用免疫的目标仍按统一影响权限过滤。

不能以开始被禁止行动来消耗卡；查询给出禁止原因和来源，提交同样拒绝且零状态修改。合法的替代行动仍可执行。本牌自身没有移动槽，因此不能从技能0构造普通或快速移动。

验收：行动前无效果/行动后生效/回合末到期；范围2与3边界和对应加成；己方/敌方；敌方技能拒绝但攻击可用；防御与其他动作不受误封；保存恢复；两个来源；版本0/1保持旧能力，版本2或显式采用新版才开放。状态以content/status/cards.json实际证据为准。
