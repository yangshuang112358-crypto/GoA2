# 背刺：行为合同

虎爪红2，先攻9，非远程攻击4，次移5、次防6，未选图标先攻+1。原文：“选择与你相邻的一个单位为目标。如果有友方单位与目标相邻，则+2攻击。（友方单位是指除你以外的另一个己方队伍的英雄或小兵）”

依D-007选择相邻敌方单位并排除攻击免疫/重型保护。声明攻击时若目标1格内存在另一个同队英雄或任一同队小兵，则提供一次牌文+2，不随支援者人数累加。攻击者自己明确排除；敌方或距离2的友方不满足。支援者的种类、永久范围、远程图标都不能把相邻扩大。即便该支援兵受保护，只要其作为单位存在且相邻仍满足条件。

牌文支援与普通小兵攻击修正独立计算，保留支援单位来源。不能把友方小兵仅算作b项而漏掉额外+2；挑战者忽略小兵项时仍保留牌文条件。普通合法攻击小兵直接击败，只有英雄需要数值防御。

次防6/次移5/快速移动与放弃不执行主要攻击。升级选中获得影袭的防御+1，未选本牌获得先攻+1。引擎6开放；验收包括没有支援、排除自己、友方英雄/三种兵、敌方/远端排除、多个支援仅+2、合法相邻目标、数值与防御、恢复/重复、次要行动与被动来源。
