# 巨浪滔天实施合同

正式源 arien-05-巨浪滔天：红3，先攻9，远程2，攻击5，次移4/次防4，先攻被动。

原文：“选择攻击距离内的一个单位为目标。攻击后：将目标移动最多1格。将最多一个与你相邻的标志物或敌方单位推动1格。”

先按距离2执行攻击；攻击与防御完成后，原攻击目标仍在场且可受本攻击附带位移时，由阿连选择其最多1格普通移动，允许不移动。移动使用被移动单位通行能力和移动限制，不加阿连或目标移动被动；属于牌内移动，不再次触发幻化或斗篷“行动前”。移动后重算相邻敌方单位，任选至多一个固定推动1格，可以是原目标也可以是另一个目标。目标被击败时跳过其移动，仍允许推动其他单位。胜利立即中断。

实现复用OptionalTargetUnitMove与汹涌的ChooseUnitPush；前者此前只由友兵技能使用，接入攻击前需补齐CanDisplace(... attackAction:true)、当前目标存在和合法性查询。引擎77起生效，<=76旧存档字节及语义保持。所有位移完成后再处理离区小兵和反击队列，不在两段位移之间提前恢复父行动。

D-050当前六英雄没有地图标志物，推动标志物分支待扩展。

测试：移动0/1格后重算推动目标、原目标移入邻接后可被推、原目标死亡跳过移动、保护/攻击免疫、静电边界与推动区别、移动距离不加被动、反击严格等两段后、非控制者命令拒绝/私有候选、保存重放与旧引擎。手工从阿连行动前开始；原目标放在距离2，邻近另一个敌人供分支选择。

标志物分支待扩展（D-050）。
