# 火力掩护实施合同

正式源 sabina-15-火力掩护：蓝3，先攻10，主要技能0、范围3，次移3/次防4，攻击被动。

原文：“如果你与一个友方小兵相邻，则技能范围内的一名敌方英雄丢弃一张卡牌，否则被击败。”

发动主要技能后，萨彼娜须与实体友方小兵相邻；近战、远程、重型均可，受保护重型仍可满足存在条件。布罗根仅在兵战视为小兵，不能满足此处条件。目标为技能范围内非免疫敌方英雄，由萨彼娜选择；敌方手牌为空仍是合法目标。范围使用范围图标与范围被动，攻击/远程加成不改变范围。

目标有手牌时本人选择弃一张，或按D-036主动选择被击败；空手直接击败。使用现有TargetDiscardOrDefeat与ForcedPaymentProgress，不改近身支援“如果可行”的不同结果。失败指令不修改状态，支付窗口只向本人暴露候选，保存/重试不能重复奖励。

本效果不是攻击，不计算攻击/防御值，攻击免疫不阻止它，全行动免疫按来源查询。每次实际弃牌统一走DiscardCard，反击等到本次技能完成边界后执行；父牌仅结算一次。击败奖励、胜利终止、复活沿用通用规则。没有相邻友兵或合法敌人时按现有停止规则，不实现暂缓的通用撤回。

测试：邻友兵/敌兵区别、受保护重型、范围与加成、两名敌人可选；本人支付与私有性、错误选择与幂等；主动拒绝/空手击败及胜利；攻击免疫与全免疫区别；真实反击联动；旧引擎能力与保存字节。手工场景加载到萨彼娜主要行动前，附弃牌/拒绝/目标分支；反击场景先由玩家手动发动夏尔加萨的反击。
