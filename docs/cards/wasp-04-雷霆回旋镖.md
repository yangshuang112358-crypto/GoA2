# 雷霆回旋镖实施合同

2026-09-13；目标引擎19。wasp-04-雷霆回旋镖，黄蜂红3，先攻9，攻击4，远程3，次移4、次防4；未选候选提供移动被动。

原文：选择攻击距离内与你不在同一直线上的一个单位为目标。如果你击败一个敌方英雄，可以重复一次。

D-022历史用户裁定：远程加成参与目标高亮；每次击败英雄后均可选择重复，不是整张牌最多重复一次。直线沿用已验收的回旋镖规则，敌我、保护、免疫和防御沿用公共攻击规则。

有序程序：ChooseAttackTarget → Attack → OptionalRepeatAttackAfterHeroDefeat → End。初次选择强制；每次击败英雄后，若尚有合法目标，由黄蜂本人选择下一个目标，或者明确不重复。选择重复直接宣告下一次攻击，下一段完成后再检查条件。可在第二次击败英雄后继续打合法小兵；击败小兵、被抵挡、数值防御成功都不再允许重复。没有合法目标、来源离场或对局胜利时终止。不得把一次重复当作新卡或额外普通行动。

每次攻击独立保存目标、数值、结果和防御窗口；重复开始前清除上一段Attack/AttackOutcome，避免下一段击败小兵时泄漏上一名英雄的攻击结果。PendingChoice.Optional区分初次强制选择和重复可选，ResumeAt=repeat_attack；Cursor停在重复指令，可序列化恢复，不增加保存字段。每次击败独立发金币、助攻和水晶损失；命令幂等不能重复奖励。只在新引擎19注册，不改E18回旋镖窗口。

反制联动：防御成功后不重复，继续已有防御后处理；防御失败造成英雄击败后才可重复。现有屏障由黄蜂独占，正式选角禁止同名英雄，不能以两个黄蜂非法对局声称该联动已测。尚未实现的紫卡触发优先级仍在Q-02至06/U-008，不根据本卡发明大招时序；本卡只产生一次PrimaryActionStarted、每段一次AttackDeclared。

检查：连续击败两英雄后仍有第三次选择；主动停止、第二次防御成功、次防不足、第二次打兵、无下一目标、水晶归零立即结束；非直线/射程/远程物品、抵挡、初次不能跳过、选择者与非法目标、重复奖励幂等、首次及后续窗口保存恢复、E18原始保存。

手工起点：黄蜂完整Action，非直线虎爪、艾瑞恩和近战兵提供不同分支；亲自攻击并让目标选择防御。右侧最近记录给出重复、跳过、防御成功和攻击小兵的操作路线。
