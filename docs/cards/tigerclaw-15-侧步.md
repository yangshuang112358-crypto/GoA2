# 侧步实施合同

2026-09-13，目标引擎24。tigerclaw-15-侧步，虎爪蓝色2级，先攻11，主要防御0且有感叹号，次移3，无次防/范围/远程；升级被动攻击。

原文：抵挡一次远程攻击。若如此做，你可以沿直线移动2格。

可从手牌抵挡一次远程攻击，包含相邻的远程攻击；非远程或不可抵挡的攻击不能选此牌。防御牌照常丢弃，不提供免疫，不要求攻击者不相邻。仅成功抵挡才登记后续。

依现有R-COMBAT/防御反制顺序，先完成原攻击及攻击后文字，再由虎爪本人选择沿一条直线恰好移动2格或不移动。移动从届时虎爪的位置计算，不使用受击时旧位置。例如近身射击先将虎爪推1格，再计算侧步。路径每一步遵守普通占位/地形/静电边界；不能转弯、穿越单位、仅走1格或增加到3格。移动被动不加距离，不能替换快速移动。没有完整合法路线时自动跳过，原抵挡仍有效。

复用effect_move选择与ChooseEffectMove命令，ResumeAt=defense_response_move，ChooserSeat为防御者，执行中的原攻击者身份不变。DefenseResponse.Cursor记录0待选、1完成；位置查询从当前地图计算，待选格和来源仍在存档。提交合法路线或skip后继续EndCardExecution，防止重新执行攻击/推动。沿直线路径查询独立于普通可达区域，以便以后给其他牌使用。

公开UnitMoved仅报告移动者及路径，不公开原本私有的防御牌名；另用仅防御者可见的DefenseMoveResolved保留来源牌。Pending.SourcePrivateTo、跳过/选择事件同样保留防御牌隐私。其他席位可看到等待移动及地图，不获得操作者的EffectMoves查询结果，不能冒名提交。界面须容忍被遮蔽的空Source，不查找空卡牌ID。

测试：精确合同/版本、相邻和非相邻远程、非远程和不可抵挡拒绝、六向直线/中途阻挡/占位/地图边界、严格2格和不转弯、skip与无路、控制者/非法命令/重复、移动加成/静电限制、近身射击先推后侧步、保存响应窗口恢复、公开移动与私有来源、E23原档。无取回/弃牌额外选择、持续效果、重复攻击或金币变化；相关类别不适用。暗影步的换牌另外实施。

手工场景从攻击者完整Action开始，亲自攻击虎爪，再选择侧步。提供远程正常攻击与近身射击推动两个起点，在右侧记录写明路线/跳过/普通防御分支。
