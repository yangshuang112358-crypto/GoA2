# 偏转屏障：行为合同

黄蜂绿2牌，先攻3，主要防御!，次移2，无次防，升级未选图标先攻+1。原文：“如果攻击者不与你相邻，抵挡一次远程攻击。若如此做，攻击者丢弃一张卡牌（如果可行）。”

本人受到非相邻英雄的远程攻击时，可以从手牌选择本牌主要防御。它抵挡任意攻击值，但不能抵挡不可抵挡攻击，不能用来抵挡相邻或非远程攻击。手牌条件、弃防御牌时机及自身数值规则沿用抵挡屏障；牌面没有次防，不能退化成数值0响应。

“若如此做”仅在这次合法抵挡成功后排入防御后处理。依据D-011及规则历史的屏障反制裁定：本次攻击者有手牌时必须由本人选择一张弃置，无牌则自动继续，不提供可选跳过。目标固定为本次攻击者，不由黄蜂选择其他人。只用InHand牌，不用本次已揭示攻击牌或已出/已弃牌。

依R-DEFENSE，先完成攻击牌的攻击后/攻击结束后文字，再进行本牌的防御后处理；当前实现保存防御来源、控制者、本次攻击者、程序版本及游标，不能因为等待攻击者弃牌而重新开始攻击、重复弃防御牌或提前轮到下一名英雄。弃完或无牌完成后才结束原攻击牌流程。

本人暗选此牌不主动发动主要防御；次移、快速移动、普通弃牌不触发反制。升级选中时获得另一个候选的攻击+1，未选本牌时其先攻+1才进入永久加成，沿用既有升级来源账本。

新反制按引擎版本4开放，版本0—3仍明确显示此主要防御未实装。非法/冒名/空值提交原子拒绝；重发防御和弃牌命令不重复消费。完整存档保留来源；视图沿用当前U-006边界，不额外公开未揭示的弃牌身份。候选只投影给弃牌者，公开日志只显示弃牌颜色。

验收：非相邻远程成功、相邻/非远程/不可抵挡拒绝，负攻击值仍须选防御；攻击者有牌必选/无牌自动完成，错席位/非手牌/假跳过拒绝；防御→攻击后→反制→结束事件顺序，重复命令与弃牌窗口恢复，公开/私有投影、结构调试保护、升级被动及旧引擎隔离。后续免疫来源按对应牌合同接入。
