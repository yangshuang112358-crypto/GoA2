# 数据字典与内容变更

唯一正式源为 content/canonical 下四个 JSON。sources 是历史证据，docs/data/cards 是生成的阅读视图，content/status 是实现进度；三者不能反向覆盖正式文本。

| 文件 | 结构 | 用途 |
|---|---|---|
| heroes.json | schema_version、heroes | hero_id、name、legacy_default_team |
| cards.json | schema_version、cards | 108张完整正式卡面数据 |
| map.json | schema_version、map_id、coordinate_system、cells | 254格地图定义 |
| ruleset.json | schema_version、rules_version 及命名参数 | 基础设置/经济/初始兵数；不承载待确认效果语义 |
| content/status/cards.json | card_id、status、contract、implementation_files、tests、known_questions | 每卡证据状态；起始全为 data_only |
| content/manifest.json | 版本、预期数量、文件哈希 | 内容版本与传输完整性 |
| sources/card-provenance.json | hero/card 来源映射 | 正式JSON位置与原图/OCR组 |
| docs/data/卡牌机制索引.json | 各牌原文关键词、规格草稿 | 帮助安排实现，不是自动解释器 |

卡片字段：
- id：稳定历史 ID；不因改名而改变。不要求数字连续。
- hero_id：外键引用英雄。name 是卡名。
- color_key：gold/silver/red/green/blue/purple；中文由显示映射产生。
- level：金银为 null，三色为1/2/3，紫为4；不是英雄等级。
- initiative：基础先攻整数。
- secondary_actions：movement 与 defense，各含 type、has_action、value。false/null表示不存在；存在时为正整数。不将0当可用行动。
- primary_action：category 完整名称、family 规则族、text原文、value基础数值、exclamation、subtype。
- subtype：null 或 type=远程/范围 与正整数 value；无第二套 has_range/has_ranged 布尔字段。
- passive_bonus.type：null/攻击/防御/移动/先攻/范围/远程，每图标默认+1；被选卡提供主动，未选升级候选才提供底部被动。

地图字段：
- x/y 为 axial q/r，整数；跨层使用稳定坐标，不依赖场景 Transform。
- state 是 empty/terrain 或红蓝各英雄、近战、远程、重型出生点之一。
- obstacle、lane、base、region 原样保留。lane 不等于“当前战区”；当前战区是运行时状态。
- 地图出生标记不等于单位实例；占位单独存于 GameState。

本次迁移移除重复字段，但每个原字段保存在 sources/legacy。校验器重建来源对照，逐卡检查正式字段无损迁移。
文本可能有录入错字，不自动修正。修改前给出原文、图像、用户裁定与影响，用新 content_version 记录。

状态提升时必须有已解决疑问的正式合同，implemented及以上须有新版实现文件，测试状态须有新版测试证据文件；校验器拒绝用sources中的历史材料冒充新版完成。文件存在只是自动门槛，实际覆盖范围仍需审查。

校验：从仓库根运行 python -B tools/validate.py。
正式内容和新文本采用UTF-8/LF，manifest对实际文件字节计算SHA-256。sources保留原始字节且禁用Git换行转换；不要把工作树CRLF哈希带入LF提交。
该工具只用 Python 标准库；实现仓库所使用的有限 JSON Schema 关键字与额外领域约束，不宣称通用 JSON Schema 解释器。不执行 sources 下旧代码。
