# 攻击与防御执行合同

首批代表牌见docs/cards中的拔枪、快速突刺、抵挡屏障、躲闪、挑战者合同。优先实现完整的短程序，再扩展攻击前后效果；不对未登记的主要牌文执行一个省略文字的普通攻击。

开始主要行动是独立命令，确认后保存来源卡、控制者、程序标识/版本、步骤游标及目标引用；此后不能改用次要动作或Pass。目标选择、英雄防御、出生分别通过对应控制者的命令完成。没有合法目标的必做步骤结束剩余牌效；非法提交不改变已保存状态。

攻击明细保存牌面、有效攻击加成、敌方小兵支援b、友方近战保护c和最终值。远程关键词与技能范围分开。英雄本人从手牌选择合法主要或次要防御，可主动不防御；完全没有防御牌时直接击败，不能构造假牌。数值防御可以低于攻击并实际失败，最终攻击为负也不豁免出防御牌。

普通次防只弃牌并比较数值；主要防御必须执行该牌响应文字。没有实装的主要响应明确列为不可执行测试项，不假装按牌面数字完整处理，也不因为尚未实装而强制判定其持有者无牌并击败。该局部情形保留响应等待并允许本人主动不防御。

击败英雄：从地图移除，记录待复活，击杀者获得受害者等级金币，其队友按1/1/1/2/2/2/3/3获得助攻金；受害队伍水晶减少其等级并立即检查胜负。轮到受害者下一张牌行动时，由本人选空闲本队英雄出生点，复活后继续该张牌，不再扣水晶。满占位U-002保持明确待选择。

攻击小兵复用战场结算，保护检查在目标集合和命令处理两处一致；重型推进先完成出生再恢复执行步骤。所有暂停状态可保存重放。测试调试改变资源必须仍受原子和权限边界约束；不得用UI直接修改核心权威。
