# 联机入口一体化方案 · 2026-10-03

状态：调研与设计，尚未把EasyTier纳入游戏包。目标是四位中国好友免费试玩，减少手工IP、配置和文件选择；不承诺公共节点一直可用或低延迟。

## 可行方案

可将固定版本EasyTier命令行内核作为独立子进程随Windows包分发，由统一启动器生成配置、启动、检查状态和停止。玩家只看到“创建房间/加入好友”，不需要EasyTier GUI。官方提供命令行启动、配置文件和RPC管理入口；具体参数需以选择版本的help及实际协议验证，不能直接将最新版文档参数写入2.6.4。[命令行安装](https://easytier.rs/en/guide/installation.html) · [参数说明](https://easytier.rs/en/guide/network/configurations.html)

EasyTier负责设备互通；Goa2服务负责游戏身份和规则。两者可以共用一个入口，但网络密码不是游戏账号密码，不能合并为“同网即任意玩家”。当前固定席位凭据边界必须保留。

## 推荐逐步做

| 阶段 | 玩家体验 | 依赖与边界 |
|---|---|---|
| A 自动组网＋统一邀请，优先 | 房主点开房；好友首次选择一个邀请文件，之后点“加入”；配置与选IP自动完成 | 无中心账号服务；仍需一次私发邀请；内核随包，启动状态可诊断 |
| B 游戏内大厅 | 昵称、四个席位、队伍、准备、连接/版本状态都在游戏里 | 统一启动器先实现可靠内核管理，再将UI嵌入游戏；昵称只是显示名 |
| C 房间码/邀请链接 | 输入短码或点击链接就加入 | 需要可达的房间发现/邀请兑换服务，或使用较长的自包含邀请；短码不能凭空找到房主 |
| D 真账号登录 | 多设备身份、好友、历史战绩等 | 另需认证/存储/恢复/维护；四人试玩不必先建设它 |

推荐先A再B。完整账号、匹配、公共大厅暂缓。免费软件不等于永远免费的稳定中继基础设施；P2P优先、直连失败才中继，延迟与运营商实测。节点列表可更新，但任何切换必须保留现有房间身份，不能静默新建一局。

## A阶段的具体流程

房主：启动Goa2 → 选择昵称 → 创建房间 → 自动检查/启动本包EasyTier → 获取稳定地址 → 启动规则服务 → 生成三个独立一体化邀请 → 进入席位1。

好友：启动Goa2 → 导入自己的邀请一次 → 自动保存到本机私有目录 → 自动组网 → 检查版本与房主连通 → 用本人凭据认证 → 进入对应席位。以后同一仍运行房间可点“重新加入”。房主新开房，邀请必须更新。

首次创建Windows虚拟网卡可能需要管理员授权；程序应说明用途并显示系统授权，不承诺绝对零弹窗。已有EasyTier GUI时检查实例/地址/监听端口冲突，不能结束用户其他VPN进程或改系统默认路由。优先复用可确认属于本项目的子进程；退出只管理本项目创建的实例。

联网步骤显示为：检查程序 → 启动网络 → 等待虚拟IP → 寻找房主 → 验证身份 → 加入游戏。每步都有超时、取消、重试和错误原因，UI线程不做阻塞等待。游戏本体尚未启动时也能收集脱敏诊断。

## 配置能否直接合入

可以内置通用参数、经过审核的节点地址和资源版本；实际网络标识/密钥、每人虚拟IP、房间ID与席位凭据在创建房间时生成，装入对应邀请或安全兑换流程，保存在用户目录，不写进公共ZIP/仓库。

统一邀请建议有格式版本、有效范围、网络参数、游戏端点、固定席位凭据、规则/内容版本。它属于私密邀请，不能用公开下载链接分发；也不能让所有好友共享同一Host配置或同一席位凭据。

固定IP与自动分配二选一必须整体设计：可按房间网段及席位分配并检查本机网段冲突；若使用DHCP，必须让实际取得地址进入房间邀请并处理地址改变，不能生成邀请后再悄悄更换房主IP。VPN接入可能让同网设备互见，后续应限制范围，不能默认导出整段家庭局域网。

## 架构和发布边界

新增NetworkBootstrap/启动器服务层：进程生命周期、配置生成、状态/端口检查、邀请导入、版本校验、诊断打包。仍调用现有Goa2.Network与IPlayerSession；UI不执行规则；认证席位与本人投影不变。GameScreen仅由同一负责人顺序接线，先保留外部启动器作为失败时恢复入口。

统一打包加入固定版本内核、必要DLL、版本清单、校验哈希、第三方许可/源码材料。核对发现EasyTier **v2.6.4仓库LICENSE为LGPL-3.0**，不是文档网站页脚的Apache许可。分发前需按所选二进制及依赖确认对应源码、许可和告知义务，保留可替换的独立组件，不因“开源”跳过核对。[v2.6.4 LICENSE](https://github.com/EasyTier/EasyTier/blob/v2.6.4/LICENSE)

当前阶段不更改渲染、卡牌效果、存档语义；自动组网不等于云服务器保存对局。原房主关闭后，网络仍互通也不能自动继续对局，房间恢复另做。

## 验收标准

1. 干净Windows电脑未安装Unity/.NET SDK/EasyTier GUI，完整包可启动；首次权限说明明确。
2. 房主＋三人只用统一邀请，分别取得正确身份，暗选不泄露；不手填IP/TOML。
3. 初始节点不可达、VPN启动失败、IP冲突、版本错误、过期/非法邀请均有分阶段错误且UI可取消。
4. 重复启动、关闭再开、房主客户端退出、掉网重连不产生双实例抢端口、不误杀其他应用、不更改系统默认路由。
5. 已有EasyTier GUI/其他VPN时能识别冲突，回退手工模式；实际跨网测试直连与中继延迟和丢包。
6. 验证包不带开发机私有配置/账号/日志；安装/卸载、许可材料和失败回退可复核。
