# 轮末与升级执行合同

依据R-ROUND-END、R-UPGRADE与R-CARD-ZONES。第四回合结束自动进入RoundEnd；界面“结算轮末”提交ResolveRoundEnd，回收、兵线、升级、补偿和下一轮按下列步骤连续推进，只有规则要求的选择暂停。这个显式入口保留已有RoundEnd存档与历史命令的结果，不修改旧命令日志或伪造迁移。

1. 回收每人的已出与弃牌，重置本轮牌实例标记；出牌历史仍由揭示事件保留。紫卡独立拥有，不能进入手牌。
2. 对当前小兵总数作一次快照。相等直接进入升级；不等时由少兵方队长选择差值数量的小兵，逐个移除且不给金币。正常重型保护仍生效。
3. 移除重型立即推进并检查胜负；没有结束则先完成所有新战区出生，再进入本次轮末的升级。不得继续把旧数量差应用到新战区小兵。
4. 对每席按当前等级连续付费到不够钱或8级，记录每一级支出；2—7级产生各自的升级选择，8级选择并确认唯一紫卡（引擎0—8仍自动授予）。每席选择可独立推进，全部完成前不能开始下一轮。
5. 升级时从正式红绿蓝阶梯确定候选：尚有1级颜色时仅可升这些颜色到2，全部达到2后才可升3。同色两候选中选一张替换，另一张的被动图标+1，保存被动来源卡、授予等级和轮次。
6. 本轮升级前后等级相同者获得1金补偿，包括满级者；补偿在本轮付费与选择结束之后发放，不能反过来购买本轮升级。然后Round加1、Turn回1并开始暗选。

候选和未选卡来源只投影本人；每席是否仍待升级是公开进度。所有选择由核心查询，错误席位/颜色/候选/重复提交不得造成部分支出、重复被动或重复出生。升级暂停和兵线中断均可保存恢复。

沙盒装配只替换用于测试的卡面，不冒充付费升级。正式颜色阶梯从实际升级记录得到，因此测试装配的3级卡不会凭空消耗英雄升级权益；随后正式选择可以替换它。轮末已经扣费后调试添加金币留待之后使用，不重新开启同一轮付费。

紫卡获得和紫卡效果分别验收；未登记的持续文字必须明确显示待实施。U-001涉及尚未实施的轮末触发/清理交错，不能用这里的基础轮末顺序替未决联动做裁定。U-002仍保留满占位任务。

验收：零金币进入下一轮及次轮补偿可用；1/6/28/超额金币；三色阶梯与未选来源；多席交错选择；8级紫卡及补偿；兵数相等/差值/重型即时推进和占位恢复；旧59命令存档；错误权限与候选零修改；跨轮公开历史与弃牌回收。
