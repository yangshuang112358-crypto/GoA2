## 运行

在项目 Goa2V1 目录的 PowerShell 执行：

```powershell
# 本机四窗口：一个服务端，四个独立游戏身份
./network/start-room.ps1

# 局域网：填写房主电脑实际的局域网IPv4，仅自动开房主的第1席位
./network/start-room.ps1 -LanAddress 192.168.1.100 -OpenLocalPlayers 1
```

启动器会构建当前规则服务端，创建新的 artifacts/network/room-日期-编号，显示房间路径。默认运行现有 artifacts/player/Goa2V1.exe；不要用旧Player连接新服务。构建保留旧核心两个CS8602警告，其余错误仍会阻止启动。

朋友拿同一版完整Player文件夹/发行包，房主只将 `private/seat-1.private.json`、`seat-2.private.json`、`seat-3.private.json` 分别给另外三人。不要互换席位文件，也不要把整个private目录给朋友。各人在PowerShell执行：

```powershell
& 'D:/Goa2V1/Goa2V1.exe' -goaNetworkTicket 'D:/Goa2V1/seat-1.private.json' -screen-fullscreen 0 -screen-width 1600 -screen-height 1000
```

路径换成实际位置。也可用 `./network/join-room.ps1 -Ticket <自己的席位文件> -Player <Goa2V1.exe路径>`。联机状态/重连按钮在顶部；若窗口太小可先最大化。

本机四窗口验证不需要网络设置。多电脑必须可到达房主填写的私网IPv4和该房间端口；若Windows询问网络权限，仅在可信任的专用网络允许服务端。该版本没有公网匹配/中继/TLS，不直接支持异地公网连接，不需要也不建议为本批验收做公网端口转发。未自动改防火墙。

## 操作与首轮验收

1. 四人各选不同英雄；蓝/红队长分别安排本队英雄出生。
2. 各自技能环选择卡牌，可换牌、再次点取消；中心确认或Enter确认。四人确认后揭示。测试热座的“选完自动揭示”不适用于联机。
3. 按行动顺序执行；右上设置→行动里保留尚未迁到战场的操作。只有合法操作者有候选。响应/弃牌时由对应玩家操作。
4. 1—4只查看对应英雄，不改变登录身份；他人已装备技能名称公开，但暗选结果保持隐藏。
5. 弃牌预选只在本人画面出现；确认后各端收到公开弃牌并演出。断线重连会清空未提交的本地预选。
6. 顶部“断开”可手动测重连。断线停用操作；若上次结果未知，重连后点“查询/重试原操作”。复用原命令编号，不会把同一操作结算两次。
7. 完整走一轮、升级、英雄击败/复活、兵战及结算；检查四人看到的公开状态一致。

停止房间并保存：

```powershell
./network/stop-room.ps1 -Room '完整房间目录'
```

等待提示导出且Restore验证通过，再关闭房主。存档位于private/authority.private.save.json。当前启动器每次开新房；旧房存档重新开服/凭据恢复、服务端崩溃自动恢复尚未提供，不能把关闭服务当作客户端重连。客户端本地保存/读取/新对局/调试均隐藏。
