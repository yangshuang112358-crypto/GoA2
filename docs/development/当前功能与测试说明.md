## 接下来做牌的顺序

1. 偷袭：先完成攻击后可选普通移动，证明动作内移动预算、零步放弃和父行动继续。
2. 魅惑：主要移动与完整本轮防御修正一起完成，覆盖次要/快速替换、到期及保存断点。
3. 插入NET-01四身份连接验证，同时推进令他人弃牌、取回卡牌等独立代表牌。
4. 再做推动/放置/换位、条件与重复攻击、持续限制、防止击败与标记；最后逐张完成六紫卡及联动。

每张先确认牌文和操作者，写失败测试，再实现完整步骤、合法目标、无目标/空手分支及存档恢复，最后用真实Player验收。87张的逐张分组见[剩余卡牌开发路线](../planning/剩余卡牌开发路线.md)。引擎9已用于本批通用流程，后续新牌按下一次实际版本分配，不复用旧计划中的版本号。

## 手工测试

在项目根目录PowerShell执行 `./tools/run-player.ps1 -Qa`，默认1600×1000。QA保存使用artifacts/unity/qa-save.json，和普通游戏存档分开。已开QA窗口时先关闭，再启动脚本。

新局默认引擎9。读取旧存档后，须在全员未选牌、没有待处理选择的暗选阶段点“采用当前规则”，才使用本批紫卡确认流程；未采用时保留旧版自动领取语义。窄窗口可拖动卡牌区底部横向滚动条，滚轮滚动列表；展开全部面板时，外层画布也可滚动。

1. 点“调试→自动选英雄与出生”，按1—4切换；选择手牌，四人选完立即揭示。切为手动确认时，每席选牌后按空格确认。其他已有明确“确认”按钮的选择也可用空格；编辑输入框、图鉴或其他覆盖窗口时不会误提交底层确认。
2. “调试→攻击·地图选单位”：在暗选阶段设置0—99基础攻击，点合法敌人，再确认。小兵走正常移除/奖励和重型保护；英雄让其所属席位选防御或不防御，保留击败奖励、水晶与复活。此工具忽略距离，模拟非远程基础攻击，不执行借用来源卡的特殊文字，也不消耗正式出牌。测试远程/牌文请用对应牌或预设。
3. 升级：给本席设28金币，快速到轮末，点“行动→结算轮末”。三色各两张同时列出，完成一种颜色后该色禁用；选完六次普通升级，再点唯一紫卡并确认。左侧新增较大的常亮紫圈，悬浮可看牌文。
4. 升级后选卡，检查牌面右侧对应数值的绿色加号；揭示牌按有效先攻从高到低，顶端有红蓝队伍条与牌色条。卡牌区可横向/纵向滚动，四个面板仍可收起以扩大地图。
5. “图鉴108”按六颜色横排；搜索、英雄筛选和本局可用筛选仍可组合。“最近记录→展开”打开当前轮，上一轮/下一轮翻页，该轮所有可见事件都在滚动列表中。
6. 直接测战斗断点：点“调试→打开测试局面…”。也可先运行 `./tools/open-debug-position.ps1 -List` 查看预设，再运行 `./tools/open-debug-position.ps1 -Name axe-cost -ReplaceTrackedPlayer`。

## 自动测试如何运行

所有命令在Goa2V1根目录执行。核心仅需已安装的Unity；不需要先打开编辑器。运行UI脚本期间让游戏保持前台，脚本使用真实鼠标键盘，不与手工操作混用。

~~~powershell
# 全部共享核心NUnit；局部可加 -Filter Goa2.Tests.UpgradeTests
./tools/test-unity.ps1

# 内容、历史夹具及打包保护；若python为商店别名则指定真实解释器
./tools/validate.ps1 -PythonExe 'python.exe完整路径'

# 源码变化后构建一次
./tools/build-unity.ps1 -Task BuildWindows

# 30份场景，无窗口运行，每步检查结果与完整恢复重放
./tools/run-scenarios.ps1

# 同一场景可改为可见播放，支持暂停/单步
./tools/run-scenarios.ps1 -Scenario tests/scenarios/debug-attack.json -Visual -Paused -KeepOpen

# 本批新增实际界面验收
./tools/test-readability-ui.ps1 -Width 1600 -Height 1000

# 原有14模块实际键鼠回归；可用 -Case upgrade,gallery,combat 选子集
./tools/test-ui-suite.ps1 -Width 1600 -Height 1000
~~~

报告位置：核心artifacts/unity/tests，场景artifacts/scenarios，界面artifacts/unity/readability-ui-*与artifacts/ui-suites。每次唯一报告和截图保留失败证据。本机.NET测试宿主仍受Windows应用控制阻挡；使用Unity运行同一份核心测试，不宣称独立.NET宿主通过。
