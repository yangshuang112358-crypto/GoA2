# AI 教学预热与完整对局评测

后续已补[防御对比微调](AI防御对比微调-2026-10-07.md)：沿用本观察/编码格式，增加不同来源与模型实际遇到的局面，保持推理合法候选集合不变。本文仍作为最初教学与PPO对照入口。

在独立 `feature/ai-training` 工作树继续第二阶段基础。新增教学导出、公开特征编码和短时示范预热，再接原有 PPO；不改正式玩法、共享 Command/View、存档、网络或 GameScreen。

## 输入与版本

观察版本3、候选版本1、编码器版本2。当前牌只取现有公开 ActionSequence 的未完成焦点牌，攻击只复制本人视图已经公开的攻击方、防御方、目标、来源牌、基础值/加成/支援/护卫/最终值及不可防御标志。不读取暗选权威字段，队友与敌方隐藏选择继续使用同一隔离测试。

编码增加当前牌、队友/敌人公开装备的牌区统计、攻击标量、候选牌行动类别、目的地与敌方单位的六角格距离。这些距离是公开几何特征，不在 Python 实现卡牌规则或推测合法性。有效防御、合法目标仍来自 C# 查询，提交仍经 GameSession 校验。公开历史、持续效果精细语义、完整地图结构仍未充分编码；没有承诺支持未知单位/人数，现有显式拒绝机制保留。

旧观察格式2检查点明确拒绝，未迁移；默认配置模型也不自动接受其他水晶生命或标记阈值。提高推进标记阈值依然不会取消泉水胜利，未来实际改变推进次数需先明确泉水/地图规则。

## 教学数据

`ai/teaching-sources.json` 固定来源与分组；9个现有场景加4场历史正式对局的命令文件。正式前缀原件已复制进 `ai/teaching`，新检出无需依赖之前被忽略的 artifacts。种子101两次换边只供训练，102两次换边只供教学留出；场景按来源整组留出。数据是离线教学局面，不计入正式完局率或胜率。

CLI 按 ScenarioRunner 执行真实前缀并检查场景断言。每个决策只导出白名单 Observation、合法候选、来源及前缀编号、simple-v1 全部并列最佳动作 ID。每个示范标签在独立环境副本里实际提交一次，拒绝即保存权威现场并失败，不能换种子继续。若所有候选同分则没有教学区分信号，明确计入 UninformativeWindows 后不输出该行；没有删除任何行内部的合法候选。

Python 不读取权威存档或观众记录。`policy.jsonl` 是教学输入；完整场景原件另放 `authority`，按来源编号与前缀可以重建。加载教学数据时检查合同、来源组/来源哈希不能跨分组、标签非空且属于合法候选。没有把示范动作称为最优解：simple-v1 的弱点同样会被模仿。

预热按决策类别均匀采样，再在该类别内均匀采样局面。目标为并列示范动作的总概率，避免惩罚其他同分示范。默认200次、每批32行；重复采样不是新增独立数据。留出成绩不用于挑选轮数或回传梯度。随后重置优化器动量，使用团队终局奖励做一轮 PPO，价值网络没有获得伪造胜负标签。

## 启动与产物

已存在独立 `.venv-ai`，无需修改驱动或另装训练库。在 AI 工作树 PowerShell：

```powershell
./tools/run-ai-curriculum.ps1 -MaxMinutes 15 -WarmupUpdates 200 -EvalPairs 2
```

脚本重建 C#、导出带规则校验的教学数据、关闭空闲构建服务器，再运行 CPU 两线程短试。可用 `-Data <已有教学目录>` 复用合同完全匹配的数据；源码/规则/内容变化应重新导出并评测。输出目录必须全新，不覆盖失败案例。

15分钟预算仅约束学习/评测部分，导出教学数据额外计时；时间和4GiB内存余量在局边界及预热每20次更新处检查。当前对局/保存可能超过时间阈值。越界保存 failure 与已有证据，不能把部分评测算全批完成。本脚本最多30分钟，不是无人值守长训入口。

三个检查点 `initial.pt`、`warmup.pt`、`ppo.pt` 各配相同种子11001/11002和换边的完整局评测。其他三席均冻结 simple-v1，学习席位为黄蜂。教学 train/holdout 指标在 teaching.json，正式结果在 evaluation.json，PPO样本在 episodes/learning，资源在 resources，版本/配置/源码及数据哈希在 manifest。检查点含模型、优化器、随机状态、合同、源码和对应评测旁文件。

当前 `curriculum.py` 是固定三阶段实验入口，没有自己的续跑命令；不能用通用 train.py 的 resume 绕过训练配置/源码检查。恢复推理已经逐检查点比较一致，可靠恢复长训仍需单独验收。

可用现有 CLI export-replay 和 tools/replay-ai.ps1 导出并验证正式局。策略输入与公共观众事件分开保存；Unity验证重放并不意味着 Unity 已部署神经网络或已完成视频录屏。实测结果见本次教学验收文档。
