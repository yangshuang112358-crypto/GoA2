# 战场结算合同

依据规则手册 R-UNITS、R-DEFEAT、R-MINIONS、R-VICTORY；这是已有裁定的工程映射，不是新增桌游规则。

- 普通击败/移除查询排除仍有其他友方小兵保护的重型。沙盒的“击败小兵”和“移除小兵”可以绕过保护；前者由指定敌方玩家得到近战/远程2金、重型4金，后者不给金币。正式攻击和轮末分别复用对应的结算原语。
- 任意来源移除重型，先移除目标、清理旧兵，再更新战区与获胜方累计推进标记。标记达到配置阈值或进入敌方泉水立即结束，不再出生小兵。标记与战区分别存储。
- 未胜利时读取新战区全部正式出生标记；空出生点生成小兵。被占出生点保留待出生记录，由对应队长选择相邻空地，不能越界、落障碍或重叠。不同出生点合法替代格互不冲突时，其处理顺序不影响最终可选集合。
- 多个被占出生点争用相邻空格的先后仍待用户回答，记录为 U-012。此局面停在明确的待裁定状态，不通过代码遍历顺序决定利益归属。全部相邻格被占按 U-002保留等待，不删除出生任务或擅自挤走单位。
- 推进期间保存原阶段、行动席位、原待选择及结算来源；出生完成后恢复。每次出生选择都是独立原子命令；重放中途存档得到相同任务和合法格。推进完成不能重新执行已经发放的金币。
- 胜利后拒绝继续改变本局；沙盒可以通过设置任一队水晶为0触发同一胜负路径。设置水晶为0不是正常伤害或击败，不附送金币。
- 初始单位ID保持旧存档兼容；推进后的单位ID包含出生代数，避免已移除单位的引用错误指向新小兵。已有命令字段、枚举数值和历史事件字面文本不变。

验收：保护查询、金币差异、立即推进、红蓝方向与11兵不对称、累计标记胜利、泉水胜利、胜后禁止命令、单阻塞出生与错误队长/非法格原子拒绝、出生中存读档、原先攻选择恢复、未决出生不丢任务。
