# 紫卡与兵战接线说明

2026-09-26，给后续逐卡开发读取。具体裁定以D-034—043、正式卡合同为准；验收数字见各card-batch-engine*.json。本页说明已有接口与下一张接入点，不代替卡牌原文。

## 从哪里接入

| 用途 | 入口与状态 | 关键约束 |
|---|---|---|
| 持有紫卡能力 | UltimatePrograms精确牌文绑定；UltimateRules.OwnedProgram | 英雄在场、所属英雄及PurpleCardId匹配；紫卡不进入手牌或ActiveEffect列表。旧引擎按注册版本门控 |
| 基础攻击数值 | UltimateRules.BasicAttackBonus/BasicAttackRangeBonus | 重型枪械只加基础攻击；不要把紫卡加成混入永久成长数值 |
| 行动前 | BeforeActionRules / BeforeActionFrame | 保存原命令和父状态。幻化先选目标/弃牌；斗篷先移最多2格。内部牌文移动不再触发新行动 |
| 斗篷移动入口 | Move命令Value=begin，CanBeginMovementPrelude | 紫卡位移与原行动位移分开；原移动候选在紫卡移动后重新生成；D-041允许前移后无穿敌路线并保留位置 |
| 斗篷重复 | UltimateRepeatUsed、UltimateRepeatExcludedTarget | 基础攻击最多两次，第二次从金牌程序第一步执行并排除首次目标单位ID；重复前也有紫卡移动 |
| 行动完成 | EndCardExecution → BeginPrimaryCompletion / ActionCompletionProgress | 停止的行动不触发；先完成防御后续及兵回归。电闪雷鸣选敌人再弃牌，潮汐之主选是否兵战 |
| 弃牌否则击败 | ForcedPaymentRules.BeginForcedPayment / ForcedPaymentProgress | D-036允许有牌主动拒绝；空手直接击败。新技能可复用支付原语，但须自己正确筛选目标及推进指令游标 |
| 兵战英雄角色 | MinionBattleParticipantRules | 一人成军在场任意区域计2；不要改UnitState.Kind或普通攻击支援。兵战内候选单独保护重型 |
| 轮中兵战 | ActionCompletionProgress.ActionBattle | 阿连必须在当前交战区；父CardExecution保留。只做兵战；不调用ResolveRoundEnd/BeginUpgrades |
| 推进后恢复 | FrontlineTransition.ResumeActionMinionBattle | 出生选择完成后回轮中兵战；胜利直接清除父执行。普通轮末仍用ResumeRoundEnd |
| 小兵击败保护 | EffectRules.MinionDefeatProtectors / PendingMinionDefeat | 保卫近战、持盾非重型、巩固防线全部实体友兵；受保护重型仍免疫此技能。兵战移除/清场不进入击败保护 |

## 后续卡牌必须保留的边界

- 所有新推动指令在合法推动结算后接AfterHeroPushed。D-035合法受阻0格算推动；免疫使推动根本不能发生时不能调用。支付选择结束前不能继续后续牌文。
- “如果可行弃牌”与“弃牌否则被击败”是不同原语。前者有牌必弃，空手跳过；后者按D-036允许选择被击败。勿把电闪雷鸣/幻化改成可随意跳弃牌。
- 真实轮中兵战与轮末兵战各有恢复原因；公共候选方法供界面使用，不把轮中状态塞进RoundEnd。视图和ScenarioRunner均要读取轮中剩余移除数。
- 每次新存档字段考虑默认省略。不能往旧原始夹具补字段；manifest捕获原始字节。构建后再运行最终Editor场景，让报告里的程序集哈希与构建一致。
- 现有BeforeActionFrame、ActionCompletionProgress和FrontlineTransition是明确用途的恢复记录。反击仍需要“致弃行动实例”与从弃牌堆执行的父子帧，不能直接递归BeginPrimary，也不能假设ActiveCard总是当前反击来源。
- 新牌先读其合同和最近同机制测试即可，无需重读所有长历史。巩固防线使用原有支付/防止击败流程，仅增加覆盖种类和版本注册；后续同类牌优先采用这种局部扩展。

## 本批可复用证据

CloakAndDaggerTests覆盖两次完整瞬闪、不同目标、失败保留紫卡位移与两段移动；OneManArmyTests覆盖两队队长、远程先移/英雄先选和升级恢复；LordOfTidesTests覆盖双方兵战、与一人成军组合、出生等待、胜利和不执行轮末流程；FortifyTests覆盖重型保护与支付、潮汐之主移除反例及旧持盾存档。

这些证据不代表已完成未来反击、地形化、标记或全部未实装牌的组合验收；每张落地时仍补它引入的真实交互。
