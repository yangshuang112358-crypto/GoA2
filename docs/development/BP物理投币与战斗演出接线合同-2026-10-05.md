# BP、物理投币与战斗演出的下一批合同

这是待实施设计，不能把本文件当作功能已上线。本批先交付独立 UI 与美术样例；以下共享机制建议切到极高档集中复核。档位不代替测试，ultra 不是必要条件。

2026-10-05后续反馈：配合 `docs/planning/对局演出与BP改版-2026-10-05.md` 末节F01—F14/P01—P05实施。横幅5秒并加阶段说明；兵种须完成正确握持、朝向攻防目标及取箭/举盾/出招回位，不能把现有准备姿态当成已验收动作。当前素材与程序尚未据本轮反馈修改。

## 用户已确认

1. 房主 Unity 客户端物理模拟，房间服务记录结果；其他客户端只观看。
2. 卡边长时间无法定面时，四个席位全部同意才重抛；缺人等待，不设置房主强制票。
3. 一局两次投币：BP 猜先与正式对局开局；后续普通决策币切面为快速半圈。
4. BP 按队伍1–2–1，同队未选人者先成功提交者取得英雄；人人可看介绍，只有本轮可选席位有提交入口。
5. 等级仅预告为1→3，本轮实际仍1级，轮末扣费与升级。

## 权威接口

- 保持纯 C# 核心与 .NET 房间服务无 Unity 依赖。为新行为新增引擎版本，不改旧 engine97 存档与重放语义。
- 增加可序列化 `DraftState`：初始队伍、当前段索引、段内已选数、英雄与席位绑定。服务端验证该席位尚未选人、队伍符合、英雄未占用、配额尚有余量；接受一次命令同时更新全部字段。
- 同队并发提交须同一房间命令队列串行执行。失败者收到新投影重新选择；绝不自动替换他提交的英雄，不因客户端按钮禁用而省略服务端校验。
- 增加 `CoinTossState`：唯一 tossId、用途（draft/opening）、主持席位、状态、最终面、最终姿态、公开重投投票集合、已接受结果的事件ID。
- 服务端以经过认证的房主身份接受结果，普通玩家不能提交最终面；同一 tossId 已落定后不能再次改变结果。新投币清空旧票，重复投票幂等，旧 tossId 投票拒绝且不部分修改。
- 房主仍是可信权威，并非防作弊物理证明。服务端检查消息大小、阶段、身份、数值有限、合理速度/姿态/时限；不可声称服务端重新验证了 Unity 模拟。
- 暂态运动帧与规则命令分离：帧带 tossId、递增帧号、位置、旋转、时间；客户端插值而不独立裁定。最终落面写入持久事件/快照；重放使用记录结果与轨迹，不重新跑随机物理。
- 统一规范化模拟舞台，使不同分辨率观看同一轨迹。BP 舞台映射窗口边界，开局舞台映射屏幕边界；不能让各客户端屏幕尺寸影响落面。
- 新客户端能力/契约校验明确拒绝旧协议入新 BP 房间。游戏包与房主服务必须同批构建，不能只更新 Unity。

## 投币状态机与断线

`等待阶段横幅 → 主持掷出 → 同步滚动 → 稳定判面 → 服务端接受 → 缓入目标位置`。

若速度很低但币面法线长期不在可判定阈值内，则进入 `等待四票`；不得偷偷重掷到想要的颜色。四票通过后开始新 tossId。物理复位只在新投币时进行。

主持掉线：保持本次已记录状态与已投票者，停止接受匿名帧，展示缺席者。重连主持从服务端状态恢复；已经接受结果不得再掷。主持更换、房主崩溃恢复不在当前承诺内，不能假装已有自动接管。

核心不依赖客户端动画结束：结果接受之后按明确的公共事件边界推进下一阶段；界面可以先播完当前演出，但旧按钮必须通过 revision、阶段、席位和选择ID校验，不能穿透提交。

## 战斗表现时间线

核心继续立即、可重放地结算；展示按公开事件形成有界的演出队列。

1. 保留攻击者、目标与参与小兵的公开动作快照。
2. 响应方卡牌环展开；本地预选不广播。确定后播放公开弃牌翻面与收环。
3. 参与者出招，箭矢到目标位置；已经被核心移除的目标使用短暂展示残影，不能重新变成可选棋子。
4. 执行击败、晶体破碎、金币喷出。来自 `GoldAwarded` / `AssistGoldAwarded` 的数额、归属必须逐事件读取，禁止自行算另一套助攻奖励。
5. 奖励币使用隔离的展示物理场景：滚碰3秒，再关碰撞吸入对应英雄；英雄不在场时吸入其公开出生点/经验栏的约定需要具体设计后记录。
6. 金币到达后只释放可见经验计数差额，不能延后服务器实际金币；合法升级/转移仍由实时投影决定。轮末或重连必须快进/对齐未完成奖励，防止旧动画把新金币覆盖。

多次弃牌、反击、重复攻击会在一个命令内产生多个事件。按命令/行动因果绑定奖励，不能把“最后被击败的人”无限沿用给后续无关金币。断线加载历史事件不重播喷币，不发双份音效。跳过/重播调试也不得改真实奖励。

## 关键验收

- 红先/蓝先全部1–2–1路径；同队同英雄竞争/不同英雄竞争；错误队、重复选人、满配额拒绝，状态零部分修改。
- 只有房主可定面，重复结果/旧投币结果/NaN轨迹/超大轨迹拒绝；四票幂等、缺一票保持等待、旧票不跨投。
- 重连于掷出、卡边、已定面、动画归位各点，最终队伍、名额、决策币全席一致；快照恢复不二次投币。
- 阶段横幅先于镜头和投币，手动自由观看不被夺回；不同分辨率轨迹同面，不因窗口尺寸改变物理裁定。
- 攻击成功/防御成功/主动不防御/弃牌反制/反击嵌套/两次攻击、助攻者离场、攻击后立刻新阶段、掉线重连、胜利中断。
- 真实四机网络验收仍由用户后续完成，本机四席不能替代。
