# 发布与回退

当前已有本地Windows开发程序artifacts/player/Goa2V1.exe，可以测试已实装的对局流程；尚未作为完整游戏对外发布。资料基线与程序能力分别记录，卡牌状态表不等同于发行完成度。
后续每个发布候选须记录程序版本、规则版本、内容哈希、协议与存档版本、构建环境、commit、测试报告和已知问题。
发布前检查：全卡状态证据、完整对局、非法命令/私有数据、重连、长局、存档迁移、回放一致性、Player构建启动。
使用独立输出目录保存构建；日志避免完整手牌或身份令牌进入公共客户端。
回退优先恢复上一已验收构建与兼容内容包；新存档若不兼容不得直接交给旧程序，保留原存档并提供迁移/拒绝提示。
线上部署、外部服务费用和发行目标在相应任务确定，资料包不擅自创建账号、外部仓库或发布。
