# 卡牌与联机、UI的接口增量

2026-09-27更新：experiment/ai-level-20260920现由总控持有，UI已于4f4a629合入engine79；新卡牌工作准备交给独立feature/cards，详见docs/handoffs/cards.md。联机与UI继续各自feature/network、feature/ui-3d工作树，联机尚未接线。本文用于源码整合，不表示已完成联网验收。双方基线较旧时，应读取本文件及最新卡牌验收记录，不根据旧完成数量推测能力。

公共入口保持 GameSession.Execute(认证席位, Command) 与 View(席位)。以下卡牌没有新增外部命令类型；合法目标和选择者仍由本人视图返回。不能仅按Pending.Kind猜测完整语义，ResumeAt用于区分同一命令中的具体步骤。

| 引擎 | 卡牌/窗口 | 接入要点 |
|---|---|---|
| 67 | 海妖之歌：effect_target / approach_target | ChooseEffectTarget选最近合法敌方单位；可以是小兵，不只英雄。首次不能skip |
| 67 | 海妖之歌：effect_move / approach_move | ChooseEffectMove移动Pending.UnitId对应单位，来源控制者选择落点；skip为不移动 |
| 67 | 海妖之歌：effect_target / approach_repeat | 同一ChooseEffectTarget命令，Optional=true时skip表示不重复；候选重算，可能重新选同一单位 |
| 68—69 | 潮水/魔法水流：placement / self_placement | ChoosePlacement；从Placements读候选，不能在客户端按放置前占位自行计算空出生点 |
| 70 | 火力掩护：forced_discard / card_forced_payment | 目标本人ForcedDiscard或DeclineRetaliationDiscard；通过CanDeclineRetaliationDiscard显示被击败选项 |
| 71 | 电能爆炸：effect_target / attack_before_optional_discard | 可选额外英雄或skip；随后仍攻击原主目标，额外目标不替换原攻击目标 |
| 71 | 电能爆炸：forced_discard / card_forced_payment | 同一支付窗口可能发生在攻击前，不可显示“攻击已结算”或“推动已结算”。支付后可能进入原目标防御，也可能因胜利立即结束 |
| 72 | 冲拳：effect_target / single_push_target | ChooseEffectTarget选择本牌允许的相邻敌方单位；当前冲拳只允许小兵，不能按通用“单位”文字擅自开放英雄 |
| 72 | 冲拳：effect_move / single_push_distance | ChooseEffectMove承载推动落点，目标是Pending.UnitId；界面应显示推动而不是普通移动。skip表示主动不推动；合法受阻0格的推动会由规则直接结算 |

| 73—74 | 碾压重拳/野蛮飞踢：effect_move 后接 single_push_target | 先由来源英雄移动0或1格，重算邻接目标；野蛮飞踢可选英雄，碾压重拳仅小兵。后续推动仍使用原窗口；幻化被推时候选可能跳过障碍中间格，动画保留完整Path但禁止点击中间障碍作为终点 |

| 75 | 汹涌：攻击后 single_push_target | Optional=true，可不选目标；选中后固定推1格，不会再出现距离选择。不可假定每个single_push_target都有下一页 |

| 76—77 | 潮起/巨浪滔天：攻击后位移 | 潮起同汹涌；巨浪滔天先进入effect_move/target_unit_move，再重算single_push_target。target_unit_move现在也可能移动敌方英雄，不能硬编码为友方小兵。两段由阿连选择，之后才恢复反击队列 |

| 78 | 意念操控：effect_target/unit_placement_target → placement/unit_placement | ChooseEffectTarget可选规则允许的任一阵营单位；ChoosePlacement移动Pending.UnitId对象，不是来源本人。首次目标及落点都不可skip。候选Placements仅给当前选择者，小兵随后可能进入回归 |

| 79 | 心灵控制：effect_target/unit_placement_repeat | 首次放置及小兵回归完成后才出现，Optional=true可skip；否则重新选择合法目标及落点。最多重复一次，不允许客户端直接重发首次动作来代表第二次 |

| 80 | 移形换步：effect_target/unit_swap | 与旧换位共用ChooseEffectTarget，可选本牌允许的敌/友英雄与小兵；客户端不得硬编码只许友方英雄。候选、保护、原子交换与小兵回归均由核心决定 |

| 81 | 激流：effect_target/attack_before_required_discard | 有合法后方英雄必须选，Optional=false无跳过；无目标按D-052直接继续原攻击。后方英雄本人沿用forced_discard/card_forced_payment支付或拒绝；主攻击目标保留 |

| 82 | 惊涛骇浪：attack_target/repeat_once_different_full | Optional=true可skip；重复重新执行后方支付及攻击，排除首次主目标且最多两次。反击先于重复窗口；没有邻接敌英雄也可攻击合法小兵。核心提供候选，UI仅更新提示 |

| 83 | 控物：effect_target/orbital_target → effect_move/target_unit_move | 只能选其他非相邻合法单位；等距落点由核心EffectMoves提供，可以0步。沿用ChooseEffectTarget/ChooseEffectMove，小兵回归先于结束；地图标志物D-050仍待扩展 |

| 84 | 引力控制：effect_target/orbital_repeat | 小兵回归完成后提供重复；Optional=true可skip。可重选同一合法单位或换目标，另起行动实例，最多重复一次。0步消耗一次，不重复则结束剩余步骤 |

| 85 | 意念黑洞：沿用orbital_target/orbital_repeat/target_unit_move | 最多两次重复，总计三次独立1格行动，每次都可换目标及0步。任意重复窗口skip结束全部剩余次数；不增加Command/View字段 |

| 86 | 魅惑：主要移动后创建本轮效果 | 新EnemyMeleeFriendlyForOwnDefense效果仅改变本人AttackBreakdown的小兵支持/守卫，不改变Unit.Team；真实攻击与DebugAttack共同使用防御阵营查询，既有Command/View字段保持 |

| 87 | 统治领域：本人防御小兵阵营视图扩至远程 | 新EnemyLightMinionsFriendlyForOwnDefense；保护中重型仍免疫，即使被其他牌视为远程也不豁免。没有新的选择窗口 |

所有窗口都可能被既有幻化、弃牌反击、小兵回归等窗口插入；恢复后按最新视图重建，不把本地按钮选择当权威状态。操作后等待提交结果，动画不能自行推进阶段，重连不重播奖励。用CandidateUnits/EffectTargets、EffectMoves、Placements等现有私有候选；其他席位不能借公开Pending读取或推算本人以外的手牌。

本批现有界面接线主要涉及 GameScreen.Combat.cs 中选择提示；未改棋盘布局和3D几何。UI分支对 GameScreen.Layout.cs 的改动应单独审查后合并。统一构建须采用同一套Domain/Rules/Application/Infrastructure与正式内容，不单独替换某个DLL；联网握手按引擎和内容版本拒绝不匹配。

整合时至少跑：海妖两次目标、一次小兵回归、放置后出生点筛选、火力掩护目标拒绝、电能爆炸额外弃牌后原目标防御、弃牌触发反击。卡牌场景证据不替代四客户端真实传输或新3D界面的实际输入验收。

通用行动预览/撤回仍按原待办暂缓；新增按钮不能回滚已经发生的弃牌或对方响应。遇到新的交互要求改变提交时机、身份或规则含义时，先记录冲突和建议，由主任务协调；独立显示优化继续进行。

## 引擎89：滑溜溜

追加EnemyActionMovementLimitOne持续效果，查询主移动/次移动/快速移动合法落点时施加起点半径与1格上限；无新增命令或待选择字段。现有SourceCardId和Window可直接展示。网络继续消费本人投影，不在客户端重算范围。内部移动不限制；BeforeAction之后按新起点查询。

## 引擎90：洪水

复用EnemyActionMovementLimitOne，EffectDuration追加ThisAndNextTurn（旧三种枚举值不变），Window仍以同一轮的开始/结束回合表达，末回合截断。无新增命令及待选择类型，客户端显示实际窗口，不按持续期枚举自行推算跨轮。

## 引擎91：中毒标记及有效被动投影

GameState追加可空PoisonMarkers，旧档省略空字段；TargetSeat/SourceSeat/SourceCardId/AppliedRound/IncludesDefense明确保存。独立于ActiveEffect取消，D-060来源/持有者被击败、来源牌取回不移除；轮末清除。重复施毒不叠加。PlayerView追加EffectiveBonuses、IsPoisoned、PoisonIncludesDefense，PermanentBonuses仍保持真实升级账面；卡牌及左栏读有效值，升级记录仍显示账面。旧展示构造未提供有效值时回退原字段。网络版本升级时需同步此投影，当前engine66网络工作树尚未接入。新事件PoisonApplied/PoisonUnchanged/PoisonExpired为公开结果，目标选择仍复用本人effect_target窗口，无新Command。

## 引擎93：动态相邻禁移及来源卡色

追加EnemyMovementGoldOrRedOnly、NextTurn及Adjacent范围，目标每次移动重新查询，不保存目标名单。Reachable/StraightExact从执行实例或已揭示牌读取来源，防御和紫卡前置显式传实际来源牌；独立接近路径同步检查。Fast单独检查。推动不调用该禁移查询；放置/换位保留原语义。主要移动绑定表增加明确可空subtype，旧范围牌匹配保持严格。无新命令或持久化选择字段。

## 引擎94：死亡缠绕

追加EnemyMovementGoldOnly，复用动态相邻和移动来源查询；仅金色例外。红牌攻击本身可执行，其内部移动被限制；若该攻击先击败持续来源，随后移动重新按已取消后的效果集合查询。无新命令/存档字段。
