# 新手教程使用与维护

## 本批内容

目标对象是完全没玩过 GoA2 的玩家。目标时长 8—10 分钟，尚需真人新手计时；程序测试不代表新手已经学会。

教程使用萨彼娜，玩家始终是蓝方席位 1；其他三席为固定合法陪练，不是通用对战 AI。十个短章节分别为镜头与移动、暗选与先攻、英雄攻击与水晶、防御与手牌条、普通小兵、重型与推进、轮末兵战、卡牌升级、八级紫卡、自主练习。

五类数值随操作讲解：

| 位置 | 数值 | 教学时点 |
|---|---|---|
| 左上 | 次要移动值 | 预览移动、撤回，再实际移动 |
| 底部 | 先攻值 | 四人暗选确认后揭牌，数值大者先行动 |
| 左下 | 主要行动值 | 攻击前说明攻击基础值，区分移动类主行动、零值技能 |
| 右下 | 距离／范围 | 选择攻击目标时，结合拔枪射程与不能攻击相邻单位的牌文 |
| 右上 | 次要防御值 | 敌方攻击本人后，实际使用拔枪防御；对比公开算式 |

攻防结束后才系统讲五色手牌条。英雄击败与水晶生命、普通兵／重型兵、即时／轮末推进和两种获胜路线均在首课。真实等级与扣费仍在轮末；升级同色替换、未选路线被动、三色阶梯和紫卡持续能力均有说明与实际选择。

## 启动

新构建支持：

```powershell
.\Goa2V1.exe -goaTutorial -screen-fullscreen 0 -screen-width 1600 -screen-height 1000
```

桌面独立教程快捷方式指向新版预览 Player，具体交付路径与实际验证以本批验收记录为准。本地游戏设置内也可进入“新手教程 · 独立练习”；退出恢复进入教程前的内存对局。联机邀请启动优先于教程参数，游戏中的联机设置只提供只读帮助，不把真实房间切换成教学局。

打开后选择“继续”或某一章节。进度按章节保存，继续会从该章起点重新开始。重试、目录、回到行动随时可用。课程说明可以收起；收起后陪练暂停，重新展开继续。操作仍使用当前游戏界面：右键技能读牌，Enter确认，右侧深灰按钮撤回，空格／右下返回当前行动，中键拖动、滚轮缩放。

教程进度默认存于 Unity 的 persistentDataPath 下 `tutorial/progress-v1.json`；测试可用 `-goaTutorialProgress <独立文件>` 指定位置。此文件只含章节、完成标记和教程设置，不含邀请、房间数据或真实对局。普通“保存”路径不会被教程写入。退出客户端也保留当前章节；并不承诺逐步恢复教程中间的一次待选动作。

## 实现边界

- `TutorialCourse` 在 Infrastructure 层构造独立局面，用普通 `GameSession.Execute` 执行玩家与陪练动作，不改规则引擎版本。
- 调试命令只用来构造章节起点；实操期间禁止调试、代操、跳过教学行为。初始设置可重放；攻击教学从完整行动开始，防御课由敌人实际宣告攻击。
- 规则动作只有被接受后才推进步骤。读牌、移动预览与撤回是本地 UI 手势，只推进对应界面练习，不假装发生规则动作。说明页由玩家读完后继续。
- 各教学文本有稳定 `TutorialLine.Id`，后续可用这些 ID 绑定配音，不在本批合成配音。
- 章节加载时跳过历史开局投币演出；真实动作产生的战斗、弃牌和推进演出照常播放。5秒阶段横幅及镜头优先于教学提示。
- 新手时长、误点率、内容理解仍须人测。首课不讲全108张卡，不裁定未决规则；联机异地验收仍由用户进行。

## 后续维护提示词

> 请维护 Goa2V1 新手教程。先读取 AGENTS.md、本文件和本批教程验收记录。保留真实规则、本人席位、独立进度与正式逐人确认；不要将卡牌教学改成调试攻击。按反馈修改对应 TutorialLine.Id 及 UI 引导，完整走完受影响章节，核对普通对局与邀请入口未被教程接管。构建并更新桌面教程入口，说明旧联机压缩包是否已重打。

## 验证入口

```powershell
./tools/test-unity.ps1 -Graphics -Assemblies 'Goa2.Core.Tests' -Filter 'Goa2.Tests.TutorialTests' -ReportName tutorial
./tools/ui3d/audit.ps1 -Width 1280 -Height 720 -TutorialOnly
./tools/build-unity.ps1
./tools/ui3d/audit.ps1 -Width 1600 -Height 1000 -TutorialOnly -Player
```

渲染验收用真实 UI 对象、合成事件与确认回调，不是 OS 键鼠或真人理解测试。失败日志保留；最终报告必须与构建源码一致。
