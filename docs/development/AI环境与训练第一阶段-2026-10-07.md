基线 e8ca1cc，engine98；分支 feature/ai-training。主工作树、main、engine34 与 Workbench.blend 均不修改。新增代码在 ai/；不改共享 Command/View、存档、网络协议或 GameScreen。

本阶段已完成，实测、启动、Unity重放与后续预算见[第一阶段验收](../verification/AI第一阶段验收-2026-10-07.md)。10场正式评测8完局/2截断；未启动长训或训练模型。

## 架构与边界

- C# HeadlessEnvironment 独占 GameSession。Next 返回实际选择者、白名单观察及规则查询候选；Submit 接收 revision 与稳定动作 ID，再由正式 Execute 校验。未知窗口、空候选、ID 冲突显式失败。
- IPolicy 仅接收 Observation 与 Candidate。不接收存档、原始 GameView、完整 Command、私有事件、其他人的暗选、调试能力或随机状态。已装备卡牌身份按 9 月 28 日用户更新公开，Selected 对他人仍是 InHand；同队也沿用现有本人投影。策略实例逐席分开。
- 卡牌 AI ID 使用正式编号前缀（如 wasp-00），启动时检测格式与唯一性；语义不依赖中文后缀、UI 顺序或候选索引。动作 ID 包括命令种类、稳定值、目标席位、坐标、移动模式。实体列表可变长，无候选截断。当前规则核心只支持四席，显式检查，未来扩展需升级协议。
- 基线 random-v1 均匀采样候选；simple-v1 优先成功防御、有效主要行动、攻击小兵和接近战区。只使用本人观察及公开静态内容，无搜索或训练。暗选一次选择随后确认，不提供 UI 反复改选/取消的无穷空转动作。
- 环境用独立种子流生成均匀投币，通过 StartDraft/ReportCoinToss 走 engine98 的 BP、部署后开局投币；落面和匹配姿态写进正式命令。它是训练环境随机源，不伪称物理仿真，不改 Unity 物理币或正式联网房主权限。
- 评测 CLI 与策略分离：固定种子、固定阵容、换边，单 worker；正式局无 Debug 命令。真正 Finished 才有团队 ±1，截断或错误不赋胜负。教学场景仅测接口覆盖，不混入正式胜率。
- 策略实际输入保存在 policy-trace.jsonl.gz；公共观战事件在 spectator-events.jsonl.gz；权威 final-save.json、commands.json 仅供离线重放/诊断，禁止供在线策略读取。落盘隔离不是同进程恶意代码沙箱；第三方策略需后续进程隔离。
- 现有 ScenarioRunner 最多 1000 命令，保存恢复最多 10000。评测 limit 最多 9000 个策略步，另外三条环境命令；超过场景容量仍保留完整存档，不能静默截取为完整回放。

## 阶段与缺口

本批依次交付：可运行基线；隔离/响应/确定性测试；短评测与 Unity 重放证据；按实测拟定后续预算。运行结果和边界在后续验收文档补齐。

核心每次投影与提交复制带全历史的状态，长局速度会下降；本批先测量，不为吞吐绕过原子性/身份校验。原始 GameView 带 Debug 字段且网络额外收窄 Pending；AI 使用独立允许列表。公开历史 v1 只含事件种类、公开卡、席位和起止位置，未传不透明 Detail/内部序号，未包含全部战斗算式和状态特征；小模型前须补特征合同与对照测试。

尚未接入产品席位机器人、实时 Unity AI 观战、推理超时进程、训练 IPC、模型加载或 PPO。后续产品集成需保持服务器分配的 bot 身份，超时只能在该 bot 席位重查合法保守动作；不接管真人。规则/内容/格式改变需拒绝旧工件或显式迁移并重评；不能承诺模型自动理解。

环境已核对：5900HX 8 核 16 线程，约 15.4 GiB 可见内存（开始约 5.8 GiB 空闲），NVIDIA 8 GiB、驱动471.51/CUDA 11.4。项目独立 .NET 10.0.401 已存在于 LOCALAPPDATA/Goa2V1Toolchain；不安装驱动或云依赖。

初次严格 .NET 构建暴露原仓库 DebugRules.cs:199、DiscardReactionRules.cs:112 两条 CS8602；不改规则代码，以命令参数 WarningsNotAsErrors=CS8602 保留警告，其余警告继续按错误处理。Unity 既有证据不等于本批已重新验证。
