# 四人免费异地联机设计

## 基线与范围

用户要求先备份再开始联网开发。2026-09-29 已确认日常分支与 origin 均为 `0526c55a55ef5d8f96cfe27f5968fcde9d3efd48`，工作区干净，push 返回 Everything up-to-date。不重复造空提交，不动 main 或 engine34 永久引用。

本任务串行负责 network、启动器和发行工具。规则 engine97、卡牌、GameScreen、Command/View、IPlayerSession 与存档格式沿用当前实现。没有派发其他会话。

目标：四名中国境内好友，免费，一人电脑开房并参与，三人加入。第一阶段采用独立运行的 EasyTier 虚拟局域网；优先 P2P，不能直连时才由共享节点转发。软件免费不等于共享节点可用性或延迟保证，尚未实测跨运营商连接。

## 架构

```
好友 Unity 客户端 ── EasyTier 私人虚拟网络 ── 房主权威服务
                                               │
                                      房主 Unity 客户端
```

房主的服务进程运行核心规则；四名玩家都是认证客户端。EasyTier 不参与规则、席位或隐藏信息。房主退出游戏窗口不等于停止服务；启动器明确提供停止房间。房主服务结束后不能自动迁移到好友电脑。

网络必须使用独立名称和密钥，只连接自己的四台电脑。挑选不与四人家庭网络冲突的私有 IPv4 网段。暂不内嵌 EasyTier、不下载不明公共节点配置、不自动改变防火墙、不购买服务，也不把游戏 TCP 直接开放到公网。

## 批次一：可携带的开房和加入入口

- 同一个 Windows x64 包包含 Unity Player、独立房主服务及其 .NET 运行时、正式规则数据、中文启动器。
- 开房人选择本机 EasyTier IPv4；允许 LAN 与本机验证地址，并清楚区分它们。服务只绑定所选地址，沿用随机空闲端口。
- 先以三个独立的邀请文件邀请好友。文件含单一席位凭据；分别私发，不能公开或一起发给同一个人。朋友在启动器选择自己的文件并进入游戏。
- 这不是六位公共房间码：纯 P2P 之外没有部署房间发现服务，不能凭空把短码解析成房主地址。后续可设计携带完整地址与单席凭据的长邀请字符串，或明确增设发现服务。
- 开房前检查发行版本，加入前检查邀请结构、版本与 TCP 可达性。TCP 可达不等于认证成功或低延迟，游戏握手仍为最终判定。
- 房间凭据、日志、存档放本机用户数据目录，绝不放可分发安装包。分发使用生成的原始 zip，排除用户运行数据。
- 关闭启动器时，若仍有本机房间则提示停止并保存或取消关闭。不静默遗留服务，不因为关闭客户端而误杀服务。
- 停止产生旧机制的 authority 存档并 Restore 检查；尚未提供重开旧房，不显示“下次继续”承诺。

验收：无 SDK/Unity 安装依赖的独立 exe 可启动；四个身份可连接并选英雄；错误/旧邀请被拒绝；断线身份不变；服务停止且存档检查成功；发行包内无凭据；WinForms 入口可实际启动。真实四台电脑、中文路径、网络节点延迟另外记录实际证据。

## 后续批次

1. 跨电脑验收：先房主与一位好友，再四人；测每人到房主的 RTT、丢包、是否 P2P、运营商差异。比较候选房主，不能只看带宽。免费共享节点拥塞则换国内节点或换房主，无法保证免费兜底的固定质量。
2. 房间体验：游戏内创建/加入、四席连接与准备状态、显式开始、连接健康信息。这涉及共享 UI 和房间协议，单独测试；本批外部启动器不冒充已完成游戏内大厅。
3. 可靠性：心跳/黑洞超时，房主异常中断持久化与原房恢复；保存凭据与幂等账本、完整隐藏状态仅留房主。不能把正常客户端重连当作房主恢复。
4. 真人完整一局：暗选、同先攻、嵌套防御/弃牌/反击、升级、兵战、死亡/复活、结束；四端投影一致且他人预选不可见。再决定是否扩大试玩。
