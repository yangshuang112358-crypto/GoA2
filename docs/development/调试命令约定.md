# 本地调试命令

调试命令属于开发工具；Sandbox在建立对局时固定。所有命令经过GameSession的身份、版本、幂等与原子检查，日志保存原始意图，恢复时按相同规则执行。普通对局拒绝这些命令。

| 命令 | 输入与边界 | 可见结果 |
|---|---|---|
| DebugPrepare | 选英雄/出生；可选四个不重复英雄ID；已选角色保留 | 选择剩余英雄，由各队长合法部署，进入暗选 |
| DebugSelectAll | 暗选；first/highest/random；跳过已确认席位 | 第一张、最高先攻或固定算法随机选牌；是否揭示仍由确认模式决定 |
| DebugConfirmAll | 暗选；所有仍有牌且未确认席位必须先有选择 | 一次确认所有选择；缺任何人的选择时整条命令拒绝 |
| DebugAdvance | action/turn/round | 依次选牌、确认、队长选最低编号候选、放弃行动，停在指定边界 |
| DebugGold / DebugSetGold | 目标席位，整数变化量/绝对值；结果0—9999 | 修改指定玩家金币，无升级/奖励伪装 |
| DebugTeleport | 单位ID、目的格 | 合法非障碍空格；只移动指定单位 |
| DebugDiscard / DebugRecover | 目标席位、本人的手牌/弃牌ID | 未锁定手牌进入弃牌区或取回；公开颜色，身份私有 |
| DebugEquipCard | 暗选且未确认；本英雄非紫牌；同色卡未被选中或待结算 | 替换为指定测试牌，不宣称升级已发生或牌效已实现 |
| DebugSetCoin | blue/red | 设置下一次并列所使用的决策币 |
| DebugRemoveMinion | 小兵ID；完成准备后，不能嵌套推进 | 绕过重型保护、无金币移除；重型立即正常推进 |
| DebugDefeatMinion | 小兵ID、敌方奖励席位；完成准备后 | 击败并发放2/4金；重型立即正常推进 |
| DebugSetCrystal | 目标席位代表其队伍；整数0—99 | 设置水晶，0立即触发对方胜利；无击败金币 |
| SetQuickSelection | on/off | 测试模式选完即揭示或保留四人确认；开启后重新检查已有选择 |

DebugAdvance(action)只能从行动/先攻选择开始；turn和round可从暗选开始。它通过已有规则函数逐步执行，不直接写Turn、Phase或已出牌区，不触发牌的主要效果。每次调用只占一条命令修订，内部事件保留同一来源ID；副作用只有正常选牌、翻牌、先攻与放弃。

轮级快进停在RoundEnd，不能跳过轮末结算。未来新增攻击响应、复活、升级等强制选择后，快进遇到这类阶段必须停下并交给对应选择者，不能自动吞掉待处理选择。循环有硬上限，防止错误规则陷入无限推进。

战场调试已接入，规则和暂停边界见[战场结算约定](战场结算约定.md)。推进会保留原行动/先攻选择，在占位出生完成后恢复；ChooseMinionSpawn是由指定队长执行的正常命令。局面结束后不可继续修改。仍未提供脱离推进链直接改战区的入口。
