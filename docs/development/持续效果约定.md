# 持续效果执行合同

设计起点为静电封锁、打断施法、决斗家和传奇决斗家，依据正式牌文、R-ROUND、R-UNITS、R-TARGETS、R-MOVE与R-DEFENSE逐卡展开。前两张已实施；决斗家两张因U-013仍未开放，不能把本文件的设计范围当作四张全部完成。后续已接入闪耀之刃与反射屏障，具体范围以各自合同和状态登记为准。

持续状态记录唯一ID、来源卡/单位、控制者、创建轮/回合/顺序、生效回合、到期边界、效果程序/版本及所需绑定。不同来源分别保留；不能用英雄上的永久布尔值模拟本回合免疫或静电封锁。所有状态、取消和到期事件进入重放。

本回合效果从实际执行时生效，到当前回合边界失效；下回合效果本回合无效，仅在本轮下一回合生效，第四回合产生则记录失效而不跨轮；本轮效果持续至本轮结束。当前只接没有轮末after争用的效果，U-001仍不被默认为已裁定。

范围型效果使用来源英雄当前所在格和相应范围加成计算。来源不在地图上时没有可覆盖区域；状态本身按明示持续期保存，不擅自加一条通用“死亡删除所有效果”的规则。单体防御免疫按文本绑定受保护英雄及本次原攻击者，不扩成阵营免疫。

静电封锁只限制移动和快速移动跨越其范围边界。普通路径逐条边检查，不能以起终点同在圈外为由穿过圈内；快速移动按原地/目标在范围内外是否一致过滤。放置、推动、交换的规则独立，不能因为复用坐标函数而套用移动禁止。

打断施法按实时技能范围限制敌方英雄的技能主要行动；普通移动、快速移动、攻击和防御响应不因该牌而被一并关闭。范围图标不把攻击牌改成技能行动。

决斗家/传奇决斗家的免疫按原攻击者作为例外，查询和命令重检一致。防御失败并被击败后是否仍获得此回合免疫、随后同回合复活是否继续受保护，牌文未写成功条件，现有裁定未明确；已单独提出U-013，此分支等待确认，不先把成功条件加进正式合同。其他持续效果独立推进。

历史兼容：新效果能力使用新引擎版本。版本0/1保留首批两攻击三防御与既有无持续效果语义；版本2支持两个范围技能，版本3加入闪耀之刃，后续能力及当前引擎8见[ADR-003](../architecture/decisions/ADR-003-规则引擎版本.md)。已有存档在无待选择且尚未暗选的Planning边界，可通过UpgradeEngine命令显式采用新版；原InitialEngineVersion及历史命令不改写。恢复按记录位置切换规则版本。

闪耀之刃使用固定Adjacent范围，不能套用技能范围加成；只有相邻敌方英雄以技能卡建立且当前生效的来源会被取消。取消按创建顺序逐条产生EffectCancelled事件，记录被取消卡、发起牌和效果ID；不删除卡牌或其他来源。本人主要攻击产生的封技仍来自攻击牌，不因此变成技能卡效果。

验收：生效前/生效中/到期后；第四回合下一回合失效；来源分离与重放；圈内外和穿圈路径；动态中心和技能范围加成；受保护与原攻击者例外；错误提交原子拒绝；正式旧存档保持旧规则或经显式命令升级。
