# 启动与操作指南

## 直接运行

双击 artifacts/player/Goa2V1.exe。完整player文件夹必须保留，不能单独移动exe；运行不要求.NET SDK或先启动Editor。

初始为新的测试对局。“读取”恢复最近保存；“新对局”确认后先保存当前进度。推荐1600×1000，1280×800已完成整套界面验收，1152×768已复核基础交互、预设、恢复、图鉴和投掷弃牌。左右列表和图鉴支持滚轮；中央地图滚轮缩放，中/右键拖动，Home或“全图”显示整张地图。小窗口默认聚焦中央战区；四边箭头可折叠对应区域，扩大地图空间。

“定位角色”将当前操控英雄放到地图中心并放大至可操作尺度，切换席位本身仍保留原视口。全图远景仅显示单位标记，放大后显示英雄数字和兵种文字，避免缩小时文字互相遮挡。

## 四席操作

1. 选择英雄后确认，点左侧或按1/2/3/4立即切换角色。英雄不能重复；席位1、3蓝队，2、4红队。输入金币等文本框时，数字不触发角色切换。
2. 全员选完后，席位1蓝队长、席位2红队长分别安排本队出生：选择成员→地图高亮格→确认。取消只清除预选。
3. 每席从手牌暗选一张；默认测试模式四人选完立即揭示，前三人等待时可改选。在“调试”关闭“四人选完立即揭示”，则全体分别确认后才揭示。
4. 同队同先攻由队长确认先行动者；跨队冲突自动使用并翻转决策币。
5. 行动者选择次要移动或快速移动→合法高亮→预选→确认，也可明确放弃。拔枪/快速突刺另可“执行攻击”，地图选择敌方目标并确认。防御者按对应数字切席位，从手牌或右栏选择防御后确认，或明确不防御；已开始的主要动作不能改为移动/放弃。被击败后，在下一张牌行动前选本队出生点复活。
6. 顶部保留最近一回合已揭示的牌，进入下一次选牌也不清空，牌文区可滚动。“全部记录”可看各轮真实出牌历史；左侧四个圆圈按回合填出牌颜色，下面仅在有弃牌时显示弃牌圆点。图鉴包含108张牌的数据，可搜索名称、文字、英雄或牌号，切换“全部”或单英雄，并用“只看本局可用”筛选当前存档已支持的主要行动/防御；不会把旧版本存档显示为全部新牌效可用。
7. 四回合后到达轮末，点击“结算轮末”。少兵方队长按地图高亮逐个移除本队小兵，重型推进先完成出生再继续升级。各升级者按1—4切换，右侧选颜色，下方两张候选选一张并确认；界面说明未选候选带来的永久加成。所有人选完即进入下一轮，未升级者获得1金。
8. 永久数值显示在左侧角色卡，右栏可展开查看本人的来源；8级自动获得紫卡，在右侧独立展示，不能暗选。紫卡持续文字和其他待实施牌文的展示，不代表效果已经执行。
9. 静电封锁/打断施法可“执行基础技能”，随后在右栏查看来源和到期回合。“在地图查看范围”用紫色描边显示覆盖格，与绿色合法目标区别；不会改变对局。技能被禁止时按钮关闭并显示来源，仍可选择其他合法动作或放弃。效果到期后提示和范围自动清除。
10. 闪耀之刃可“执行基础攻击”，只高亮相邻敌方英雄。攻击结算后取消相邻敌方英雄技能卡的激活效果，再建立本回合相邻封技；即使对方防御成功，攻击后文字仍执行。其“相邻”不受范围加成扩大。
11. 偏转屏障/反射屏障抵挡非相邻远程攻击后，切换至攻击者，点手牌或右侧选项并“确认弃置”。取消只清除预选，不能跳过；空手自动继续。完成后反射屏障提供本回合非相邻远程攻击免疫，后续攻击不会高亮受保护者。其他席位可查看免疫事实，不额外显示未公开的防御牌名。
12. 神枪手/一枪爆头已开放主要攻击。目标本回合揭示过攻击或基础攻击牌时，防御窗口显示独立“牌文2”加成；已放弃该攻击也仍算使用。神枪手不能选择相邻目标，一枪爆头可以，但仍按实际攻击、防御数值比较。

## 保存

Windows用户目录 AppData/LocalLow/Goa2V1/Goa2V1/saves/hotseat-v1.json；已有存档替换时保留.bak。保存先写临时文件再替换；读取验证版本、内容hash、命令重放和最终状态，失败时保留当前对局并显示原因。

存档是包含全部手牌的本机完整状态；当前热座不是联网账号身份。读档和切换席位直接展示当前角色，不再使用交接遮挡。

旧存档保留原规则能力；在全员尚未选牌的暗选阶段，可点击“采用当前规则”开放新版能力，保留原记录。若还在轮末，先完成结算进入下一轮。此操作只向前升级，保存和重放均记录切换位置。

## 手工调试

需要直接测试响应或升级时，使用[手工调试局面](手工调试局面.md)中的open-debug-position.ps1。八个预设先验证真实命令并恢复到指定阶段，再打开可手工操作的窗口；不用重新逐个配牌、发金币和摆位。

布罗根可装配投掷飞斧/投掷长矛：执行攻击后，先从下方手牌或右栏选一张弃置并确认，也可点“不弃牌，继续攻击”。飞斧需要本次实际弃牌才+2距离；长矛已有弃牌时可直接获得+2。之后地图高亮合法敌方，右栏显示本次攻击距离。小窗口远处目标不可见时，可收起顶部出牌区或滚轮缩小地图；已揭示记录仍保留，展开即可查看。

劈砍、致命横扫、死亡回旋与背刺可通过装配同色牌测试。选择主要攻击后地图只高亮合法相邻敌方；防御窗口显示牌文加成、普通小兵项及产生牌文条件的单位列表。夏尔加萨按自身周围敌人数计数，背刺检查目标周围的其他友方，来源位置一并显示。

虎爪可装配近身格挡/近身还击来响应非远程攻击；攻击者有牌时本人必须弃一张，空手时只有近身还击会击败攻击者。萨彼娜带头冲锋要求自身相邻友方小兵。防御条件不满足时，右栏说明原因，手牌显示“本次不能防御”并提供悬停提示；数值不足的普通防御仍可选并正常失败。胜者固定显示在顶部，不受右栏滚动影响。

打开右侧“调试”，选择目标角色后可自动准备四人对局、四人快选/随机选牌、增加/扣除或设置金币、传送地图单位、弃置/取回自己的手牌、装配同色测试牌、切换决策币。最下方可确认全部已选牌、跳过当前行动/回合、快速到轮末。传送只允许无障碍空格；快进按规则逐张放弃并保留出牌记录。装配牌不代表主要效果已实施。

调试顶部“打开测试局面…”提供八个可以接着手工操作的起点，涵盖飞斧、长矛、反射弃牌、还击、升级、复活和占位出生。选择后“保存并加载”会先保存当前对局，并自动切至可操作角色；取消保留当前对局。详细说明见[手工调试局面](手工调试局面.md)。

所有调试操作都写入命令记录并可恢复；普通确认存档不能开启调试权限，需创建新的测试对局。测试对局内仍可选择四人正式确认流程。

战场调试还可移除或计奖励击败小兵、计奖励击败敌方英雄、设置队伍水晶；普通击败检查重型保护，调试移除可越过保护。防御/攻击目标等待期间禁止传送、移兵和弃回牌，避免改变正在响应的局面。占位出生和满出生点复活时仍可通过传送释放空格。

轮末选择期间同样限制移兵、击败、弃回牌和普通传送，出生受阻时保留释放占位的传送。金币仍可设置，但本轮升级费用已结算后的新增金币留待之后，不会重复打开本轮付费。快速到轮末会停在结算入口，不替你选择升级牌。

## 开发与重跑

在Hub添加本仓库 unity 文件夹，使用6000.3.23f1。本机Editor位于用户目录 UnityEditors/6000.3.23f1/Editor/Unity.exe。打开 Assets/Scenes/Main.unity，菜单 Goa2/Prepare project 同步数据，然后Play。Prepare仅在主场景不存在时创建它，后续构建保留已有场景。

仓库根目录执行：

~~~powershell
./tools/test-core.ps1
python -B tools/validate.py
python -B -m unittest discover -s tests -v
python -B tools/prepare_unity.py
./tools/build-unity.ps1 -Task BuildWindows
./tools/run-player.ps1
~~~

脚本支持-DotnetExe和-UnityExe，并检查常用本机路径；无需强求加入PATH。Python商店占位入口不可用时请使用实际解释器路径或validate.ps1的-PythonExe。核心唯一源码在core/com.goa2.core/Runtime。

test-core.ps1支持-Runner Auto/Dotnet/Unity，核心测试同源放在UPM包Tests/Editor。完整测试与环境问题处理见[自动化测试](自动化测试.md)。

batch构建前关闭正在打开该工程的Editor，重建Player前关闭旧Player。菜单 Goa2/Validate editor integration 可单独核验Unity内导入与保存恢复。构建使用Windows x64 Mono Release，日志和报告在 artifacts/unity。

## 真实窗口自动验收

运行 ./tools/test-ui-suite.ps1 可依次验收全部14个界面模块，并保留独立证据目录；-Case选择部分模块。每次只运行一份界面测试，窗口保持前台。

读取失败会保留当前内存中的对局；修复文件或重新保存当前对局后可继续。新对局若保存失败，弹窗会说明失败并保留旧进度，可重试或返回。用指定存档启动时若文件损坏，可在错误页选择重试或新建测试对局，原文件不会被自动覆盖。

不启动游戏时也可用[离线资料浏览器](离线资料浏览器.md)查卡、看地图与规则，生成文件为artifacts/reference/Goa2V1-资料浏览器.html。

关闭已有Player后运行 ./tools/test-player-ui.ps1；或带 -Width 1280 -Height 800 验证小窗口。脚本打开可见窗口，以真实鼠标和键盘操作；运行时该窗口需要保持前台。它会检查19项交互并留下JSON报告、截图和独立QA存档，结束后保留窗口供检查。

单独手工QA可用 ./tools/run-player.ps1 -Qa，测试存档固定写入artifacts/unity/qa-save.json，不覆盖正常游戏存档。-LoadSave接受要恢复的存档路径。直接启动exe也支持-goaLoad和-goaSavePath参数。

可选QA参数-goaScreenshot后传绝对PNG路径，界面、缩放或滚动变化后写截图及同名.ui.json布局。tools/qa-player.ps1读取artifacts/unity/player.pid，只向前台Goa2V1发送鼠标/键盘；-Caption或-Element依赖布局，匹配按钮后仍通过真实点击。支持Capture、Click、Scroll、Drag、Key，不能代替核心权限检查。
