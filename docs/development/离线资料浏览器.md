# 离线资料浏览器

artifacts/reference/Goa2V1-资料浏览器.html可以直接用浏览器打开。文件内嵌全部资料、样式和脚本，不需要启动服务或连接网络；也不会把搜索、筛选或地图操作写回正式数据。

当前内容包括6英雄108张卡、21张已接入牌的合同/验收文件、254格地图、规则手册、裁定记录、待确认问题、项目复盘和启动操作说明。卡牌可按英雄、六种颜色（含紫卡）、实现状态筛选，并搜索名称、文字或ID。详情保留感叹号、0、无次要行动和数值的区别；紫卡明确标为英雄8级获得。

地图支持滚轮缩放、拖动、全图复位、区域筛选、显示坐标及输入坐标定位。这里显示正式地图与出生标记，不是某份存档中的当前单位分布。规则文档可按关键词筛选段落，原始完整文档仍是对应Markdown文件；浏览器不会替你回答未决裁定。

重新生成：

~~~powershell
python -B tools/build-data-browser.py
# 可指定项目目录和输出位置；仓库内的生成文件仅允许写入artifacts
python -B tools/build-data-browser.py --root 项目目录 --output 输出目录/资料浏览器.html
~~~

生成前运行现有资料/来源/结构/引用验证。输出旁的JSON登记HTML哈希与数量；HTML“来源与版本”页登记34份输入的SHA-256。后续文档或卡状态变化后需重新生成，旧HTML不会自动更新。生成器只需Python标准库；默认系统python不可用时，使用[启动指南](启动与操作指南.md)中的已安装Python路径。

真实浏览器验证使用Node.js、Playwright和本机Microsoft Edge：

~~~powershell
node tools/test-data-browser.cjs
node tools/test-data-browser.cjs --visual
~~~

默认无窗口运行，--visual打开浏览器并放慢步骤。测试结果与1440×1000、1152×768截图保存在artifacts/reference-tests/独立编号；包含卡牌检索、完整详情、地图坐标/区域/拖动/鼠标锚点、窗口尺寸变化后的坐标变换、文档搜索、未决问题和无网络/脚本错误检查。

此工具是资料查阅入口。Unity程序仍负责实际对局，卡牌状态以content/status/cards.json及其证据为准。
