## 未提交与历史代码

sources/git 保存旧工作树相对 HEAD 的补丁；sources/legacy/goa2_v4 下归档当前 src、tests、web、启动入口，便于离线核查135测试及修复证据。
该目录不是新版运行时代码。Goa2V1 禁止 import、链接或复制这些 Python 规则到 Unity 生产程序集。
补丁可能保留旧文档中的个人路径和原始空白，这是取证原文；新文档、工具和CI不使用个人绝对路径。
不复制 .git、缓存、旧房间存档、账号令牌或本机环境；它们不属于正式内容。资产清单仅记录旧房间文件存在及哈希以核验未改动。

## 资料缺失与边界

外层目录虽有 .git，但 Git 不识别为有效仓库。各 v2/v3/v4 子仓库独立存在；新建 Goa2V1 独立 Git，不修复或重置外层。
原 v1 主要源码已不在工作目录，历史中曾有删除请求；保留历史需求，不声称重建了全部原文件。
正式地图已被用户确认。本次检验结构与迁移完整性，未重画地图或重复要求对称性确认。
