# 术语表

| 中文 | 工程术语 | 精确定义 |
|---|---|---|
| 轮 | round | 四个出牌回合及轮末结算 |
| 回合 | turn | 各玩家一次暗选、揭示、依先攻结算的周期 |
| 单张牌行动 | action resolution | 一个行动者执行其已揭示卡牌，不等于整个回合 |
| 先攻 | initiative | 基础值和有效修正决定顺序；不叫速度 |
| 决策币 | decision coin | 跨队同先攻确定先手队伍后翻面 |
| 战区 | combat region | redNear / mid / blueNear 中当前一个 |
| 战线标记 | frontline mark | 推进累计成绩，不是地图区域坐标 |
| 单位 | unit | 英雄或小兵；阵营限定按动作及牌文 |
| 标志物 | marker | 卡牌引用的部件；需单独定义，不自动算单位 |
| 远程 | ranged | 攻击距离图标，不等于技能范围 |
| 范围 | range | 技能或效果距离，不自动变为远程攻击 |
| 主要防御 | primary defense | 被攻击时作为主要防御使用，相关防御文字按时机执行 |
| 弃牌 | discard | 从指定区域移入弃牌状态；本身不执行其主要行动 |
| 取回 | retrieve | 从牌文指定位置回到手牌 |
| 卡牌交换 | card swap | 交换两张牌的位置与状态 |
| 单位换位 | unit swap | 交换地图位置，不能默认算移动 |
| 放置 | place | 特定效果放到合法位置，路径限制按该效果 |
| 推动 | push | 被阻挡可停下，0 格仍可完成该步骤 |
| 免疫 | immunity | 对相应行动既不可指定也不受影响 |
| 激活/持续 | active/continuous effect | 需要生命周期，不存成界面布尔值 |
| 控制者 | controller | 控制效果来源或单位的玩家 |
| 选择者 | chooser | 当前窗口应作决定的人，可能不是控制者 |
| 卡牌等级 | card level | 金银 null，三色 1—3，紫 4 |
| 英雄等级 | hero level | 1—8，决定升级成本、击败损失及紫卡解锁 |
| data_only | 仅数据 | 文字与数值存在，效果未实现 |
| specified | 已定规格 | 合同及实质歧义已解决，尚不代表可执行 |
| behavior_tested | 行为测试通过 | 该牌针对性矩阵通过 |
| integration_tested | 集成测试通过 | 该牌与阶段、效果、选择恢复及信息投影的适用交互通过 |
