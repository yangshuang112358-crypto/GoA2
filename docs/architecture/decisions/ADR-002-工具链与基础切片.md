# ADR-002：工具链与基础切片

日期：2026-09-10。状态：已选择，实际安装/构建证据见BATCH-01验收。

选择Unity 6000.3.23f1（6.3 LTS；09d2ecc7fb28），官方版本接口和发布页在实施当天核对。锁定LTS补丁以便重现；后续升级独立验证，不自动追随Hub推荐版本。
独立.NET SDK 10.0.401只用于核心构建和测试，游戏核心目标为netstandard2.1、C# 9.0。Unity并不使用.NET 10运行游戏。

源码唯一入口为core/com.goa2.core/Runtime。Unity通过本地UPM包引用；四个.NET工程通过Compile Include引用这些源文件。Domain、Rules、Application、Infrastructure分别有程序集边界，前三者不引用Newtonsoft，所有四层均不引用UnityEngine。
JSON在Infrastructure处理，Unity包com.unity.nuget.newtonsoft-json锁3.2.2，其对应Newtonsoft.Json 13.0.2；.NET侧使用同版本并提交NuGet lock文件。

首个验证平台为Windows x64、Mono后端。UI采用Unity内置UI Toolkit与程序绘制的六边形，不依赖另一个网页运行时。该选择是当前开发验证平台，未将未来跨平台发行范围定死。
首屏必须能浏览正式地图和全部卡牌，操作由GameSession的私有视图和合法集合驱动。

实际安装、编译和Windows Player已验证；完整证据见[本批验收](../../verification/BATCH-01进展.md)。中文内置Noto Sans CJK SC Regular，OFL许可与SHA256见[资源记录](../../development/第三方资源.md)，避免依赖目标机器安装的字体。

content/canonical仍是唯一源。prepare_unity.py校验哈希后复制到被忽略的StreamingAssets；构建前重新生成，运行时再次验证清单。不得在Unity副本直接修数据。

本批动作只开放已经实现的次要移动、快速移动与执行前放弃。主要行动文字未实现时明确提示，不能自动当普通攻击。完整轮末结算未实现时停在明确的RoundEnd边界；不能静默开新轮。

本批为本地四席热座开发切片；席位选择器只切换展示和本机操作上下文，不是联网身份协议。未来网络适配器必须从认证连接绑定席位。完整权威存档仅保存在本机，不作为公共视图传输。
