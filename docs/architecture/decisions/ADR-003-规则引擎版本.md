# ADR-003：保持历史命令可重放

状态：采用。背景：补录既有出生顺序裁定后，相同旧命令在新实现会产生不同的待选择状态。只检查正式规则版本、内容哈希和协议版本无法区分这种变化。

GameState新增InitialEngineVersion和EngineVersion；缺失字段读为0，新建对局使用当前版本7。前者记录命令历史的初始语义，后者记录当前语义。恢复从初始版本建局，重新执行全部已接受命令，再比较完整结果；未知版本拒绝。

版本0保留旧版竞争出生暂停结果；版本1采用队长选择本队小兵顺序、跨队按决策币且不翻面。旧命令DTO与原枚举数值保持不变，避免历史幂等指纹变化。新增状态字段使用明确默认值，由反序列化规范化后比较。

此版本独立于正式卡牌/地图/规则资料的版本。新增纯查询、测试、UI或不改变旧命令结果的字段无须机械升级。改变旧命令结果时必须记录版本边界和兼容测试。不能手改保存的版本字段绕过恢复校验。

证据：LegacySaveTests恢复BATCH-01真实59命令轮末文件；BattlefieldTests保留引擎0争用出生的旧结果；SpawnOrderTests覆盖引擎1的本队选择与红/蓝币优先。命令恢复仍为权威来源，不信任保存的派生结果。

轮末后续采用新增ResolveRoundEnd命令：保留原RoundEnd到达事件和边界结果，随后显式记录回收/移兵/升级，不改变旧EndTurn。LegacySaveTests另外验证普通确认旧档在第60条新命令进入下一轮并能完整重放；该新增能力不要求改写原59条记录。

版本2开放静电封锁和打断施法的持续效果；版本0/1保持它们主要动作未实装的原语义。绑定卡程序时读取对局版本，展示支持能力与命令执行同源。

版本3开放闪耀之刃的相邻英雄攻击、激活技能效果取消和相邻技能禁止；版本2的原能力保持。EffectAreaKind默认SkillRange以兼容已经保存的两个技能范围，新的Adjacent明确不吃范围/远程加成。固定夹具engine2-purple-aura.json来自旧版本2的真实Player，保存了黄蜂8级紫卡拥有及静电封锁后的状态；恢复不能把新紫卡反应追加入旧命令。

UpgradeEngine命令只允许在Planning且全员尚未选牌、没有执行器/待选择/轮末/出生/残留效果时，提高到当前支持的版本。普通确认对局也可显式采用新规则，不要求沙盒；不修改InitialEngineVersion和既有命令。引擎升级自身进入命令历史，重复不会再次执行，同版本、降级、未来版本均拒绝。EngineUpgradeTests覆盖旧普通确认59条→轮末继续60→采用当前规则61，并完整重放；真实窗口也已从该旧文件保存出相同版本/修订结果。

版本4开放偏转屏障和反射屏障的防御后反制。CardExecution保存DefenseResponse、原攻击者及游标；新ForcedDiscard命令处理本人手牌。反射屏障在弃牌步骤后建立绑定自身的非相邻远程攻击免疫，使用独立None区域类别。新增私有来源字段默认null，旧命令指纹不变；版本0—3仍把这两张防御明确列为未实装，不把反制追加入旧防御结果。

版本5开放神枪手/一枪爆头，按当前实际揭示时标计算目标使用攻击牌的+2。CardTextBonus在攻击明细中独立保存，旧档默认0，AttackBonus仍为总有效加成。旧引擎4防御后待弃牌的真实Player存档已固定为engine4-barrier-pending.json，不能因新增攻击程序破坏恢复。

版本6开放劈砍、致命横扫、死亡回旋和背刺。牌文修正使用独立描述符，记录原因及按ID稳定排序的单位来源；前三张以攻击者为中心计敌方单位，背刺以目标为中心查其他友方支援。CardTextReason默认为空、CardTextSourceUnits默认为空表；版本5的神枪手类原结果继续使用这些默认值。真实旧Player的engine5-headshot-pending.json固定相邻一枪爆头待防御状态，验证原条件+2、恢复后完成防御，再于下一回合显式升级；旧指纹不变。

版本7开放近身格挡、近身还击和带头冲锋。防御条件分开描述远程类别、最短距离与相邻友方小兵；合法选项与不可用原因共用同一函数。近身还击的空手分支按固定原攻击者触发击败，胜利会终止父执行器，不能恢复已结束对局。新增私有HeroDefeatSource事件只在这类私有来源击败时生成，原公开攻击/调试击败事件保持原语义。真实版本6的engine6-unsupported-defense.json验证唯一剩余未实装防御仍保留等待，不擅自执行新反制或自动击败。

历史夹具与其输入按原始字节提交，允许原文件的CRLF，防止Git换行转换改变取证哈希；其他空白检查保留。版本4/5输入在早期提交曾被规范为LF，本地仍保留原捕获字节，已据原文件恢复入索引并核对其SHA-256，未重新生成旧版本结果。

版本8开放投掷飞斧/投掷长矛。可选本人弃牌是独立指令与ChooseOptionalDiscard命令，明确skip，空手直接继续。随后按描述符判断本次实际弃牌或本人弃牌区，保存PreAttackDiscarded、AttackRangeLocked及AttackRangeBonus再选目标。旧字段默认false/0，旧命令枚举值保持原值；版本7的近身还击真实待弃牌档恢复后完成原强制弃牌，不加入新攻击成本。永久远程加成与技能范围分开，查询与声明同源。
