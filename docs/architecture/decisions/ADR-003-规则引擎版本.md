# ADR-003：保持历史命令可重放

状态：采用。背景：补录既有出生顺序裁定后，相同旧命令在新实现会产生不同的待选择状态。只检查正式规则版本、内容哈希和协议版本无法区分这种变化。

GameState新增InitialEngineVersion和EngineVersion；缺失字段读为0，新建对局使用当前版本1。前者记录命令历史的初始语义，后者记录当前语义。恢复从初始版本建局，重新执行全部已接受命令，再比较完整结果；未知版本拒绝。

版本0保留旧版竞争出生暂停结果；版本1采用队长选择本队小兵顺序、跨队按决策币且不翻面。旧命令DTO与原枚举数值保持不变，避免历史幂等指纹变化。新增状态字段使用明确默认值，由反序列化规范化后比较。

此版本独立于正式卡牌/地图/规则资料的版本。新增纯查询、测试、UI或不改变旧命令结果的字段无须机械升级。改变旧命令结果时必须记录版本边界和兼容测试。未来允许中途切换引擎时，须通过有前置条件的显式命令保留在日志中；当前尚未提供这种切换，不能手改保存的版本字段绕过恢复校验。

证据：LegacySaveTests恢复BATCH-01真实59命令轮末文件；BattlefieldTests保留引擎0争用出生的旧结果；SpawnOrderTests覆盖引擎1的本队选择与红/蓝币优先。命令恢复仍为权威来源，不信任保存的派生结果。
