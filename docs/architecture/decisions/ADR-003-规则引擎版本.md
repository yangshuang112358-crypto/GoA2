# ADR-003：保持历史命令可重放

状态：采用。背景：补录既有出生顺序裁定后，相同旧命令在新实现会产生不同的待选择状态。只检查正式规则版本、内容哈希和协议版本无法区分这种变化。

GameState新增InitialEngineVersion和EngineVersion；缺失字段读为0，新建对局使用当前版本3。前者记录命令历史的初始语义，后者记录当前语义。恢复从初始版本建局，重新执行全部已接受命令，再比较完整结果；未知版本拒绝。

版本0保留旧版竞争出生暂停结果；版本1采用队长选择本队小兵顺序、跨队按决策币且不翻面。旧命令DTO与原枚举数值保持不变，避免历史幂等指纹变化。新增状态字段使用明确默认值，由反序列化规范化后比较。

此版本独立于正式卡牌/地图/规则资料的版本。新增纯查询、测试、UI或不改变旧命令结果的字段无须机械升级。改变旧命令结果时必须记录版本边界和兼容测试。不能手改保存的版本字段绕过恢复校验。

证据：LegacySaveTests恢复BATCH-01真实59命令轮末文件；BattlefieldTests保留引擎0争用出生的旧结果；SpawnOrderTests覆盖引擎1的本队选择与红/蓝币优先。命令恢复仍为权威来源，不信任保存的派生结果。

轮末后续采用新增ResolveRoundEnd命令：保留原RoundEnd到达事件和边界结果，随后显式记录回收/移兵/升级，不改变旧EndTurn。LegacySaveTests另外验证普通确认旧档在第60条新命令进入下一轮并能完整重放；该新增能力不要求改写原59条记录。

版本2开放静电封锁和打断施法的持续效果；版本0/1保持它们主要动作未实装的原语义。绑定卡程序时读取对局版本，展示支持能力与命令执行同源。

版本3开放闪耀之刃的相邻英雄攻击、激活技能效果取消和相邻技能禁止；版本2的原能力保持。EffectAreaKind默认SkillRange以兼容已经保存的两个技能范围，新的Adjacent明确不吃范围/远程加成。固定夹具engine2-purple-aura.json来自旧版本2的真实Player，保存了黄蜂8级紫卡拥有及静电封锁后的状态；恢复不能把新紫卡反应追加入旧命令。

UpgradeEngine命令只允许在Planning且全员尚未选牌、没有执行器/待选择/轮末/出生/残留效果时，提高到当前支持的版本。普通确认对局也可显式采用新规则，不要求沙盒；不修改InitialEngineVersion和既有命令。引擎升级自身进入命令历史，重复不会再次执行，同版本、降级、未来版本均拒绝。EngineUpgradeTests覆盖旧普通确认59条→轮末继续60→采用当前规则61，并完整重放；真实窗口也已从该旧文件保存出相同版本/修订结果。
