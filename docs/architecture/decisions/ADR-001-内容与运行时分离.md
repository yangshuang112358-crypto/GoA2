# ADR-001 内容与运行时分离

日期：2026-09-10；状态：已采用于资料基线。

背景：v4卡JSON混入三套实现状态字段，多个版本和OCR并存，存在把历史实现误认为新版完成的风险。
决定：content/canonical 是唯一正式源；status独立；sources保存不可变证据；可读目录从正式数据生成。Unity导入资产以后由JSON生成，不能人工同时编辑成第二套真相。
稳定ID原样保留，英雄名/中文颜色等重复字段派生。map格数据原样保留，仅加包络版本。规则、内容、协议、构建版本分别管理。
备选：复制v4整个运行时；把ScriptableObject与JSON都当主数据。前者复用偶然行为，后者带来冲突，因此未采用。
验证：Schema、唯一性、引用、初始手牌、升级图、地图出生点、逐卡迁移对照、manifest哈希。
回退：原JSON及文件哈希完整留在sources；任何后续格式变化须显式迁移，不改写历史快照。
