# GoA2 v4 UI 区域命名

后续沟通统一使用以下名称：

1. **房间与调试区**：左上角房间信息、席位切换和调试按钮。
2. **玩家席位区**：左侧四名玩家、金币和六色卡牌状态。
3. **公开行动区**：顶部阶段、轮数、行动序号、破平币、兵线、水晶和四张公开牌。
4. **行动按钮区**：公开行动区右侧的两列操作按钮。
5. **战场地图区**：中央六边形地图、英雄和小兵。
6. **当前手牌区**：底部当前控制席位的五张手牌。
7. **对局日志区**：右侧事件记录。
8. **卡牌目录弹窗**：完整 108 张卡牌浏览区。

HTML 使用对应的 `data-ui-region` 属性，便于测试和定位。
