# 测试 Agent Prompt 与测试矩阵

## 1. Test Agent Prompt

```text
你是 GoA2 v5 独立 Test Agent。

先阅读权威规则、当前任务合同、架构边界和改动 diff。默认只修改测试、
测试数据和测试文档；发现生产缺陷时报告，不悄悄改生产代码。

职责：
1. 将规则拆成可执行行为矩阵；
2. 先复现缺失行为；
3. 覆盖正常、边界、非法、无目标、错误玩家、时序、序列化和多人隐私；
4. 验证非法命令原子性；
5. 验证同一输入确定性；
6. 验证事件顺序和效果来源；
7. 验证 Pending Choice 保存/恢复；
8. 验证公共状态不泄漏私有手牌；
9. 验证回放重建；
10. 不因为一个 happy path 就宣布完成。

输出限制：
- Findings 按严重度排列；
- 给出测试文件、测试名、失败原因；
- 说明哪些类别不适用；
- 报告聚焦测试和全量测试结果；
- 不超过 50 行。
```

## 2. 基础规则测试矩阵

每个功能考虑：

- 数据合同；
- 正常流程；
- 最小值和最大值；
- 无合法目标；
- 错误 phase；
- 错误玩家；
- 旧 revision；
- 重复 Command；
- 失败前后状态完全相同；
- Event 顺序；
- JSON/存档 round-trip；
- Replay 一致；
- 公共/私有投影；
- Host 与客户端一致。

## 3. 移动矩阵

- 0、1、最大移动值；
- 障碍；
- 友军和敌军占位；
- 目标格占位；
- 多条最短路径；
- 地图边界；
- 永久移动加成；
- 主要移动文字与快速移动替换；
- 快速移动同区域；
- 相邻区域；
- 障碍分隔区域；
- 起始区有敌人；
- 目标区有敌人；
- 取消和改选；
- Pending Movement 重连。

## 4. 攻击/防御矩阵

- 英雄/三类小兵；
- 友军不可被普通攻击；
- 无相邻敌人；
- 基础攻击值、攻击被动；
- 各类小兵修正；
- 最终值为正、0、负；
- 不防御；
- 防御值小于、等于、大于攻击；
- 感叹号防御；
- 防御牌已使用/已弃置；
- 防御者本人选择；
- Pending Attack 重连；
- 击败奖励、水晶、复活；
- 攻击前/后事件顺序。

## 5. 先攻矩阵

- 四个不同先攻；
- 同队两张相同；
- 跨队两张相同；
- 四张相同；
- 决策币红/蓝；
- 决策币翻面；
- 队长选择后重新判断剩余；
- 先攻永久加成；
- 断线时队长选择恢复。

## 6. 兵线矩阵

- 数量相等；
- 差值 1 至最大；
- 只剩重型；
- 重型有保护；
- 调试移除重型；
- 回合中击败重型；
- 轮末移除重型；
- 红/蓝向三个区域推进；
- 第三次推进；
- 敌方泉水；
- 出生点被英雄/小兵占用；
- 队长选择非法格；
- 推进期间胜利立即停止后续步骤。

## 7. 升级矩阵

- 金币不足；
- 恰好支付；
- 连续支付；
- 8 级；
- 未升级补偿；
- 红绿蓝 2 级；
- 未满足条件不能升 3；
- 选中替换、未选加被动；
- 同类被动叠加；
- 四人同时有选择；
- 一人先完成不阻塞其他人；
- 所有人完成后才进入下一轮；
- Pending Upgrade 重连。

## 8. 卡牌测试矩阵

每张卡至少记录：

- Card Contract；
- 每个原子步骤；
- required/optional；
- chooser；
- target kinds/team/range；
- 下限和上限；
- 无合法目标；
- 空手牌/资源不足；
- 免疫；
- 重型保护；
- 多目标顺序；
- repeat 停止条件；
- before/after；
- duration/expiry；
- replacement/prevent；
- 与永久被动交互；
- 与防御交互；
- 来源追踪；
- Pending Choice 序列化；
- Replay；
- 多人私有信息；
- 至少一个交互回归用例。

## 9. 测试状态

- `data_only`：只有数据。
- `specified`：合同和歧义已解决。
- `implemented`：行为存在但矩阵未完成。
- `behavior_tested`：牌自身矩阵通过。
- `integration_tested`：阶段、其它效果、网络、序列化和 UI 合同通过。

只有 Test Agent 或 Coordinator 在证据齐全时提升状态。

## 10. Unity 测试落点

- Edit Mode：Domain、Rules、Cards、Application、序列化、Replay。
- Play Mode：UI 绑定、Scene、Prefab、输入、动画后的状态一致性。
- Player Test：构建环境、平台差异。
- Multiplayer Test：多实例、身份、同步、重连和网络模拟。
- Manual：视觉可读性、操作感、教程和无障碍。
