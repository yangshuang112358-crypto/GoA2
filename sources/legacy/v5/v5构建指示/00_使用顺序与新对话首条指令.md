# GoA2 v5 构建指示总入口

更新日期：2026-06-21

## 1. 本文档包的目的

本目录是 GoA2 v5 Unity 版的项目启动包。它不包含代码，只提供：

- v4 已验证成果与可迁移知识；
- 当前权威游戏规则；
- Unity 项目架构和技术边界；
- 从立项到发布的研发、测试和 Git 流程；
- 主要负责人及各专项 Agent 的 Prompt；
- 分阶段任务、验收标准和风险清单。

v5 是独立重建。可以迁移规则、数据、测试场景和 UI 需求，不直接复制
Python、网页运行时代码或 v4 的偶然行为。

## 4. 每次向主要负责人说“下一步”时

主要负责人应返回：

- 本步目标；
- 为什么现在做；
- 本步只修改哪些文件；
- 给执行 Agent 的 Prompt；
- 自动测试和 Unity 手工检查；
- 完成定义；
- 是否应提交 Git；
- 出错时需要收集哪些日志。

## 5. Unity 技术基线

- 推荐新项目锁定 Unity 6.3 LTS 的具体 patch 版本。
- 渲染管线优先选择 URP。
- 测试使用 Unity Test Framework：Edit Mode、Play Mode、必要时 Player 测试。
- 四人低频回合制联网优先评估 Netcode for GameObjects 与 Multiplayer
  Services Sessions；在纯规则本地演示稳定前不接入联网。
- 任何包版本写入版本锁定文件，不允许团队成员自行漂移升级。
