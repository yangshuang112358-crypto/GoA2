# GoA2 v5 权威游戏规则

状态：v5 开发基线。新裁定必须先更新本文档，再修改实现。

## 1. 权威顺序

1. 用户最新明确裁定；
2. 本文档；
3. 正式卡牌数据与卡牌文字；
4. 已通过的 v5 自动化测试；
5. v4 测试行为；
6. v2/v3 旧实现。

不得从旧代码推翻新规则。具体卡牌有歧义时暂停该牌实现，以最小场景提问。

## 2. 游戏结构

- 4 名玩家，2 对 2。
- 席位 0、2 为蓝队；席位 1、3 为红队。
- 初始队长是各队座位序号较小者：蓝 0、红 1。
- 6 名英雄可选且不得重复。
- 每队默认 7 点水晶生命，房间创建时预留调整入口。
- 战线默认推进 3 次获胜，房间创建时预留调整入口。
- 正式地图已校验，不再重复检查对称性。

## 3. 胜利

任一条件立即结束游戏：

- 敌方水晶生命降至 0；
- 一方完成第 3 次战线推进并取得五圈中的中圈；
- 战线从敌方近区再次推进至敌方泉水。

不会出现水晶胜利与战线胜利同时触发，不定义二者优先级。

## 4. 地图与单位

- 地图为 axial 六边形坐标。
- 可通行地形移动费用均为 1。
- 障碍不可进入、不可穿过。
- 英雄和小兵占据格子，普通移动不可穿过或停在被占格。
- 单位包括双方英雄和双方小兵。
- 小兵分近战、远程、重型。
- 免疫意味着不能被对应行动影响，也不能被该行动指定。

## 5. 轮与回合

- 一轮固定 4 个回合，不要求打完五张牌。
- 每回合四名玩家各暗选一张可用牌。
- 确认前可改选，确认后不能改变。
- 四人全部确认后自动翻牌。
- 依修正先攻从高到低逐张结算。
- 第四回合结束后自动进行轮末，不需要点击。
- 本轮最后回合产生的“下一回合”效果直接失效，没有例外。
- 出牌或弃牌在本轮内不可再次使用，轮末回收。

## 6. 先攻与决策币

- 先攻 = 卡牌基础先攻 + 永久先攻被动 + 合法临时修正。
- 英雄等级不直接增加卡牌数值。
- 同先攻不提前固定内部顺序，每结算一张后重新判断。
- 同队同先攻：队长选择谁先行动。
- 跨队同先攻：决策币颜色对应队伍先行动，然后决策币翻面。
- 初始决策币随机为红或蓝。

## 7. 卡牌与行动

每张卡固定展示：

1. 主要行动；
2. 次要移动；
3. 次要防御；
4. 范围或远程。

行动可包括：基础攻击、攻击、基础技能、技能、终极技能、防御、移动、
防御/技能。

- 数值 0 或 `hasAction=false` 表示该次要行动不存在。
- 主要行动为移动的卡没有次要移动选项。
- 选择行动后，在尚未执行前可取消或改选。
- 未实装卡的主要行动只能用明确的占位完成机制，不得伪装成已实装。
- 卡牌主要文字必须拆成顺序执行的元动作。
- 每个元动作最多处理一个目标。
- 多目标由打出者决定顺序并逐个结算。
- 未写“可以”的步骤是强制步骤；无合法目标时按该牌合同结束或跳过。

## 8. 普通移动与快速移动

### 普通移动

- 主要移动使用主要行动值，并执行主要移动文字。
- 次要移动使用次要移动值。
- 按合法路径逐格移动，不能穿过障碍或单位。

### 快速移动

任何存在的主要或次要移动槽可以替换为快速移动：

- 目标可在起始区域或一个相邻区域；
- 起始区和目标区都不能有敌方单位；
- 障碍分隔区域不算相邻；
- 起始区与目标区允许相同；
- 替代主要移动时不执行主要文字。

## 9. 攻击

- 攻击文本未特别说明时，“单位、英雄、小兵”均指敌方目标。
- 普通非攻击效果未说明阵营时可包括双方；具体牌有歧义时询问。
- 基础攻击阶段性基线：选择相邻敌方单位。
- 小兵被合法攻击后直接结算击败，不进行英雄式防御。
- 英雄被攻击后进入防御响应。

英雄最终攻击值：

`最终攻击值 = a + b - c`

- `a`：卡牌攻击值加攻击永久被动。
- `b`：目标相邻的敌方近战/重型小兵，加距离 2 内敌方远程小兵。
- `c`：目标相邻的己方近战小兵；不计算己方重型小兵。
- 最终值可以小于 0。

## 10. 防御

- 被攻击英雄必须选择一张合法防御牌，或选择不防御并被击败。
- 即使最终攻击值不大于 0，也必须出防御牌才算防御。
- 主动防御和次要防御均可成为合法防御来源。
- 感叹号主要防御在满足文本条件时抵挡任意值；逐卡实装前暂按任意值，
  但必须预留条件检查。
- 防御值 >= 最终攻击值则成功，否则失败并被击败。
- 防御者自己选择弃哪张牌。
- 作为防御弃置不自动执行该牌主要行动文本。

标准时序：

1. 攻击前；
2. 选择并弃置防御牌；
3. 判断防御成功；
4. 攻击后；
5. 攻击结束后；
6. 防御结束后。

## 11. 击败、奖励与复活

- 近战/远程小兵：击杀者 +2 金。
- 重型小兵：击杀者 +4 金，并立即检查战线推进。
- 英雄：击杀者获得目标英雄等级数量的金币。
- 助攻按目标等级使用 `1/1/1/2/2/2/3/3`。
- 被击败英雄所属队伍水晶损失其当前等级。
- 英雄进入待复活。
- 轮到该英雄下一张卡行动时，先由该玩家选择本队合法出生点，再继续卡牌。

## 12. 小兵与战线

- 战斗区域只有红方近区、中区、蓝方近区。
- 初始在中区双方各生成 4 近战、1 远程、1 重型。
- 直接使用正式出生点，不再询问数量。
- 其它友方小兵存活时，重型小兵不能被正常击败或移除。
- 调试移除可绕过保护，但移除重型仍触发正常推进。
- 重型小兵任何时点被移除都立即推进，不必等轮末。

轮末：

1. 比较双方当前小兵数量；
2. 少兵方额外移除差值数量；
3. 由少兵方队长逐个选择；
4. 非重型小兵必须先移除；
5. 重型被移除后立即推进；
6. 清除旧战区全部剩余小兵；
7. 在新战区出生点重生双方全套小兵；
8. 出生点被占时由对应队长选相邻合法格。

小兵离开战斗区域后的回归路径和队长选择，在首张能造成该状态的卡牌
实装时完成规则确认与测试。

## 13. 金币、等级与升级

- 英雄初始 1 级，最高 8 级。
- 从当前等级升下一级，支付当前等级金币。
- 轮末自动连续支付直到钱不足或到 8 级。
- 当轮没有升级的玩家在升级结算后获得 1 金，不能用于本轮升级。
- 每次成功升级产生一次卡牌升级选择。
- 所有有升级选择的玩家同步选择自己的牌；互不阻塞。
- 只有所有玩家升级选择完成后才开始下一轮。

红、绿、蓝升级：

- 从下一等级两张候选中选一张；
- 选中牌替换当前同色牌；
- 未选牌提供一个永久被动；
- 三色都达到 2 级后才能升 3 级；
- 手牌始终保持金、银、红、绿、蓝五张可选牌。

紫色卡：

- 8 级解锁；
- 六名英雄紫卡全部为持续被动；
- 不参与暗选和普通手牌状态；
- UI 固定显示其拥有状态。

永久被动类型：攻击、防御、移动、先攻、范围、远程。同类叠加，
卡面显示 `基础值+加成`，席位显示聚合总加成。

## 14. 卡牌目标与效果原则

- 不存在单个元动作同时造成范围伤害。
- 多个目标必须逐个选择、逐个产生事件。
- 效果需要保存来源、控制者、时点、持续时间和优先级。
- Instant、Triggered、Continuous、Replacement 必须区分。
- before、after、replace、prevent 必须是明确事件窗口。
- 所有 pending choice 可序列化，断线重连后可继续。
- 强制弃牌在目标有牌时不能跳过；无牌时继续或按牌文处理。
- 具体卡牌的逐元动作、选择窗口、替换与交互在实现该牌时向用户确认。

## 15. 当前明确的复杂牌知识

黄蜂牌组已经积累以下语义：

- 电击系：先选攻击目标，可再选额外英雄；额外目标本人选择弃牌，然后回到攻击。
- 屏障系：攻击者本人选择弃牌；有牌时强制。
- 反射屏障：后续远程攻击不能再指定黄蜂。
- 意念黑洞：黄蜂逐格选择移动方向，每次只移动一格。
- 雷霆回旋镖：满足击败英雄条件时可继续选择重复。
- 意念操控：不能选择免疫重型小兵，放置格由黄蜂选择。
- 电闪雷鸣：基础技能后的弃牌是独立触发，被影响英雄本人选牌。

这些只作为逐卡合同输入，不代表 v5 已实现。
