# R2B02：通用数值石标与行动徽记

本组依据用户对 R2B01 的反馈精修：沙漏收窄、靴子改为清晰的侧面轮廓，所有类别都有独立立体内部徽记。这是实际可编辑 Blender 模型，尚待用户外观验收，未替换游戏资产。

用 Blender 4.5 LTS 打开 `R2B02_SemanticBadges.blend`。顶部 Scene 选择六个场景；数字键盘 0 查看相机，F12 渲染。默认场景为鞋子和沙漏近景，空格可播放小角度转动。每个石标有独立 Empty 根节点，移动或旋转根节点可操作整块；内部徽记、石面、边框、刻字槽底均分开。

| 场景 | 内容 |
| --- | --- |
| 00_CORRECTED_BOOMERANG | 替换全部五块石标后的完整回旋镖按钮 |
| 01_BOOT_AND_HOURGLASS | 修正后的鞋子与沙漏近景 |
| 02_SEVEN_CORE_BADGES | 移动、防御、攻击、技能、先攻、范围、攻击距离 |
| 03_CARD_COLORS_AND_MAGIC | 金银红绿蓝紫石材；原值、绿色增加、红色减少 |
| 04_COMPLETE_NUMERIC_FORMS | 0—9、双位数12/13、负数−2、条件防御∞及旧!兼容字形 |
| 05_ACTION_AND_HISTORY_MARKS | 弃置、取回、响应、快速移动、紫卡触发 |

数值为真实几何凹槽，绿色／红色魔力位于槽底，不改变牌色石材。主行动及范围／攻击距离使用牌色，次要移动、防御及先攻使用灰石。数字页为工艺样本，不表示这些值属于某张真实卡牌。技能无数值时不刻0。∞沿用项目的条件防御显示，不意味着无条件免疫；!只保留字形兼容，不建议显示回游戏。

五种流程徽记用于行动／记录，不是新增卡牌数值槽。这套通用标记可供各卡复用，但不等于108张卡的专属插画已完成。

模型内字形已转为网格，不需要额外字体；使用程序材质，无外部贴图依赖。CPU Cycles渲染是本次外观证据；直接导出FBX不会自动带入相同石材、凹刻和灯光效果。Unity接入仍需材质烘焙、字形复用、小尺寸清晰度与性能验证。

生成器：`tools/art/build_r2b02_badge_library.py`；形体与凹刻：`tools/art/r2b02_stones.py`；徽记：`tools/art/r2b02_emblems.py`；几何检查与实渲：`tools/art/render_r2b02_badge_library.py`。默认拒绝覆盖已有模型，手工修改应另存副本。
