# R2B01：回旋镖单件精修模型

用户认为上一批模型与01差距过大，本批收缩为一个完整技能按钮，逐项重做后交付看样。此目录不是游戏发行包。

用 Blender 4.5 LTS 打开 `R2B01_Boomerang.blend`。默认相机是正面近景，数字键盘0查看，按空格可播放整件小角度摆转。选中 `BUTTON / rotate this complete assembly` 可以转动完整按钮。部件在 `01 / Editable button components` 集合内；材质、灯光、文字凹槽和图标均可编辑。

## 本件内容

- 灰石分段外圈、红色矿石镶带、凹图标盘、与下半盘连成整体的名字石板。
- 数值：次要移动4、次要防御3、主要攻击3、攻击距离3、先攻9；名字为“回旋镖”。
- 靴、盾、剑形、准星长矛、沙漏五种石标，位置沿用用户确认方案。
- 数字和中文名为真实几何凹槽，数字约凹入0.125、中文约0.070个模型单位；暗色槽底位于表面之下。
- 原创分段锻造回旋刃，薄刃、铜质内芯、少量刻伤、橙色弧光和碎石，全部为可编辑立体部件。
- 隐藏的 `VARIANT green_magic` 和 `VARIANT red_magic` 是攻击4／攻击2的填槽材质演示。默认关闭；展示它们时应隐藏原攻击3石面及对应暗槽底。它们不表示已接上实际游戏被动计算。

没有使用概念图贴片。石材和光照由 Blender 材质节点计算。所有可见字形已转为网格切槽，查看模型无需额外安装字体。

## 范围

这是本轮单件精修交付，等待用户美术验收；不是全部技能图标完成，也没有替换 Unity 游戏资源。石材崩口和甲片层次仍比01概念图更规整，不能宣称像素级还原。后续接入需处理游戏实际尺寸、刻字替换、材质烘焙及交互；不能直接导出FBX便视为相同渲染效果。

生成器：`tools/art/build_r2b01_hero_button.py`；图标模块：`tools/art/r2b01_boomerang_hero.py`；验槽和实渲：`tools/art/render_r2b01_hero_button.py`。默认拒绝覆盖已有模型，只有明确重建生成文件时附加 `--replace-generated`。手工修改请另存文件，避免被生成器覆盖。

本批不涉及规则、网络、存档、Unity构建、用户Workbench、main或engine34回退引用。
