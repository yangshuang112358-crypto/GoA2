# R2B01 Blender 模型样本

本目录是实际可编辑模型，尚未接入 Goa2V1 游戏。

- R2B01_ComponentSamples.blend：完整技能、独立石标、旋转装饰环、数字槽近景，共4个命名场景。
- R2B01_FrameParts.blend：空白框体、牌色嵌环、名牌槽、凹叉金属背面和浅分层装配，共2个场景。

使用 Blender 4.5 LTS 打开。在顶部场景选择中切换场景；数字键盘0看相机，中键拖动观察模型。ComponentSamples 的03场景按空格播放：五技能固定，仅装饰转动。完整一圈20秒；场景默认8秒节选，需无缝循环时把帧范围设为0—479。

所有数字和中文刻名为真实几何，不需要另装字体才能查看。材质为程序石材、铜与魔力；没有将概念图贴到平面充当模型。帧动画演示采用CPU Cycles，Blender材质不等于已经转换好的Unity材质。

这是结构与材质样板。当前石材磨损、浮雕图标仍比01概念图简化；没有完成108张技能图标、运行时数值切换或完整交互。请先验收形状、深度、颜色和动效方向。

手工精修请“另存为”新文件名，防止后续生成器覆盖自己的修改。项目制作记录：docs/ui3d/R2B01模型样本与后续接入-2026-10-09.md。
